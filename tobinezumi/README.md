# トビネズミMMO（仮称）ver.0.2「暮らし」

『だんのうら』のおまけゲーム。一匹のトビネズミとして乾いた草原と砂漠を跳ね回り、種や草や小石を集め、自分だけの巣を地下に掘って暮らす。
オフライン（ひとり・この端末に保存）でも、ローカルのサーバーにつないで複数人でも遊べる。

- 入口：`tobinezumi.html`（本編タイトルの「おまけ：トビネズミ」からも入れる）
- 資料：`docs/`（`MVP_SPEC.md` 仕様と受け入れ基準、`PROTOCOL.md` 通信、`ARCHITECTURE.md` 構成と DB、`GAME_DESIGN.md`、`SCREEN_SPEC.md`）

## 1. オフラインで遊ぶ（サーバー不要）

GitHub Pages など静的な置き場所でそのまま `tobinezumi.html` を開く。サーバー（`tobi-server.json`）が見つからなければ自動でオフラインになる。
`tobinezumi.html?offline=1` なら必ずオフライン。保存は localStorage の `tobi_` で始まる鍵だけ（本編・境界事象のセーブには触れない）。

| 操作 | キー |
|---|---|
| 跳ねて移動 / 大ジャンプ（約 4 タイル・1.2 秒ごと） | WASD・方向キー / Space |
| 拾う・調べる・巣に入る・巣を掘る・水を飲む・寝床で眠る | E |
| 種子を食べる / フレンド | Q / F |
| 持ち物 / チャット / メニュー | I / Enter / Esc |
| 巣：全体モード（ビルド）⇄ 閲覧モード | B・Tab（ビルドはマウス。1〜7 でツール、Ctrl+Z で取り消し） |

**スマホ・タブレット**：そのまま開けばタッチ用の画面になる（縦向き＝下に操作の帯、横向き＝左右の端にボタン）。地上は左のスティックで跳ね、地面や採集物・巣穴をタップするとそこへ行って拾う・入る。巣の全体モードは 1 本指でツール、2 本指で移動・拡大縮小。詳しくは `docs/SCREEN_SPEC.md` の「F」。
ホーム画面に追加すると全画面のアプリとして開く（`tobinezumi.webmanifest`。https か localhost で開いたとき、オフライン用の保存も効く）。

### 暮らし（Ver.0.2）

- **体調（ハート）・空腹（稲妻）・水分（しずく）**：遊んでいる間だけ減る（満タンから 空腹 25 分・水分 20 分・体調 40 分）。種子で空腹 +15、オアシスのふちで水 +30、夜の夜露で +15、巣の寝床で眠ると体調が 45 秒で戻る。0 になっても死なないが、体調 25 未満だと遅く、大ジャンプできない。
- **昼と夜**：24 分で 1 日（夜 10 分・昼 10 分）。夜は暗く、採集物が早く戻り、夜だけの種子と夜露が出る。
- **フレンド・巣の設定**：メニュー →「フレンド」。全体モードの「巣の設定」で訪問設定（非公開／フレンドだけ／許可リスト／公開）・共同作業者（オンライン）。巣を訪ねてきた子は通知、留守中の訪問は次のログインで一覧。オフラインではナッツ・モカ・リコとフレンドになれる。
- **動作確認用の早回し**：オフラインで `tobinezumi.html?offline=1&timescale=60&hour=22`（60 倍速・22 時から）。サーバーは `TOBI_DEV=1 TOBI_TIMESCALE=60 TOBI_START_HOUR=22 npm start` のときだけ（ふつうに起動したサーバーでは効かない）。
- セーブは版 2（`tobi_save_v1` の中の `v`）。ver.0.1 のセーブは読み込み時に自動で移行（持ち物・巣はそのまま、数値は 80/80/100 から）。

## 2. ローカルのサーバーで複数人で遊ぶ

Node.js 22.13 以上（組み込みの `node:sqlite` を使う）。依存は `ws` だけ。

```sh
cd tobinezumi/server
npm install
npm start
```

→ `http://localhost:8080/tobinezumi.html` を**複数のブラウザ（または別のプロファイル・シークレットウィンドウ）**で開き、それぞれ「新規登録」→ キャラクター作成。
同じ LAN のほかの PC からは `http://<このPCのIP>:8080/tobinezumi.html`。

### スマホからつなぐ（同じ Wi-Fi）

1. サーバーは最初から全部の口（`HOST=0.0.0.0`）で待ち受けている。PC の LAN の IP を調べる：
   - Windows：`ipconfig`（「IPv4 アドレス」例 `192.168.1.23`）／macOS：`ipconfig getifaddr en0`／Linux：`hostname -I`
2. スマホのブラウザで `http://192.168.1.23:8080/tobinezumi.html` を開く（PC と同じ Wi-Fi に）。自動でオンラインになり、「新規登録」→ キャラクター作成。
3. つながらないとき：PC のファイアウォールで TCP 8080 の受信を許可する（Windows は初回起動時の「アクセスを許可」）。ゲスト用 Wi-Fi など端末どうしの通信を止めているネットワークでは使えない。
4. http（LAN）では service worker が動かないので、オフライン用の保存とアプリとしてのインストールは効かない（ホーム画面へのブックマークはできる）。遊ぶこと自体は問題ない。外から使うなら下の「安全のための注意」のとおり HTTPS の逆プロキシを置く。


- サーバーはリポジトリのルートから必要なファイルだけを配り（`tobinezumi.html`・`tobinezumi/client|shared|assets`・フォント・本編）、`/tobi-server.json` に `{"ws":"/ws"}` を返すので、開くだけで自動でオンラインになる。
- GitHub Pages 版のクライアントから同じサーバーへつなぐ：`tobinezumi.html?server=ws://localhost:8080/ws`
- データ：`tobinezumi/server/data/game.db`（SQLite 1 ファイル）。起動時に `migrations/` の未適用分と、巣データの版の移行（`migrateNest`）が自動で走る。
- 止める：Ctrl+C（または `kill $(cat data/server.pid)`）。止める前に全員の位置を保存し、クライアントは自動で再接続して続きから遊べる。
- 状態：`http://localhost:8080/healthz`（人数・メモリ・通信量）。1 分ごとに `[stats]`（CPU・メモリ・通信量）をログに出す。

| 環境変数 | 既定 | 意味 |
|---|---|---|
| `PORT` / `HOST` | 8080 / 0.0.0.0 | 待ち受け |
| `TOBI_DATA` | `data` | DB と PID ファイルの置き場 |
| `TOBI_BACKUPS` / `TOBI_BACKUP_KEEP` / `TOBI_BACKUP_HOURS` | `backups` / 48 / 1 | 自動バックアップの置き場・世代数・間隔（0 で止める） |
| `TOBI_STATS_SEC` | 60 | `[stats]` ログの間隔（0 で止める） |
| `TOBI_REGISTER_MAX` | 20 | 1 つの接続元から 10 分に登録できる数 |
| `TOBI_DEV` / `TOBI_TIMESCALE` / `TOBI_START_HOUR` | 0 / 1 / – | 開発用：`TOBI_DEV=1` のときだけ、時計・暮らし・採集物の戻りを何倍速にするかと、起動時の世界の時刻 |

### オンラインでできること（Ver.0.1＋0.2）

- 登録・ログイン（パスワードは scrypt、セッション token は 30 日）、キャラクター作成（1 アカウント 1 匹）
- 共有フィールド：ほかのプレイヤーの姿・名前・跳躍・チャット（頭上の吹き出し＋ログ）。自分は予測、他人は 100ms 遅れの補間
- 採集：サーバーが管理。同時に拾っても先着 1 人だけ。2〜5 分後に別の場所へ再出現
- 巣：掘る・通路・部屋（拡張）・寝床・倉庫・家具・撤去。すべてサーバーで検証し、中にいる人へ配信
- 訪問：巣の訪問設定（全体モードの上のセレクト）＝ 非公開 / 公開 / 許可リスト（キャラ名で）。訪問者は見る・歩く・チャットだけ（編集・倉庫は不可）
- 切断：自動で再接続（0.5→1→2…→30 秒）。その間は画面が暗くなり「つながりなおしています…」。60 秒以内なら同じ位置（巣の中なら巣の中）、それより後は自分の巣の入口から
- 保存：位置（30 秒ごと・ログアウト・切断・停止時）、持ち物と巣は操作ごと
- Ver.0.2：空腹・水分・体調はサーバーが計算（食べる＝種子が要る・飲む＝水辺か夜露の近くだけ・眠る＝寝床の上だけ）し、`individuals.status.life` に保存。昼夜はサーバーの時刻で全員同じ。フレンド（申請・承認・オンライン状態・巣の場所）、訪問設定「フレンドだけ」、共同作業者（非公開の巣でも入って編集できる）、訪問の通知（留守なら次のログインで一覧）。DB は起動時に `003_life_social` へ自動で移行

## 3. ボット（負荷試験）

```sh
npm run bots -- 10                 # 10 体を 60 秒（--secs 120、--url ws://host:8080/ws、--prefix bot）
```

ボットは登録（2 回目からはログイン）→ キャラ作成 → 跳ね回る・大ジャンプ・チャット・近くの採集物を拾う・公開の巣を訪ねる。終わると合計（拾った数・スナップショットの間隔・受信量など）を 1 行の JSON で出す。

## 4. バックアップと復元

```sh
npm run backup                     # 今すぐ：data/game.db → backups/game-YYYYMMDD-HH.db（VACUUM INTO・動いていても取れる）
npm run backup -- --list           # 一覧
npm run restore -- backups/game-20261011-09.db
```

- サーバーは 1 時間ごとに同じ形で自動バックアップし、新しい 48 個を残す（`TOBI_BACKUP_KEEP`）。
- 復元は**サーバーを止めてから**（動いていると PID ファイルを見て止める）。中身を確かめ（integrity_check）、今の DB を `backups/pre-restore-*.db` に退避してから差し替える。そのあと `npm start`。古い版のバックアップでも起動時のマイグレーションで新しい版に上がる。

## 5. テスト

```sh
cd tobinezumi/server && npm test   # サーバー：core（ws 不要）＋ e2e（本物の WebSocket）
node tests/run.mjs                 # リポジトリ全体（トビネズミのサーバー core を含む。ws が無ければ e2e は飛ばす）
```

life（Ver.0.2）：減り方・食べる／飲む／眠るの検証・へとへとの移動・再起動後も数値が残る・昼夜で採集物が変わる・早回し・共同作業者・フレンド・訪問の通知。リポジトリ側の `tests/tobinezumi-life.test.mjs` は共有ルールとオフライン版（セーブの移行 v1→v2 を含む）。
ボット（`npm run bots`）は、おなかがすくと食べ、のどがかわくと夜露かオアシスへ行って飲み、巣のあるボットは寝床を作ってときどき眠る。

core：認証（scrypt・token の期限・ログイン失敗の制限）、移動の検証（速度上限・ジャンプのクールダウン・壁を通らない・予測と一致）、採集の排他（10 人同時でも 1 人）、巣の権限と rev（stale_rev）、訪問設定、チャットの制限、再接続（60 秒）、再起動後の復元、マイグレーション、バックアップ／復元。

Docker で動かす場合（任意）：`docker build -t tobinezumi -f tobinezumi/server/Dockerfile .`（リポジトリのルートで。未検証の参考）→ `docker run -p 8080:8080 -v tobi-data:/app/tobinezumi/server/data tobinezumi`

## 6. 安全のための注意（ローカル運用の前提）

- Ver.0.1 は**ローカル／信頼できる LAN 向け**。インターネットへ公開するなら、前に HTTPS（WSS）の逆プロキシ（Caddy・nginx など）を置き、`HOST=127.0.0.1` で待ち受けること。平文の ws ではパスワードが盗み見られる。
- パスワードは scrypt（N=16384）＋ソルト。DB には token の SHA-256 しか置かない。ログイン失敗はユーザー名ごと 5 回／5 分、接続元ごと 20 回／5 分で止める。登録も接続元ごとに制限。
- サーバーが正：位置はサーバーが入力列から計算（位置を送る口が無い）。入力は 1 秒 60 個まで、跳躍のクールダウン・壁は共有ルール `shared/move.js`。採集・建築・倉庫・訪問はすべてサーバーで検証し、持ち物と巣は同じトランザクションで保存。
- チャットは 80 文字・制御文字を除去・10 秒 5 回まで。表示はすべてエスケープ（HTML として解釈しない）。1 メッセージ 16KB まで、1 接続 150 通／秒を超えると切断。同じアカウントの 2 か所目のログインで古い接続を切る。
- 静的配信は許可した場所だけ（`tobinezumi/server`・`.git`・`tools`・`tests`・`docs` は配らない）。`data/`・`backups/`・`node_modules/` は git に入れない（`server/.gitignore`）。
- 管理画面は無い（Ver.0.1）。ログとコマンドラインで運用する。
