# GAME_DESIGN — トビネズミMMO（仮称）ゲーム全体構想

> 状態：**設計案（承認待ち）**

## 1. 一言で

**一匹のトビネズミとして乾いた大地を跳ね回り、住みやすい土地に自分だけの巣を掘り、世代を重ねていくオンライン生活ゲーム。**

魔王もラスボスもいない。目的は「生き抜く」「良い土地を見つける」「巣を豊かにする」「子孫を残す」。プレイヤーが自分で小さな目標を見つけ、達成し続ける。

## 2. 柱（デザインピラー）

1. **跳ねる気持ちよさ** — 小刻みな連続跳躍と大ジャンプ。移動そのものが楽しい。
2. **掘って、住む** — 地下の断面に通路と部屋を掘る（全体モード）。掘った巣の中を実際に歩いて暮らす（閲覧モード）。同じ巣を二つの見方で。
3. **ゆるくつながる** — 同じ草原で他のトビネズミとすれ違い、チャットし、巣を訪ね合う。競争より共生。
4. **本物の生態に寄り添う** — 夜行性、乾燥地の植物、種子食、巣穴の入口を塞ぐ習性、天敵（フクロウ・キツネ・ヘビ）。見た目はリアル寄り、でも親しみやすく。
5. **長く育つ** — 新地域・季節・繁殖・遺伝・世代交代を年単位で追加できる土台。

## 3. 世界観

- 舞台は中央アジア〜北アフリカの乾燥地帯を思わせる架空の大陸。砂漠・乾燥草原・岩場・砂丘・渓谷。
- 主人公はトビネズミ（長い後脚、大きな耳、房のついた長い尾）。初期は 1 種のみ。将来、ミミナガトビネズミ・コミミトビネズミなど近縁種を追加可能な構造。
- **隠しエリア「富山」**：本来トビネズミがいないはずの、雪山と水田と桜の土地。なぜそこへ辿り着けるのかが物語上の秘密。わかばプロジェクトの他作品（『だんのうら』『境界事象』など）との関係は、収集品・背景・出来事・隠し演出で**ほのめかすだけ**。具体的な理由はまだ決めない（器だけ用意）。

## 4. 遊びのサイクル

```
地上で探索 ──→ 採集（種子・草・小石）──→ 巣へ持ち帰る ──→ 倉庫に保管
   ↑                                              │
   │                                              ↓
他プレイヤーと交流 ←── 巣を訪問・見せ合う ←── 掘る・部屋を作る・飾る
```

- 将来はここに「空腹・体調」「天敵からの逃走」「昼夜と季節」「繁殖・育児・世代交代」が重なる。

## 5. 画面（詳細は SCREEN_SPEC.md）

| 画面 | 視点 | 役割 |
|---|---|---|
| タイトル／キャラクター作成 | — | 登録・ログイン、名前、毛色 |

## 6. 将来の大きな機能（ROADMAP.md に段階化）

- **生存**：空腹・水分・体調・寿命。夜に活動し、昼は巣で眠ると回復しやすい。
- **環境**：天候・昼夜・季節（夏の休眠、冬眠）。
- **危険**：捕食者（フクロウ・キツネ・ヘビ）。大ジャンプでかわす。巣への侵入・入口の封鎖。
- **土地**：場所ごとに食料・危険・地質（掘りやすさ）・気候・希少資源・景観。土地探し・引っ越し。
- **繁殖・遺伝・世代交代**：成熟 → NPC 個体と繁殖 → 複数の子（遺伝で毛色・耳・脚・尾・体格が異なる）→ 巣で成長 → 次の操作個体を選ぶ → 巣・収集品・血統を継承。家系図。
- **交流**：共同巣、贈り物、ランキング（巣の豊かさ・家系の長さなど穏やかな指標）。
- **収集品・実績**：他作品との連動アイテム（ドラゴンズカード、機械の部品、不思議なお守り、黒い羽、謎の結晶 …）。

## 7. トーン

- 静かで温かい。夕暮れと夜の色。風の音、砂の音、虫の声。
- 文字は短く、説明しすぎない。プレイヤーの発見を大事にする。
- 他作品との関係は**断定しない**（『境界事象』と同じ姿勢）。

## 8. やらないこと（当面）

- 戦闘中心のゲーム化、課金要素、大規模 MMO 用の分散サーバー。
- 既存ゲーム（『アジト2』など）の画面・素材の複製。地下断面ビルドは**着想のみ**でオリジナルデザイン。
