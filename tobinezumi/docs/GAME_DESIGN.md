# GAME_DESIGN — トビネズミMMO（仮称）ゲーム全体構想

> 状態：**設計案（承認待ち）**

## 1. 一言で

**一匹のトビネズミとして乾いた大地を跳ね回り、住みやすい土地に自分だけの巣を掘り、世代を重ねていくオンライン生活ゲーム。**

魔王もラスボスもいない。目的は「生き抜く」「良い土地を見つける」「巣を豊かにする」「子孫を残す」。プレイヤーが自分で小さな目標を見つけ、達成し続ける。

## 2. 柱（デザインピラー）

1. **跳ねる気持ちよさ** — 小刻みな連続跳躍と大ジャンプ。移動そのものが楽しい。
2. **掘って、住む** — 地下の断面に通路と部屋を掘る（全体モード）。掘った巣の中を実際に歩いて暮らす（閲覧モード）。同じ巣を二つの見方で。
3. **ゆるくつながる** — 同じ草原で他のトビネズミとすれ違い、チャットし、巣を訪ね合う。競争より共生。
4. **本物の生態に寄り添う** — 夜行性、乾燥地の植物、種子食、巣穴の入口を塞ぐ習性、天敵（フクロウ・キツネ・ヘビ）。見た目はリアル寄り、でも親しみやすく。
5. **長く育つ** — 新地域・季節・繁殖・遺伝・世代交代を年単位で追加できる土台。

## 3. 世界観

- 舞台は中央アジア〜北アフリカの乾燥地帯を思わせる架空の大陸。砂漠・乾燥草原・岩場・砂丘・渓谷。
- 主人公はトビネズミ（長い後脚、大きな耳、房のついた長い尾）。初期は 1 種のみ。将来、ミミナガトビネズミ・コミミトビネズミなど近縁種を追加可能な構造。
- **隠しエリア「富山」**：本来トビネズミがいないはずの、雪山と水田と桜の土地。なぜそこへ辿り着けるのかが物語上の秘密。わかばプロジェクトの他作品（『だんのうら』『境界事象』など）との関係は、収集品・背景・出来事・隠し演出で**ほのめかすだけ**。具体的な理由はまだ決めない（器だけ用意）。

## 4. 遊びのサイクル

```
地上で探索 ──→ 採集（種子・草・小石）──→ 巣へ持ち帰る ──→ 倉庫に保管
   ↑                                              │
   │                                              ↓
他プレイヤーと交流 ←── 巣を訪問・見せ合う ←── 掘る・部屋を作る・飾る
```

- 将来はここに「空腹・体調」「天敵からの逃走」「昼夜と季節」「繁殖・育児・世代交代」が重なる。（Ver.0.2 で空腹・体調と昼夜、Ver.0.3 で天敵・天気と季節・土地選びが重なった：夜は実りが多いがフクロウとキツネが出る、昼はヘビ、草むらでじっとすれば隠れられる、危険の少ない土地は実りも少なめ、硬い土地は掘るのが大変）

## 6. 将来の大きな機能（ROADMAP.md に段階化）

- **生存**：空腹・水分・体調・寿命。夜に活動し、昼は巣で眠ると回復しやすい。（Ver.0.2 で空腹・水分・体調と昼夜を実装：MVP_SPEC.md §6）
- **環境**：天候・昼夜・季節（夏の休眠、冬眠）。（Ver.0.3 で砂嵐・雨・寒い夜・季節・休眠を実装：MVP_SPEC.md §7.2）
- **危険**：捕食者（フクロウ・キツネ・ヘビ）。大ジャンプでかわす。巣への侵入・入口の封鎖。（Ver.0.3 で実装：§7.1。**死なない**：つかまると体調が大きく減り、持ち物の一部を落とす。怖さより「見つからないように・見つかったら逃げる」遊び。設定で やさしく・出ないにもできる）
- **土地**：場所ごとに食料・危険・地質（掘りやすさ）・気候・希少資源・景観。土地探し・引っ越し。（Ver.0.3 で 64 区画・調べる・引っ越しを実装：§7.3）
- **繁殖・遺伝・世代交代**：成熟 → NPC 個体と繁殖 → 複数の子（遺伝で毛色・耳・脚・尾・体格が異なる）→ 巣で成長 → 次の操作個体を選ぶ → 巣・収集品・血統を継承。家系図。（Ver.0.4 で実装：MVP_SPEC.md §8。実際のトビネズミにならって、夜行性・春から夏に子が多い・冬は巣ごもり・大きな耳は熱を逃がす。**死なない**：寿命の目安をすぎるとやさしく「次の世代へ」と知らせるだけ。求愛は短い「なかよくなる」（じっとする・種子をあげる）だけで、家族向けの表現にとどめる）
- **交流**：共同巣、贈り物、ランキング（巣の豊かさ・家系の長さなど穏やかな指標）。
- **収集品・実績**：他作品との連動アイテム（ドラゴンズカード、機械の部品、不思議なお守り、黒い羽、謎の結晶 …）。（Ver.0.5 で実装：図鑑 18 品・実績 13・ごほうびの飾り・巣に飾る。§9）
- **広がり**：岩場・砂丘・渓谷の新しい土地と、隠しエリア「富山」。（Ver.0.5 で実装：MVP_SPEC.md §9）

## 7. トーン

- 静かで温かい。夕暮れと夜の色。風の音、砂の音、虫の声。
- 文字は短く、説明しすぎない。プレイヤーの発見を大事にする。
- 他作品との関係は**断定しない**（『境界事象』と同じ姿勢）。

## 8. やらないこと（当面）

- 戦闘中心のゲーム化、課金要素、大規模 MMO 用の分散サーバー。
- 既存ゲーム（『アジト2』など）の画面・素材の複製。地下断面ビルドは**着想のみ**でオリジナルデザイン。

## 9. 富山（Ver.0.5 で実装したこと・決めていないこと）

> 方針（企画どおり）：**他作品との関係も、トビネズミが富山へ行ける理由も決めない**。収集品・背景・調べられる物・小さな出来事で**ほのめかすだけ**。ゲームの中で他作品の題名・人物の名前は出さない。

### 実装したこと
| 項目 | 中身 |
|---|---|
| 行き方 | 西の「みずおとの谷」の上流（谷の奥）に**苔むした古い石の標**。「ゆきの よる　しろい もの　ここに あなを あける」……と読める気がする。3 つの土地で「しるし」（ふるい石板のかけら・青い砂ガラス・白い毛のひとふさ。どれも冬の谷を指す説明）を図鑑に集め、**冬の夜に雪が降っている**とき、標のそばに「不思議な穴」がほの白く開く。条件はサーバーが確かめる（`shared/collect.js` の `gateOpen`）。一度たどり着いたら、あとは**夜ならいつでも**開く（春の桜・夏の蛍も見に行ける） |
| 土地 | 北に**雪の山なみ**（立山連峰のような横長の景色）、真ん中に**水を張った田んぼ**とあぜ道と水路（季節で 苗 → 青い稲 → 金の稲穂 → 雪の田）、あぜ道に**桜**（季節で花・葉・紅葉・雪の枝）、南と東の端に**瓦屋根の家**（人間の世界：入れない・越えられない）。夏の夜は蛍、冬はよく雪が降り、寒い（`cold`） |
| 静けさ | 捕食者も野生のトビネズミもいない（だれも追ってこない、だれもいない）。遠くで鈴のような音がまれに鳴る（環境音） |
| 調べられる物 | 小さな祠（「…の神さま　…まもり…」かすれて読めない）・細い道しるべ（かすれた数字「４４４」だけ読める）・油のにおいのする金属のかたまり（工場で使うもの…だろうか）・草の中で光る四角い板（画面に「……」と文字が流れて、すぐ暗くなる）・夜の山のふもとの向こうの、夜通し灯りのついた大きな建物 |
| 白い小さな影 | 夜、遠くにほんの少しだけ白い小さな影が見えることがある。近づくと消える。「…いま、なにか白いものが いた気がする」。名前は出さない |
| 不思議な品（収集品） | ドラゴンズカード「どこかで見た絵が描かれた札」・機械の部品「人間の世界のものらしい」・不思議なお守り「見たことのない紋章が刻まれている」・黒い羽「大きな鳥のものだろうか…」・謎の結晶「別の世界から来たような気がする」・**???の札**「よく分からない絵が描かれている。少し硬い。巣に飾れそうだ。とても貴重なもののようだ…」（いちばん出にくい：夜・その場の子がほかの不思議な品を 4 つ以上持っているときだけ・1 回の判定で 1.2%） |
| 巣 | **富山には巣を掘れない**（「ここでは 巣を掘る気になれない（土が冷たくて、なにかが違う）」）。来た穴から いつでも谷へ戻れる。0.5 では「仮の巣穴」も作らない（富山を「暮らす場所」ではなく「訪ねる場所」にしておく。あとで器を足せるよう、地図に `noBurrow` の印だけ） |
| 記録 | アカウントの印 `account_flags.toyama = 1`・実績「知らない土地」（とるまで ？？？）・世界地図の南西の霧が晴れる・図鑑の「富山」の段 |

### 決めていないこと（器だけ）
- トビネズミがなぜ富山へ行けるのか。穴はだれが・なにが開けているのか。白い影はなにか。
- 不思議な品が どの作品の・だれの物なのか（説明は「どこかで見た」「人間の世界」「見たことのない」までで止める）。
- 光る板の文字の中身・道しるべの数字の意味・遠くの灯りの建物。
- これからの出来事（`events` 表・`account_flags` は空けてある。季節ごとの品・富山での小さな出会いなどを、ほのめかしのまま足していく）。
