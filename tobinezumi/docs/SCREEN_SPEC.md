# SCREEN_SPEC — 画面構成と操作仕様

> 状態：**設計案（承認待ち）**。添付イメージ（キャラクター作成／砂漠の共有フィールド／巣の全体画面／巣内を歩く／訪問／繁殖／富山）を見た目の基準にする。

## 共通
- 内部解像度 480×270（16:9）、整数倍に最近傍拡大（1920×1080 なら 4 倍）。UI 文字は内部解像度とは別レイヤーで高解像度に描く（読みやすさ優先）。
- フォント：DotGothic16（OFL）。UI の枠は濃茶の地に明るい縁取り（添付イメージの雰囲気）。
- 色調：夕暮れの砂色・オリーブの草・青い水・茶色の土。巣の中はランタンの橙。
- PC（キーボード＋マウス）とスマホ・タブレット（タッチ）の両方。タッチは「F. スマホ・タブレット（タッチ操作）」。PC の見た目と操作は従来どおり（480×270 の整数倍）。

## A. タイトル・キャラクター作成
1. タイトル：ロゴ、夜の砂漠で跳ねるトビネズミ。「ログイン」「新規登録」。
2. 登録／ログイン：ユーザー名・パスワード。エラーは入力欄の下に短く。
3. キャラクター作成（添付イメージ左上）：大きな立ち絵（左）＋「なまえ」入力＋「毛色を選択」（◀ ▶ で 5 色、選んだ色の小さな見本 3 体）＋［決定］。
4. 確認：「この子で はじめますか？」→ はじめる。

- カメラは自分を中心に追従（地図の端では止まる）。
- 名前は頭上（自分は明るい色）。吹き出し 5 秒。
- ミニマップ（右上）：地形と自分の巣の入口、近くのプレイヤーの点。
- 採集物は近づくと縁が光り「E 拾う」。
- 巣穴入口に近づくと「E 巣に入る（○○の巣）」。

| 操作 | キー | 動き |
|---|---|---|
| 移動 | WASD / 方向キー | 小跳躍の連続（約 0.18 秒ごとに 1 跳ね、8 方向） |
| 大ジャンプ | Space | 向いた方向へ約 4 タイル、低木・小石を越える。クールダウン 1.2 秒 |

| チャット | Enter | 入力欄を開く／送信。Esc で閉じる |
| メニュー | Esc | 設定（音量・拡大率）・ログアウト |

## C. 巣の全体モード（地下断面ビルド）
- 添付イメージ「巣の全体画面」：上に地表と空、下に土の断面。左に縦のツールメニュー（掘る／通路／寝床／倉庫／家具／撤去）。
- グリッド 48×24（1 セル 16px）。マウスホイールで拡大縮小、右ドラッグでスクロール。
- 選んだツールの置ける場所は明るく、置けない場所は赤で表示（理由を短く：「岩は掘れない」「部屋が重なる」「素材が足りない」）。
- 部屋の辺にカーソルを置くと拡張ハンドル。
- 下部に素材の数（草・小石・種子）。
- 右下に［歩いてみる（Tab）］。

| 操作 | 入力 |
|---|---|
| ツール選択 | クリック or 数字キー 1〜6 |
| 配置・掘る | 左クリック／左ドラッグ |
| 回転（家具） | R |
| 取り消し（直前 1 手） | Ctrl+Z（サーバーへ逆操作を送る） |
| 閲覧モードへ | Tab |
| 閉じる（巣ビルドを抜ける） | B / Esc |

## D. 巣内閲覧・生活モード
- 添付イメージ「巣内を実際に歩く」：横からの断面。ランタンの明かり、寝床、種の山、棚、出入口。
- 画面下に操作ガイド：［← → 移動］［Space ジャンプ］［E 調べる］［B ビルドモード］。
- 縦通路では ↑↓ で登り降り。斜め通路は ← → だけで上り下り。
- 部屋の名前（寝床・倉庫）を入ったときに小さく表示。
- 訪問者は名前付きで表示、吹き出しで会話（添付イメージ「他プレイヤーの巣を訪問」）。

## G. 暮らし・昼夜・つながり — Ver.0.2「暮らし」
- **体調・空腹・水分のバー**（添付イメージ：ホットバーの右）：赤いハート＝体調、黄色の稲妻＝空腹、水色のしずく＝水分。PC は右下、巣の中（ホットバーなし）は右上、タッチは左上（地域名の下）。低くなるとアイコンが点滅、0 は枠が赤。押す（タップ）と「くらし」パネル（数値・ことば・説明・「種子を 1 つ食べる」）。境目をまたぐとトースト（おなかがすいてきた・のどがかわいてきた・へとへとだ）。
- **時計**：ミニマップのすぐ下（巣の中は右上）に太陽／月のアイコン＋「昼 13:20」。夜は青い縁。
- **昼夜の見た目**：夕方は橙、夜は青く暗く、自分のまわりだけ柔らかく明るい（ほかのトビネズミ・自分の巣穴の灯り・夜露も小さく光る）。夜のオアシスには星と月が映る。明け方は桃色。**巣の中の明るさは変えない**：入口から差しこむ光が夜は弱く青白くなり、地表より上の空に星と三日月が出る（全体モードの空も色が変わる）。
- **食べる**：PC は `Q`、持ち物で種子を選んで「1 つ食べる」、くらしパネルのボタン。タッチは右下の小さな丸「食べる」。巣の中の「種の山」で E（調べる）＝倉庫の種子を食べる。
- **飲む**：オアシスのふちで「E 水を飲む」、夜の草むらの夜露（きらきら光る水滴）で「E 夜露を飲む」（タップで歩いて行って飲む）。
- **眠る**：寝床の上で「E 眠る（体調が戻る）」。画面がゆっくり暗くなり「すやすや…」と体調のバー（時間が早く流れる）。満タンで「よく眠った」。ほかの子には眠る姿と z が見える。
- **フレンド**：メニュー →「フレンド」（PC は `F`）。名前で申請、一覧（申請が来ている／オンライン（巣の中）／オフライン／返事待ち）、受ける・断る・取り消す・やめる・「巣の場所」（ミニマップで光らせる）。地上の巣穴の名札に「（フレンド）」、ミニマップのフレンドの巣は緑で点滅。
- **巣の設定**（所有者・全体モードの上の帯「巣の設定」）：訪問設定 4 つ（指で押せる大きなボタン）、許可リストと共同作業者は名前のチップ（× で外す・入力欄＋「追加」）、最近たずねてきた子。共同作業者が全体モードに入ると上の帯は「共同作業者として編集」、歩く画面の名前は「（共同作業者）」。
- **訪問の通知**：トースト「○○ が あなたの巣を たずねてきた」。ログインした直後に「留守のあいだに」パネル。

## H. 危険と土地 — Ver.0.3「危険と土地」
- **捕食者**（地上）：キツネ（地面を走る・掘る）、フクロウ（空。地面に小さな影、狙うと影が大きく濃くなり、点線の赤い輪＝急降下の予告）、ヘビ（岩や草のかげで半透明に待ち伏せ・「シャーッ」で震える・伸びて飛びかかる）。狙われると頭の上に**「！」**（黄色の札）、画面の端が赤く脈打つ（急降下・飛びかかりの瞬間は速く）、ミニマップに赤い点。効果音（「！」・ほうほう・ひゅうっ・シャーッ）。逃げきると「○○から にげきった！」。
- **草むらに隠れる**：草地・草の房・低木のそばで 0.5 秒じっとしていると半透明になり、足元に草、名札の下に「かくれている」（捕食者がいるとき・夜）。
- **つかまった**：画面が赤く光ってゆれる → 「キツネに つかまった！ 体調が減り、種子×2・草×1 を落とした（拾いに戻れる）」→ 自分の巣の入口（無ければ出発点）へ。しばらく点滅（狙われない）。落とし物はその場に山（きらきら）で「E 種子 ×2 を拾う（落とし物）」。ほかの子にも見える・拾える。
- **時計の横に季節と天気**：「🌙 夜 22:10 │ 秋」、砂嵐は渦巻きの線＋「砂嵐」（枠が砂色）、雨は雲としずく＋「雨」（枠が水色）、冬の夜は雪の結晶＋「寒い」（白い縁）。季節の文字は色分け（春 桃・夏 黄・秋 橙・冬 青白）。
- **天気の見た目**：砂嵐＝画面が砂色にかすみ、端ほど見えない、横に流れる砂粒。雨＝青灰色、斜めの雨すじ、草むらに水たまり（「E 水たまりの水を飲む」）。冬の夜＝画面の端に霜、雪がちらつく。季節で地面の色味が少し変わる（夏 明るい黄・秋 橙・冬 白っぽい青）。夜は天気の粒も暗い。理由のトースト（「砂嵐で体調が減っている（岩や低木のかげ・巣へ）」「寒い夜：巣の外では体調が減る」）、くらしパネルにも理由。休眠中は「冬眠：ぐっすり休める」。
- **土地を調べる**（PC `L`・タッチ上の帯「土地」）：パネル「土地を調べた」＝区画の名前、食料・危険・地質・景観の ★5 つと短い説明（危険 0 は「安全地帯（捕食者が来ない）」）、気候、希少資源、「ここに巣を掘るなら：掘れる（1.2 秒・素材 なし）／掘れない（理由）」「この区画の巣 n 個」。巣が無ければ［ここに巣を掘る］、巣があれば「引っ越し：費用 小石×3・草×4（巣の中はそのまま）」と［ここへ引っ越す］（できないときは薄く・理由）。調べた所に赤い旗（20 秒）。
- **巣を掘る確認**：土地の性能の 1 行（食料・危険・地質・景観・気候・希少）。掘る時間は地質で 0.9〜2.1 秒（掘る姿）。
- **引っ越し**：確認「巣の入口を ここ（○○）へ移しますか？ 巣の中（部屋・家具・倉庫）はそのまま持っていける。費用… 次に引っ越せるのは 10 分後」→ 掘る姿 → 古い入口と新しい入口に土けむり → 「引っ越した！」。フレンドには「○○ が 巣を引っ越した（ミニマップで光っている所）」。
- **ミニマップの重ね表示**（PC `M`・タッチはミニマップをタップ）：区画ごとに 危険（緑 → 黄 → 赤）／食料（濃い緑ほど多い）／なし。ミニマップの下に「危険（緑→赤）」。
- **入口をふさぐ**（巣の中を歩く画面）：入口の縦穴の下で「調べる 入口をふさぐ（小石×2・夜のキツネから巣を守る）」→ 縦穴の口に小石が積まれ、上の名前の横に「入口：ふさいである」。もう一度で「入口をひらく（小石が 1 つ戻る）」。地上の入口にも小石が見え、名札の案内は「（入口がふさがれている）」。
- **留守のあいだに**（ログイン直後）：訪問者に加えて「キツネが巣の入口を掘り返した（倉庫の種子 −3）」（赤）／「キツネが来たが、ふさいだ入口のおかげで無事だった」（緑）と、ふさぎ方の一言。オンライン中は トースト。
- **メニュー**：「捕食者（フクロウ・キツネ・ヘビ）」＝ふつう／やさしい／出ない（オフラインだけ）、「効果音」＝鳴らす／鳴らさない。
- **タッチ**：地上の上の帯に「土地」を足した（持ち物・土地・チャット・メニュー・隠す）。横向きでは右の端のボタンの列を**ミニマップの下端から**並べる（`--mm-bottom` を画面から測る）。390×844・844×390・360×740・820×1180 で HUD が重ならないことを確かめた。パネルを閉じた指は地面のタップにならない。

## I. いのちをつなぐ — Ver.0.4「いのちをつなぐ」
- **キャラクター作成**：毛色の下に［♀ 女の子］［♂ 男の子］。確認に「♀ 女の子・若者（3 日）から」。タイトルの版は「ver.0.4「いのちをつなぐ」」。
- **年齢**：体調のバーを押す（PC はメニュー → くらし）と、くらしパネルのいちばん上に「名前　おとな・5.2 日（遊んでいる間だけ年をとる…寿命の目安 30 日）」と［家族・家系図］。おとなになると「おとなになった！ 野生のトビネズミと なかよくなれる」、年寄りは「のんびり子や孫を見守ろう」。30 日をすぎると世界の 1 日に 1 回「そろそろ次の世代へ」（家族を見る／旅立つ（子がいないとき）／まだ このまま）。
- **野生のトビネズミ**（地上）：遺伝子どおりの毛色・耳・脚・尾・体。名札は小さく「野生の○○」。気になると後ろ脚で立ち上がってこちらを見る（`jerboa.field.sniff`）。信頼が 0 より大きいと頭の上にハート（0/25/50/75/100 で満ちる）と桃色の細いバー。近くで「調べる 種子をあげる（○○・信頼 40/100）」、あげるとハートが舞い「もぐもぐ… 信頼 65/100」。跳ね回ると「びっくりして逃げた（そっと近づいて、じっとしよう）」。なかよしになると「○○ と なかよしになった！ ついてくる」、名札に ♥、ハートの横にきらきら。タッチは野生の子をタップすると そばまで行く。
- **巣へ迎える**：ついてきた子と入口から入ると「○○ を 巣に むかえた！ つれあいになった（世界の半日ほどで 赤ちゃんが生まれる）」。だめなときは「○○ は 入口で待っている：巣に寝床の部屋が要る…」（赤）。
- **赤ちゃん**：「巣で 赤ちゃんが 4 匹 生まれた！」。自分の巣の中なら（外なら次に入ったとき）**名前をつける**パネル：子の絵・♀♂・おすすめの名前の入った入力欄・形質の札（「赤茶」「斑」「耳が大きい」…：大きい方は緑、小さい方は青、まれなものは金）→［この名前にする］［あとで］。
- **巣の家族**（歩く画面）：つれあい・子・きょうだいが寝床の部屋にいて、子ども・若者は親が同じ部屋にいるとついてくる（2 秒いると部屋を移ってくる）。昼（夜行性）と親が眠るときは寝床で眠る（z）。名前は小さく、つれあいは ♥。おなかが少ないと「おなかすいた」。近くで「調べる ○○ に種子をあげる（おなか 20）」「つれあいの○○と なかよくする（赤ちゃん）」。訪問者にも家族が見える（調べると「○○：子ども・子ども・1.2 日（○○の家族）」）。
- **家族パネル**（PC `K`・メニュー「家族」・くらしパネル）：いまの子・つれあい・子ども／きょうだいの行（絵・名前・♀♂・役割・段階・年齢・おなかのバー・形質の札）、［名前］、若者以上の自分の子には［次の世代に］。お産の予定「もうすぐ赤ちゃんが生まれる（あと 8 時間・遊んだ時間で）」、つれあいがいないときは なかよくなり方の説明。「若者を地上へ連れて行く」のチェック。［家系図を見る］［旅立つ］（年寄りで子がいないとき）。
- **世代交代**：確認「○○（若者・1.7 日）が あとをつぎます。巣・倉庫・持ち物・フレンドは そのまま…」→ 見送りの場面（前の子の絵 → 新しい子の絵、「○○ は ご先祖になって、巣の奥でのんびり暮らします。これからは ○○ の番！」）。地上のみんなの画面で名札が変わり、フレンドの一覧・巣の入口の名前も新しい名前に。
- **地上の若者**：3 匹まで足あとをたどってついてくる（ほかの子の画面でも）。捕食者が 150px 以内に来ると「若者たちは 巣へ かくれた」（消える）、いなくなると「もどってきた」。
- **家系図**：大きなパネル。世代ごとの段（つれあいは相手の段）、親から子へ金の線、つれあいの間は赤い線、親せきは点線。札＝額縁（いまの子は明るい金）・その子の姿（毛色・斑・耳・脚・尾・体を描き分け）・♀♂と名前・役割と段階・形質のアイコン（耳・脚・尾・体・毛・斑）。タップした子は青い枠と下の行に「○代目・親 ○○・○○・形質の札」。PC はドラッグ・ホイール、タッチは指で動かす・2 本指でつまんで拡大、右上に［＋］［－］［全体］。横向きのタッチでは右の端のボタンの列をよける。開いている間はトーストを出さない。

## J. 広がり — Ver.0.5「広がり」
- **土地と旅**：画面の左上に土地の名前（はじまりの原・いわばの高台・すなの海・みずおとの谷）。地図の端の出口は土の色が少し明るく、道しるべの矢印と行き先の名前。出口の中へ跳ねると黒く暗転して次の土地へ、着くと土地の名前の札（初めてなら「はじめての土地」）。タッチは出口の近く（4 マス以内）をタップすると そこまで行って旅をする。ミニマップは土地ごと（出口の印つき）。
- **土地の見た目**：岩場＝灰色の岩の尾根と小石。砂丘＝砂の波・さらさら砂（少し明るい）・砂嵐で画面が黄色くかすむ。渓谷＝段差（崖の縁の影）・川（揺れる水面・飛び石）・坂。冬は地面に雪のまだら、雪の日は雪が舞う。
- **世界地図**（PC `N`・メニュー「世界地図」・タッチ「地図」ボタン）：4 つの土地の絵とつながり、いる所に印、行ったことのない土地は霧。富山にたどり着くと、谷の奥から点線でつながる「？？？」が現れる。

## F. スマホ・タブレット（タッチ操作）— Ver.0.2

**いつ出るか**：指で操作する端末（`(pointer: coarse)`）なら自動。タッチパネル付き PC は指で触った時点で切り替わる。メニュー「タッチ操作のボタン」＝自動／いつも出す／出さない、`?touch=1`／`?touch=0` でも指定できる。各画面の「隠す」で畳み、右下の「操作を表示」で戻す。

**画面の大きさ**（`client/touch-logic.js` の `touchLayout`）：
- 内部解像度を画面に合わせて変える（拡大率は整数でなくてよい）。電話の縦向き ≒ 240×330、横向き ≒ 506×234、タブレット横 480×334。メニュー「表示の大きさ」＝自動／大きめ／小さめ（広く見える）。
- 縦向き：ゲーム画面を上（ノッチの下）、操作の帯を下。帯は中身の高さだけ（地上 196px・巣の中 204px・全体モード 118px）で、残りはすべてゲーム画面。タイトルは帯なしで全画面。
- 横向き：ゲーム画面は全画面。左下にスティック、右下に大きなボタン、右の端に小さなボタンを重ねる。ノッチ（safe-area）を避ける。
- 向きを変える・大きさが変わると、すぐに配置しなおす。ページのスクロール・ピンチ拡大・引っぱって更新・長押しメニュー・ダブルタップ拡大は止める。
- 画面キーボード：チャット欄は見えている範囲（visualViewport）の下端に合わせて出す。ログイン・名前入力のパネルはキーボードが出ている間は上に寄せる。入力欄は 16px 以上（iOS の自動拡大を防ぐ）。
