# SCREEN_SPEC — 画面構成と操作仕様

> 状態：**設計案（承認待ち）**。添付イメージ（キャラクター作成／砂漠の共有フィールド／巣の全体画面／巣内を歩く／訪問／繁殖／富山）を見た目の基準にする。

## 共通
- 内部解像度 480×270（16:9）、整数倍に最近傍拡大（1920×1080 なら 4 倍）。UI 文字は内部解像度とは別レイヤーで高解像度に描く（読みやすさ優先）。
- フォント：DotGothic16（OFL）。UI の枠は濃茶の地に明るい縁取り（添付イメージの雰囲気）。
- 色調：夕暮れの砂色・オリーブの草・青い水・茶色の土。巣の中はランタンの橙。
- PC（キーボード＋マウス）とスマホ・タブレット（タッチ）の両方。タッチは「F. スマホ・タブレット（タッチ操作）」。PC の見た目と操作は従来どおり（480×270 の整数倍）。

## A. タイトル・キャラクター作成
1. タイトル：ロゴ、夜の砂漠で跳ねるトビネズミ。「ログイン」「新規登録」。
2. 登録／ログイン：ユーザー名・パスワード。エラーは入力欄の下に短く。
3. キャラクター作成（添付イメージ左上）：大きな立ち絵（左）＋「なまえ」入力＋「毛色を選択」（◀ ▶ で 5 色、選んだ色の小さな見本 3 体）＋［決定］。
4. 確認：「この子で はじめますか？」→ はじめる。

## B. 地上共有フィールド
```
┌────────────────────────────────────── 画面 ─┐
│ [地域名]                           [ミニマップ]│
│                                                │
│        ナッツ        そらとび                  │
│          🐭            🐭                      │
│   リコ                         [吹き出し]      │
│    🐭                                          │
│ [チャットログ 4 行]          ♥ ━━━ (将来:体力) │
│ [ホットバー 8 枠]                               │
└────────────────────────────────────────────────┘
```
- カメラは自分を中心に追従（地図の端では止まる）。
- 名前は頭上（自分は明るい色）。吹き出し 5 秒。
- ミニマップ（右上）：地形と自分の巣の入口、近くのプレイヤーの点。
- 採集物は近づくと縁が光り「E 拾う」。
- 巣穴入口に近づくと「E 巣に入る（○○の巣）」。

| 操作 | キー | 動き |
|---|---|---|
| 移動 | WASD / 方向キー | 小跳躍の連続（約 0.18 秒ごとに 1 跳ね、8 方向） |
| 大ジャンプ | Space | 向いた方向へ約 4 タイル、低木・小石を越える。クールダウン 1.2 秒 |
| 調べる・拾う | E | 最寄りの対象（採集物・入口・他プレイヤー＝名札表示） |
| 持ち物 | I | 8 枠。クリックで詳細、ドラッグで並べ替え |
| チャット | Enter | 入力欄を開く／送信。Esc で閉じる |
| メニュー | Esc | 設定（音量・拡大率）・ログアウト |

## C. 巣の全体モード（地下断面ビルド）
- 添付イメージ「巣の全体画面」：上に地表と空、下に土の断面。左に縦のツールメニュー（掘る／通路／寝床／倉庫／家具／撤去）。
- グリッド 48×24（1 セル 16px）。マウスホイールで拡大縮小、右ドラッグでスクロール。
- 選んだツールの置ける場所は明るく、置けない場所は赤で表示（理由を短く：「岩は掘れない」「部屋が重なる」「素材が足りない」）。
- 部屋の辺にカーソルを置くと拡張ハンドル。
- 下部に素材の数（草・小石・種子）。
- 右下に［歩いてみる（Tab）］。

| 操作 | 入力 |
|---|---|
| ツール選択 | クリック or 数字キー 1〜6 |
| 配置・掘る | 左クリック／左ドラッグ |
| 回転（家具） | R |
| 取り消し（直前 1 手） | Ctrl+Z（サーバーへ逆操作を送る） |
| 閲覧モードへ | Tab |
| 閉じる（巣ビルドを抜ける） | B / Esc |

## D. 巣内閲覧・生活モード
- 添付イメージ「巣内を実際に歩く」：横からの断面。ランタンの明かり、寝床、種の山、棚、出入口。
- 画面下に操作ガイド：［← → 移動］［Space ジャンプ］［E 調べる］［B ビルドモード］。
- 縦通路では ↑↓ で登り降り。斜め通路は ← → だけで上り下り。
- 部屋の名前（寝床・倉庫）を入ったときに小さく表示。
- 訪問者は名前付きで表示、吹き出しで会話（添付イメージ「他プレイヤーの巣を訪問」）。

## E. ダイアログ・通知
- 画面上部中央にトースト（「ナッツ が やってきた」「種子 を 手に入れた」）。
- 切断時は画面全体を少し暗くし「つながりなおしています…」。

## F. スマホ・タブレット（タッチ操作）— Ver.0.2

**いつ出るか**：指で操作する端末（`(pointer: coarse)`）なら自動。タッチパネル付き PC は指で触った時点で切り替わる。メニュー「タッチ操作のボタン」＝自動／いつも出す／出さない、`?touch=1`／`?touch=0` でも指定できる。各画面の「隠す」で畳み、右下の「操作を表示」で戻す。

**画面の大きさ**（`client/touch-logic.js` の `touchLayout`）：
- 内部解像度を画面に合わせて変える（拡大率は整数でなくてよい）。電話の縦向き ≒ 240×330、横向き ≒ 506×234、タブレット横 480×334。メニュー「表示の大きさ」＝自動／大きめ／小さめ（広く見える）。
- 縦向き：ゲーム画面を上（ノッチの下）、操作の帯を下（画面の約 1/3）。タイトルは帯なしで全画面。
- 横向き：ゲーム画面は全画面。左下にスティック、右下に大きなボタン、右の端に小さなボタンを重ねる。ノッチ（safe-area）を避ける。
- 向きを変える・大きさが変わると、すぐに配置しなおす。ページのスクロール・ピンチ拡大・引っぱって更新・長押しメニュー・ダブルタップ拡大は止める。
- 画面キーボード：チャット欄は見えている範囲（visualViewport）の下端に合わせて出す。ログイン・名前入力のパネルはキーボードが出ている間は上に寄せる。入力欄は 16px 以上（iOS の自動拡大を防ぐ）。

| 画面 | 操作 |
|---|---|
| タイトル・ログイン・作成 | ボタンは指の大きさ（高さ 40px 以上）。毛色は ◀ ▶。入力欄に勝手にフォーカスしない（キーボードを勝手に出さない） |
| 地上 | 左：仮想スティック（左側のどこを触ってもそこが中心。8 方向）。右：**ジャンプ**（大ジャンプ）・**調べる**（E）。上の帯：**持ち物**・**チャット**・**メニュー**・隠す。**地面をタップ**＝そこへ跳ねていく、**採集物・巣穴をタップ**＝歩いて行って拾う・入る、ほかのトビネズミをタップ＝そばへ、**自分をタップ**＝調べる。「調べる ○○」の案内やホットバーも押せる |
| 巣：全体モード | 1 本指＝ツール（タップ＝1 マス／1 回、なぞる＝掘り続ける・通路・部屋。家具は押したまま動かして位置を合わせ、離すと置く）。長押し（0.2 秒）でもその場から始まる。**2 本指**＝移動とピンチで拡大縮小（×0.5〜3、離すと ×0.5/0.75/1/1.5/2/3 に寄せる）。部屋ツールでは辺の真ん中に ● のつまみが出て、指の当たりは広め。ボタン：**見回し**（1 本指で移動に切り替え）・**取り消し**・**向き**（家具の反転）・拡大＋・縮小－・**歩く**・持ち物。撤去は確認してから。左のツール欄は指の大きさで、◂ でたためる |
| 巣：歩く | 左：方向パッド（◀ ▶ 移動、▲ ▼ 登る・降りる。入口の縦穴を ▲ で地上へ）。右：**ジャンプ**・**調べる**（眠る・倉庫）。上の帯：**ビルド**（全体モード）・持ち物・チャット・メニュー |
| 持ち物 | 枠をタップで選び、別の枠をタップで入れかえ（ドラッグも可）。枠は 48px 以上 |
| 倉庫 | 「1 つずつ／全部」を切り替えてから枠をタップ（PC の Shift+クリックも可） |
| チャット | ボタンで入力欄とキーボード。**送信**・× ボタン。日本語の変換中の Enter では送らない |

**動き**：UI キャンバスの devicePixelRatio は 2 まで。タブが裏に回るとループを止め、押しっぱなしの指は離したことにする。
