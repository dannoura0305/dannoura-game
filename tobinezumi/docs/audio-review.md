# トビネズミ 音の見直し（2026-11-14）

ジャンル：一匹のトビネズミとして草原と砂漠を跳ね回り、集め、巣を掘って暮らす、のんびりした非競争のドット絵ゲーム。
見る点：のんびり・心地よい・小さな生き物らしい音か／土地・昼夜・季節で空気が変わるか／捕食者の緊張が伝わるが怖すぎないか／長く遊んでも疲れない音量と繰り返しか／BGM。

大きさは LUFS（効果音は 400ms の窓の最大＝一瞬の大きさ、曲・環境音は平均）。合成音は Chromium の OfflineAudioContext で鳴らして ffmpeg で測った（`tobinezumi/tools/sfx_measure.mjs`）。

## 監査の要点（見直す前）

1. **BGM が無かった**。タイトル・野原・巣・行事のどこでも曲が無く、音は効果音と合成の環境音だけ。
2. **効果音の大きさが 38dB もばらばら**だった（いちばん大きい「つかまった」-36、いちばん小さい「着地」-75 LUFS）。着地・掘る・取りのぞく・食べる・旅はほぼ聞こえず、知らせ（生まれた・めずらしい物）だけが目立っていた。
3. **音色が電子音寄り**：危険の予告（！）・つかまった・入口をふさぐが四角波、キツネがのこぎり波。小さな生き物の暮らしの音としては硬く、「つかまった」は低い四角波のブザーで、負けの音のように聞こえた。
4. **環境音は合成のノイズと 1 本の正弦波**（虫は 4200Hz を揺らしただけ）。土地と天気で風・雨・川の強さは変わるが、**昼の生き物の気配（鳥）が無く**、明け方と昼の違いが無かった。季節は虫（夏の夜）だけ。
5. **富山の風**が、コメント（「風が弱く」）と逆に、はじまりの原より強かった（+0.04）。
6. 効果音は毎回まったく同じ高さで鳴り、よく鳴る音（拾う・着地・跳ぶ）の繰り返しが単調。
7. 効果音と環境音が別々の AudioContext を作っていた。効果音の大きさは「鳴らす／鳴らさない」だけ。
8. **合成の虫の声（4200Hz の高い音）が、昼も夜も巣の中でもずっと鳴り続けていた**（ブラウザで層ごとに測って分かった。揺らしの発振器を大きさの段に直接足していたので、大きさ 0 でも -24 dBFS で鳴っていた）。環境音の中でいちばん大きく、長く遊ぶと耳が疲れる原因になっていた。本来の層（風など）は -50 dBFS 台で小さすぎた。
9. よかった点（残す）：捕食者ごとに予告の音が違う（フクロウ＝ほう、キツネ、ヘビ＝しゅー、急降下＝ひゅう）。にげきった時の「ほっ」。巣の中で環境音がこもる。富山の遠い鈴と 4:44 の通りすぎる音（あいまいなまま）。危険の音以外は小さく短い、という方針。

## 大きさの考え方（後）

- 効果音：音ごとの目標（`sound-data.js` の `SFX_TARGET`）。よく鳴る音は -27〜-33、知らせと危険は -22〜-26。いちばん大きい音といちばん小さい音の差は 11dB（前は 38dB）。合成音は測った値から、素材は変換後に測った値から、目標に合わせる（どちらも ±1.5dB 以内）。
- 曲：平均 -22 LUFS の素材を「ふつう」で 0.55 倍（約 -27 LUFS）。効果音より下に敷く。
- 環境音：素材は平均 -30 LUFS。層ごとの大きさ（`ambMix`）に掛け、環境音全体を 3 倍（+9.5dB）にした（虫の音の不具合を直すと、ほかの層が -50 dBFS 台で小さすぎたため）。
- ブラウザ（Chromium）で出口の大きさを測った値（RMS・dBFS、設定はすべて「ふつう」）：

| 場面 | 環境音 | 曲 |
|---|---|---|
| はじまりの原・春の昼（晴れ） | -38.4 | -26.7（Peaceful Days） |
| 春の明け方 | -36.4（鳥がいちばん） | -29.8（Meadow Thoughts） |
| 夏の夜 | -36.5（虫） | -26.9（Innocence） |
| 冬の夜 | -43.7（風だけ・静か） | -32.8 |
| 雨 | -32.9 | -26.2 |
| 砂嵐 | -30.7（風。はじめ -26.7 で大きかったので約 4dB 下げた） | 流さない |
| 狙われている間 | — | 曲が 0.33 倍（-32.8 → -38.5）。終わると 5 秒ほどで戻る |
| 見直す前（参考） | -24（ほとんどが鳴り続ける虫の音の不具合） | 曲なし |
- 全体の出口に軽いリミッター（重なっても割れない）。

## 変えなかった物

- サーバー（`tobinezumi/server`）の挙動・プロトコル。音の鳴るきっかけ（`sfx()` を呼ぶ所）はそのまま。
- 合成音はすべて残した（素材が読めるまで・読めない時のフォールバック）。今までの音の名前もすべて残る。
- 富山の遠い鈴・4:44 の通りすぎる音（あいまいなまま）。
- `sw.js`（`tobinezumi/assets/` は再生時の保存の扱いのまま。先読みには入れていない）。

## 確かめられなかった事

- 耳で聞いての確認はしていない（作業環境に音を聞く手段が無い）。曲は、ページの説明（楽器・雰囲気）と、明るさ・打楽器らしさ・音の立ち上がりの数を測って、穏やかな物を選んだ。聞き比べ用の mp3 を作業用フォルダに作った。
- 巣の曲は、ブラウザで「巣の場面」を渡して切り替わること（子守歌を読み、流す）を確かめた。実際に巣を掘って入る操作での確認はしていない。

## ブラウザでの確認（Playwright・Chromium・オフライン）

- タイトル → キャラクター作成 → 野原まで、音のエラー・読み込みの失敗は 0 件。
- 起動時に読む音のファイルは 0 件。タイトルで最初に触ってから 1.5 秒後に、タイトルの曲だけを読む。野原に入ってからその場面の環境音・曲・効果音（合計 1.8MB ほど）を読む。
- 素材がある効果音（拾う・掘る・着地・飲む・置く・行事）は素材で鳴り、ほかは合成音で鳴る。
