# 万象堂（ばんしょうどう）— 共通の占術エンジンと店の画面

> 公開するのは、だんのうらの町（https://dannoura-town.pages.dev/）の『怪談館』の「占いの間」だけ。
> このリポジトリでは部品のソースと試験を持つだけで、github.io に万象堂のページは出さない（制作者の決定 2026-11-25）。

「万象を読み、万の道を照らす。」

どの作品からでも呼び出せる、占いの部品です。

- 計算（エンジン）、文と表、画面は共通です。
- 作品ごとに変えるのは「店の設定」（`shops/*.js`）だけです。

設計と調査の結果は `docs/banshodo-plan.md` を見てください。

## ファイル

| ファイル | 役割 |
|---|---|
| `vendor/astronomy.browser.min.js` | 天体の位置の計算（astronomy-engine 2.1.19、MIT ライセンス、無料。著作権表示はファイルの先頭にある） |
| `bansho-texts.js` | 占術の表と解釈の文（すべてオリジナルの文）、テーマの語彙 |

| `bansho-ui.js` | 重ね画面 `BanshoUI.open(店の設定, { onClose })` |
| `bansho.css` | 画面の見た目。色と書体は、店の設定で変えられる |
| `shops/kaidan.js` | だんのうらの町『怪談館』の占いコーナー（怪談館出張所・占いの間） |
| `../tests/banshodo-core.test.mjs` | エンジンの試験。`node tests/banshodo-core.test.mjs` で動く |
| `../tools/banshodo_patch_kaidankan.mjs` | 怪談館の html に万象堂を足す道具 |

**まだ出していない占術**：手相、恋愛・相性、仕事運・金運、年齢別運勢。メニューにも出さない（作りかけを見せない決まり）。

## 決めたこと（制作者の回答 2026-11-25）

- **AI による総合鑑定は使わない。** 総合鑑定は、統合エンジンの決まった型の文だけで作る。どの文にも出典（どの占術のどの要素か）を付ける。
- **天体計算のライブラリは入れる。** astronomy-engine を使う。MIT ライセンスで費用はかからない。依存も無い。
- **流派の初期値：日の変わり目は 0 時。**
  - 23 時台は、日柱を当日のままにする。時柱の干は、翌日の子の刻のものにする。
  - 真太陽時の補正はしない（設定で変えられる）。
- **手の写真は本人が選べるようにする**（手相を作るときに使う。下の「次にやること」）。

## 個人情報の扱い

- 入力は「生年月日」以外は任意。呼び名も本名でなくてよい。
- **既定では保存しない。** 「この端末に保存する」に印を付けた人だけ、localStorage に保存する。
  - 保存する鍵は `bansho.profile.v1`、`bansho.book.v1`、`bansho.settings.v1` の 3 つ。
  - 印を付けなければ、ページを閉じると消える。
- 「この端末の万象堂の記録をすべて消す」で、3 つの鍵をすべて消す。
- どこへも送らない。外部のサービス、AI、サーバーは使わない。
- 作品の保存（例：怪談館の `kaidankan_v15_state`）には触れない。

## 作品に入れる方法

```html
<link rel="stylesheet" href="banshodo/bansho.css">
<script src="banshodo/vendor/astronomy.browser.min.js"></script>
<script src="banshodo/bansho-texts.js"></script>
<script src="banshodo/bansho-core.js"></script>
<script src="banshodo/bansho-ui.js"></script>
<script src="banshodo/shops/kaidan.js"></script>   <!-- 店の設定 -->
<script>
  // NPC に話しかけたときなどに
  BanshoUI.open(BANSHO_SHOPS.kaidan, { onClose: function (res) {
    // res.readings … この回の鑑定 / res.todayThemes … 今日のテーマ（例 ['relations']）
    // テーマはイベントを「足す」条件にだけ使う。本筋の分岐には使わない
  } });
</script>
```

### だんのうらの町『怪談館』への入れ方

1. このリポジトリの `banshodo/` フォルダを、町のサイトの `kaidankan_ver1_5_2.html` と同じ場所へ写す。
2. 次のコマンドを実行する。
   ```
   node tools/banshodo_patch_kaidankan.mjs kaidankan_ver1_5_2.html
   ```
   `kaidankan_ver1_5_2.bansho.html` ができる。**元のファイルは書き換えない。**
3. 足されるのは次の 3 か所だけ。
   - `<head>` の CSS 1 行
   - 館内案内の最後に「占いの間」ボタン
   - `</body>` の前の script
4. 中身を確かめてから、元のファイルと置き換える。

試験では、次のことを確かめた（パソコンとスマホの幅の両方。町の公開版を写した物で試した）。

- 館内案内（入館口、展示室、図鑑、館長室）がそのまま動く。
- `kaidankan_v15_state` が変わらない。
- 「展示室へ戻る」と Esc で館内に戻る。

## 新しい占術の足し方

`Bansho.methods.register({ id, name, group, family, needs, compute })` で足す。

- `group`：`east`、`west`、`birth`、`palm` は人の占術で、総合鑑定に入る。`draw` と `today` は「その時の問い」で、総合鑑定に入れない。
- `family`：同じ系統の物（例：星座占いとホロスコープ）は、総合鑑定で一つと数える。
- `needs`：`birth.date`、`birth.time`、`birth.place`、`blood`。足りない人には「出さない」。
- `compute(ctx)` は `{ facts, items:[{h,t}], notes, themes:[{tag, w, src}] }` を返す。
  - `tag` は `bansho-texts.js` の `THEMES` の語彙だけを使う。
  - `src` は「占術・要素」の形にする。
  - 語彙に無いテーマと、出典の無いテーマは、エンジンが捨てる。

## 次にやること

1. **手相**
   - 左右の手の写真を登録する。左右は本人が指定し、直せるようにする。
   - 本人が写真の上の線をなぞって確かめる。確かめた線だけで鑑定する。
   - 左右を比べる。時期の違う写真を比べる。
   - 写真は「保存する／しない」を、生年月日とは別に本人が選ぶ。保存先は端末の中（IndexedDB）だけ。
2. 恋愛・相性：相手の生年月日を入れる。相手の同意の印を付ける。保存はしない。
3. 年齢別運勢と人生年表：四柱推命の大運を使う。
4. 姓名判断、算命学、夢占い。
5. 店員の名前、顔の絵、台詞を正式にする（今は「占い師（仮）」）。
