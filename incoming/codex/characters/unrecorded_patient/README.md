# 記録のない患者／3Dモデル初版

参照：ChatGPT 画像 2026年11月8日 13_37_05.png。
顔のない縦長の頭、横へ傾いた首、片肩が下がった灰青色の病衣、無記入の名札と書類、細く長い指、点滴台を造形しています。

## ファイル
- unrecorded_patient.blend：編集用モデル、リグ、素材、4動作、撮影設備。
- unrecorded_patient.glb：キャラクターと点滴台、リグ、素材、4動作。撮影設備は除外。
- preview.png / three_views.png / details.png：全体・三面図・詳細。
- motions.png：GLB再読み込み後に撮影した動作。
- validation.json：構造・ウェイト・ループなどの検査結果。
- source/：Blender用の再生成スクリプト。

## 仕様
Blenderはメートル単位、Z上方向、正面-Y。GLBはY上方向。
点滴台込みの全高は2.41m。原画に実寸指定がないため仮設定です。
骨34本、頂点211,390、三角形422,364、GLB 22.9 MiB。
色と法線の画像10枚を埋め込んであります。左右の指には各5本の骨があります。
点滴台はpoleボーン、車輪はcaster0〜3で独立しています。キャスターの自動回転や接地処理はありません。

## 動作
30fps、0〜120フレーム。各4秒。
- idle：小さな上体と首の揺れ。
- search_record：書類を抱えながら上体を傾け、空いた手を前へ伸ばす。
- hold_record：書類を抱える姿勢のまま、首と上体をわずかに動かす。
- walk_in_place：足を交互に前後させる、その場での歩行。

.blendのNLAトラックは初期状態でミュートです。再生するときは目的の1トラックだけミュートを解除してください。
ルート移動は含みません。点滴台は同じルートに属しますが、歩行クリップ中はその場にとどまります。
記録を検索するAI、実際の物品取得、経路探索、当たり判定、布やチューブの物理演算は未実装です。
顔は無表情・無顔の固定形状。表情や口パクはありません。原画の机や個体差バリエーションは含みません。

## 確認範囲と残る差
Blender 5.2でGLBを再読み込みし、34本の骨、全頂点のウェイト、埋め込み画像、4動作とループ端点を確認しました。
Cast Engine内の表示や動作、実機パフォーマンスは未検証です。ゲーム用LODや衝突形状は含みません。
原画の繊細な皮膚、複雑に重なる布、頭部と指の造形には差が残る初版です。点滴の透明素材は表示環境によって見え方が変わります。
既存キャラクターとC:\wakabaのプロジェクトは変更していません。
