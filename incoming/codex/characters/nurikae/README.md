# 塗替（ぬりかえ）／巨大ボス・3Dモデル初版

参照：ChatGPT 画像 2026年11月8日 13_37_23.png。
巻きシャッターを重ねた装甲、変圧器と碍子、背面配線、3本の街灯、右腕の5本の電線ループ、左腕の箱型装置と3本の機械爪を造形しました。
原画の「約20m」に合わせ、街灯を含む静止姿勢の全高を20mに設定しています。

## ファイル
- nurikae.blend：モデル、素材、リグ、4動作、撮影設備を含む編集用データ。
- nurikae.glb：モデル、素材、リグ、4動作。撮影設備は含みません。
- preview.png / three_views.png / details.png：全体、三面図、構造の確認画像。
- motions.png：GLB再読み込み後の薙ぎ払い・塗り替えの構え。
- validation.json：骨、ウェイト、発光素材、動作、ループの検査結果。
- source/：再生成用のBlender Pythonスクリプト。

## 仕様
Blenderではメートル単位、Z上方向、正面-Y。GLBは標準のY上方向。
静止全高20.00m、幅15.16m。
骨86本、頂点260,886、三角形518,320、GLB 23.9 MiB。
画像7枚を埋め込み。電線5本には各12本の骨を割り当てています。
シャッターの凹凸、端の折返し、留め具は立体形状です。金属・錆の色と細かな表面法線には画像を使用しています。
街灯と胸部の紫色は発光素材で、GLB内にも保存しています。表示先のブルームや露出によって輝きの見え方は変わります。

## 動作
30fps、0〜120フレーム、各4秒。
- idle：本体と街灯のわずかな揺れ。
- cable_sweep：右腕を横へ伸ばし、電線の輪を大きく広げる薙ぎ払い。
- repaint：足を接地させたまま腰を落とし、上体と街灯を傾ける塗り替えの構え。
- core_pulse：胸部の発光部分がわずかに膨張する脈動。発光強度のアニメーションではありません。

.blendのNLAトラックは初期状態でミュートです。再生する動作1つだけミュートを解除してください。
電線は骨とキーフレームで変形し、薙ぎ払い時には長さ方向のスケールも変化します。物理シミュレーションではありません。
ルート移動、攻撃判定、塗り替えによる地形やマテリアルの変更、AI、効果音、放電エフェクトは含みません。

## 検証と残る差
Blender 5.2でGLBを再読み込みし、86本の骨、全頂点のウェイト、埋め込み画像と発光素材、4動作、ループ端点を検査しました。
静止姿勢から各動作への接続と、主な動作姿勢での手首の接続・接地高さも確認しています。
Cast Engine内の表示と実機性能は未検証です。LODや当たり判定などのゲーム向け調整は未実装です。
原画に比べ、装甲の複雑な巻き重なり、破損や錆の分布、機械内部の密度には差が残る初版です。
既存モデルとC:\wakabaのプロジェクトには変更を加えていません。
