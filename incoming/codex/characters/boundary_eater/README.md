# 境界を喰らうもの／最終ボス・3Dモデル初版

参照：ChatGPT 画像 2026年11月8日 13_39_06.png。
中央の大きな黒い眼、目盛り状の虹彩、上・中・下段に左右1枚ずつ並ぶ6枚の翼、翼の小さな眼、記録の帯が絡み合う胴体と四本の根状の脚を造形しました。
原画に数値の寸法指定がないため、静止姿勢で全高12mを仮設定しています。

## ファイル
- boundary_eater.blend：モデル、素材、リグ、4動作、撮影設備を含む編集用データ。
- boundary_eater.glb：モデル、素材、リグ、4動作。撮影設備は含みません。
- preview.png / three_views.png / details.png：全体、三面図、構造の確認画像。
- motions.png：GLB再読み込み後の薙ぎ払い・喰らう姿勢。
- validation.json：骨、ウェイト、画像、動作、ループの検査結果。
- source/：再生成用のBlender Pythonスクリプト。

## 仕様
Blenderではメートル単位、Z上方向、正面-Y。GLBは標準のY上方向。
全高12.00m、翼を含む幅22.36m。
骨36本、頂点408,350、三角形813,668、GLB 35.1 MiB。
画像8枚を埋め込み。翼は6枚それぞれに3本の骨を割り当てています。
帯の重なりと縁、眼、虹彩の放射状の線は立体形状です。記録の帯の罫線と細かな紙の表面は画像テクスチャです。
翼の表と裏のそれぞれに36個の小さな眼を配置。個々の瞬きは未実装です。
中央の黒い瞳は光沢素材です。内周にはごく弱い紫の発光を設定しており、ブルームは表示先に依存します。

## 動作
30fps、0〜120フレーム、各4秒。ルート移動なし。
- idle：三対の翼がわずかに揺れる待機。
- wing_sweep：胴体をひねり、三対の翼を動かす薙ぎ払い。
- devour：翼を前方へ包み込む構えと瞳の拡大。
- abyss_gaze：中心の眼と瞳のわずかな変化。

.blendのNLAトラックは初期状態でミュートです。再生する動作1つだけミュートを解除してください。
記録の帯は骨による変形です。布や紙の物理シミュレーションではありません。
敵AI、攻撃判定、吸引や捕食のゲーム処理、環境変化、音・粒子エフェクトは含みません。

## 検証と残る差
Blender 5.2でGLBを再読み込みし、全頂点のウェイト、埋め込み画像、4動作、ループ端点、翼の骨の接続と接地高さを検査しました。
原画に比べ、帯の細かなほつれ・破れ、翼の複雑な折れ重なり、眼の周囲の彫り込みには差が残る初版です。
Cast Engine内の表示と実機性能は未検証です。LODとゲーム用当たり判定は未実装です。
既存モデルとC:\wakabaのプロジェクトには変更を加えていません。
