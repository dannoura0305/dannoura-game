# 当直（とうちょく）／中ボス・3Dモデル初版

参照：ChatGPT 画像 2026年11月8日 13_37_36.png。
丸い圧力計の顔と可動する針、暖色の作業灯、紺の作業つなぎ、右腕のモンキーレンチ、左前腕の点検表、3本の背面排気管と赤茶のバルブを造形しました。
原画に寸法の指定はないため、配管と作業灯を含む高さ約2.5mの仮寸法です。

## ファイル
- tochoku.blend：モデル、素材、リグ、4動作、撮影設備を含む編集用データ。
- tochoku.glb：モデル、素材、リグ、4動作。撮影設備は含みません。
- preview.png / three_views.png / details.png：全体、三面図、構造の確認画像。
- motions.png：GLBを再読み込みして撮影した動作姿勢。
- validation.json：検証結果。
- source/：再生成用のBlender Pythonスクリプト。

## 仕様
Blenderではメートル単位、Z上方向、正面-Y。GLBは標準のY上方向。
全高2.485m、骨26本、頂点227,009、三角形450,799、GLB 26.8 MiB。
画像11枚を埋め込み。
目盛り、文字、針、ネジ、レンチのウォームギア、点検表の罫線、配管とバルブは立体形状です。
布の織り、皮膚の細かい凹凸と金属の色むらは画像テクスチャです。
作業灯の発光素材はGLBにも含まれます。ブルームや周囲への照明効果は表示先の設定に依存します。

## 動作
30fps、0〜120フレーム、各4秒。ルート移動なし。
- idle：微かな上体の揺れと計器の振れ。
- patrol：その場での巡回歩行と顔の向きの変化。
- restart：前かがみでレンチの腕を前へ出し、点検表の腕を上げる動作。操作対象の外部バルブは含みません。
- steam_brace：足を広げて腰を落とし、両腕を開く構え。針と背中のバルブも動きます。

.blendのNLAトラックは初期状態でミュートです。再生する動作1つだけミュートを解除してください。
蒸気の粒子・煙シミュレーション、効果音、巡回AI、攻撃判定、外部設備の再起動処理は含みません。

## 検証と残る差
Blender 5.2でGLBを再読み込みし、骨、全頂点のウェイト、埋め込み画像と発光素材、4動作、ループ端点を検査しました。
動作開始時の静止姿勢との一致、代表姿勢の手首の接続と接地高さを確認しています。
原画に比べ、肩から背中の前傾、布の自然な潰れ方、金属の腐食や傷の分布には差が残る初版です。
Cast Engine内での表示・実機性能は未検証です。LODやゲーム用当たり判定は未実装です。
既存のモデルとC:\wakabaのプロジェクトには変更を加えていません。
