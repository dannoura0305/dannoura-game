# 本編とミニゲームの音の見直し（監査・前後・理由）— 2026-11-14

対象：本編『だんのうら』（`game.js` の `AU`・`main/`）と、ミニゲーム 17 本（`minigames/*.js`。`core.js`・`registry.js` は共通部分）。
素材の出典は `docs/AUDIO_CREDITS_MAIN.md`。`assets/bgm/` の 8 曲と `assets/voice/` は**変えていない**（合わないと思う所は最後の「提案」に）。

## 測り方

- 大きさは **Mmax**＝400ms の瞬間ラウドネスの最大（LUFS、ffmpeg ebur128）と **peak**（dBFS）。どれも効果音の音量 = 1 の時。
- 効果音：Playwright（Chromium）で `AudioNode.connect` の行き先を録音用の口に差し替え、`MG.sfxProbe.play(名前)`（`core.js` の `mg.exposeSfx` で各ゲームが出す一覧）で **1 つずつ鳴らして**別々の WAV に録り、測った。本編は `AU.se(名前)` を 1 つずつ。
  「前」は元の版（HEAD）に `exposeSfx` の 1 行だけを足した物で測った。
- 遊んだ時：ボットがキー・ボタンを 25 秒押し続けた録音（最初の 2.5 秒は除く）。ボットは主にメニュー・台詞を押すので、遊びの中の音は一部しか鳴らない（目安）。
- BGM：ffmpeg ebur128 の平均（integrated）。BGM は HTMLAudio なので上の録音には入らない。ゲームの中では約 -33.5 LUFS で鳴る（`0.15 × 設定 × 補正`）。

### 大きさの目標（効果音の音量 = 1）

| 種類 | Mmax |
|---|---|
| 小さく頻繁な音（カーソル・足音・文字送り・刻み） | -38〜-34（文字送りはさらに小さく -45〜-40） |
| ふつうの操作・手応え（決定・命中・置く・取る） | -32〜-28 |
| 大きな出来事（クリア・失敗・レベルアップ・大きな被弾） | -28〜-25 |
| 上限 | -24 より大きくしない・peak は -6dBFS より下 |
| 鳴り続ける環境音・エンジン音 | -40〜-36（BGM の下に敷く） |

## 監査の要点（全体）

1. **鳴るべき所で鳴っていなかった（不具合）**：ローグライク（深夜の工場巡回）とホラー（怪談配信）は、`window.AU` で音が使えるかを判定していた。`AU` は `game.js` の `const` なので `window` に無く、**効果音も環境音も一度も鳴っていなかった**。→ 直し、テストで再発を防ぐ（`tests/audio-main.test.mjs`）。
2. **二重鳴り**：パズル・落ち物・クイズ・カード・会議・防衛・脱出・料理・釣りで、ゲーム自身の合成音と本編の `AU.se` が**同時に鳴って**いた。音色が混ざり、大きさも読めなかった。
3. **小さすぎる・ばらばら**：ミニゲームの音の多くが -45〜-63 LUFS と、BGM（約 -33.5）に埋もれていた。一方で料理の刻む音・ホラーの代わりの `ghost`・脱出の圧縮空気などは -22〜-24 と大きすぎた。本編の効果音も -33〜-52 とばらばら。
4. **ジャンルに合わない**：レース・釣り・料理・ステルス・ローグライクなど、出来事の音の多くが本編の UI の電子音（`decide`・`notif`・`warn`・`tool`）の借り物で、区別も付かなかった。
5. **単調**：繰り返す音（足音・回転・射撃・コイン）が毎回同じ高さ・大きさ。連打を間引かない物もあった。
6. **BGM**：既存の 8 曲は平均の大きさが -13.6〜-16.9 LUFS と 3.3dB ばらばら。ミニゲームは本編の曲の使い回しで、レース・ランナー・防衛・カード・クイズに `stream`（ローファイ）や `factory`（エレクトロ）が付いていた。
7. **音量設定に従わない所**：料理の焼く音・脱出の雨は、始まった時の効果音の音量のままで、後で変えても追従しなかった（料理は 0 にしても鳴り続けた）。
8. **まれな「パチッ」**：Web Audio の GainNode は作った時の音量が 1 で、遅れて始まる音の最初の 1 サンプルが音量 1 のまま出ることがあった（ローグライクの足音で 80 回に 2 回、-3〜0dBFS）。本編と 17 本の音の作り方で、作った直後に .0001 にした。Playwright で全部の音を鳴らし、該当が 0 件になったことを確かめた。

## ミニゲーム（ゲームごと）

数値は Mmax（LUFS）。「→」は前→後。詳しい音ごとの値は作業の記録（scratchpad）にあり、ここでは要点だけ。

### 原付で夜勤へ（race・3D レース）
- 監査：エンジンは速度で音程が上がるだけ（アクセルの開け閉めで変わらない）。雨と合わせて -33〜-35 で、BGM より大きかった。出来事はほぼ本編の借り物（縁石と接触が同じ `tool`、転倒・信号無視・遅刻が同じ `warn`、スリップと雷が同じ `noise`）。3・2・1 は `btn`。ブレーキ・水たまりは無音。
- エンジン：アクセル開度と回転数（上がりは速く、落ちはゆっくり）で鳴らす。鋸波＋矩形波＋サブ→ローパス→開けるほど歪む。吸気ノイズ（開度に比例）・風切り（速さの 2 乗）・雨・減速中のアフターファイア。全開 -36.6、巡航 -38.9、ブレーキ中 -44.7（BGM の下）。
- 一発の音：3・2・1 -37.5 → 880Hz の電子音 -31.2、GO -28.0。縁石「ゴトゴトッ」-30.1・接触（金属のこすれ）-29.1・転倒「ガシャーン」-26.7・スリップ（水はね＋鳴き）-31.1・水たまり（新）-36.5・ブレーキ（新）-36.0・信号無視「ブブー」-28.4・遅刻（時計の鐘）-27.3・打刻（ガチャン＋和音）-27.4・クラクション -25.2 → -31.1（大きすぎた）・ニアミスの風切り -39.2 → -33.3。

### 深夜の買い出しダッシュ（runner）
- 監査：走っているのに足音が無い。ジャンプ -44・着地 -60・スライディング -45 と小さく、被弾 -38.7 も BGM に埋もれていた。
- 足音（新）：左右で音程を変えた足音 -39.0（連続で -35）。ジャンプ -32.9、着地「どすっ」-34.1、スライディング（靴のこすれ）-33.5、飲み物・プリンを取る -29.2/-28.4、被弾・転落 -28.2/-27.3、電車（低い「ゴー」＋ガタンゴトン）-34.2、クリアのファンファーレ -26.2。

### 炎上コメント撃退（shooter）
- 監査：撃つ音は 35ms の矩形波を 1 発おきに鳴らすだけ（-57）で手応えが無い。命中・撃破・弾きが 1 つの間引きを共有していたため、命中の直後の撃破の音が消えていた。
- 撃つ音：破裂ノイズ＋音程の落ちる矩形波＋低い芯、毎発 -39.4（連射で -35）。レーザー・拡散で音を変える。命中「コツッ」-38.1、撃破（弾けて落ちる・コンボで音程が上がる）-42.3 → -32.6、被弾（歪んだ衝撃）-27.8、ボム・ボスの爆発 -24.8/-25.1。間引きは種類ごとに分けた。ボス戦の打楽器のリズム（BGM の音量に従う）はそのまま。

### 荒らしディフェンス（defense・タワーディフェンス）
- 監査：出来事のほとんどで、自前の音と本編の `AU.se` が二重に鳴っていた。ウェーブ開始 -43・ボス -46・勝ち負け -41 と小さく、戦況（心が減った・荒らしが迫った・次のウェーブまで）が音で分からなかった。射撃 -55・命中 -60。
- 後：ウェーブ開始（太鼓 2 発＋号令、ウェーブが進むほど高く）-27.3、ボス（低い金管の警報）-26.2、守り切り（新）-28.5、心が削られた -26.3。新しい音：荒らしが心の手前に来た時の短い警報 -32.9、心が残り 3 以下になった瞬間の警報 -27.6、残りわずかの間の鼓動（残り 3/2/1 で速くなる）-32.6、次のウェーブの 3・2・1 -35.7。射撃 -39.0・命中 -37.1。

### 夜釣りで頭を空っぽに（fishing・癒し系）
- 監査：水の音が小さすぎた（着水 -43、投げる -55、リール -58）。いちばん大事な瞬間に本編の電子音が鳴っていた（アタリ・着水＝`notif`、合わせ＝`decide`、釣れた＝`ach` -23.1 で大きすぎ）。
- 後：投げる「ヒュッ」＋糸の出る音 -34.8、着水（しぶき＋泡）-33.7、つつく -37.4、アタリ（竿鈴「チリン」×2）-29.9、合わせ（重い「グッ」＋しぶき）-30.3、釣り上げ（しぶき＋2〜3 音）-27.5、逃げられた（糸がゆるむ）-33.6、時間帯（遠くの低い鐘）-31.4。波の環境音 -47 → -37.7 と、時々の岸壁の「ちゃぷ」-42.5。電子音はやめ、静けさを残した。

### 深夜の夜食づくり（cooking）
- 監査：刻む・返す・盛るに本編の `tool`/`btn` を重ねていて大きすぎた（peak -5）。完成は `ach`（-23.1）。焼く音は高い所だけで単調、しかも効果音を 0 にしても鳴り続けた。
- 後：刻む（まな板の「トン」＋「サク」）-28.1 → -33.2、返す -32.9、盛る「コト」-32.3、注ぐ「ジュワッ」-32.6、判定（柔らかい自前の音）-31〜-33、一品完成（お皿の「チン」＋和音）-28.8。焼く音は「シャー」＋ゆっくり動く「ジュー」の 2 層 -38.1、焼け具合で油がはぜる「パチッ」が混ざる。音量 0 で止まる。

### 起こさないで家事（stealth）
- 監査：全体に小さすぎた（足音 -57）。失敗の物音（-41〜-46）が小さく、どれだけ音を立てたか耳で分からない。気付かれそうな音は電子音の「ピピッ」。足音が床の種類に関係なく同じ。
- 後：足音を床の種類で変える（畳はこもる・タイルは硬め）、板の間 -34.9・そっと歩くと -44。失敗の物音（きしみ・カチャ・ガラガラ等）を -31〜-33 に揃え「やらかした」が分かる大きさに。気付かれそう＝息をのむ音＋低い不協和 -31.3。家事の小さな音 -35〜-40。

### 怪談配信・実録編（horror）
- 監査：**自前の効果音 17 種と雨・低いうなりの環境音が一度も鳴っていなかった**（`window.AU` の不具合）。直した上で測ると、間の中で聞かせたい小さな音がほとんど聞こえなかった（ささやき -53.6、きしみ -52、足音 -53）。驚かしの音に低音が足りない。
- 後：きしみ -31.0・ささやき -35.4・足音 -36.2、驚かし（38Hz の低音を足す）-29.0、雷 -27.3。環境音（雨・うなり）はいちばん強い段階でも -38.3（BGM の下）。呪いの結末の `ghost` は外し、驚かし＋0.7 秒後のささやきに（間を作る）。

### 閉じ込められた夜勤明け（escape・脱出）
- 監査：本編の音を多く借りて自前の音と重なっていた（拾う＝`tool`、正解＝`decide`、扉＝`ach`、背景の稲光＝`noise`、部屋の移動＝`btn`）。圧縮空気 -22.5・ブレーカー -23.3 と大きすぎた。雨は始まった時の音量のまま追従しない。
- 後：給油「トクトク」-32.6、まちがい（低い電気のブザー）-30.8、部屋の移動（足音 3 歩）-36.4、遠雷 -36.4、ドライバー -34.6、扉 -27.3、圧縮空気 -30.6、ブレーカー -28.2。雨は 1 秒ごとに音量に追従。UI の役目の音（ズーム・選択・ヒント）は本編の音のまま。

### 深夜の工場巡回（rogue・ローグライク）
- 監査：**効果音も環境音も一度も鳴っていなかった**（`window.AU` の不具合）。中身は矩形波の「ピコ」が多くホラーに合わない。文字送りに壁の音を流用。電池・メモ・消灯・影の接近に固有の音が無い。
- 後：コンクリートの足音（左右で音程差）-37.6、息 -38.1、漏電（60Hz のうなり＋火花）-29.6、被弾 -28.2、退散 -28.7、非常口のシャッター（巻き上げ＋鎖）-29.7。新しい音：文字送り -39.0、電池 -31.3、メモ -33.1、懐中電灯が消える -27.6、影が 2 マス以内に来た瞬間 -32.4、遠くの配管（14〜30 秒ごと）-37.0。心音（2 拍を同じ時刻表で）-35.1、環境音 -38.0。

### 夜勤の第三工場（factory3d・3D）
- 監査：影の出現音が**音割れ**（-13.8 LUFS・peak 0dBFS。開始を遅らせた音の音量の初期値が 1 のままだった）。環境音（雨・発電機）が常時 -31 で BGM より大きく、足音・しずくが埋もれていた。

## 音量の設定に従うこと

- 本編：BGM は `bgmVol()`（設定×補正）。設定を変えると今の曲に追従、0 で無音（Playwright で確認）。曲が読めない時の代わりの合成音も、鳴り始めの 2 秒の間に設定を変えるとフェードに上書きされていたのを直した。効果音は `AUDIO_SET.se` を掛け、0 なら何も作らない（テストと Playwright で確認）。ボイスは変えていない。
- ミニゲーム：17 本とも鳴らす度に `AUDIO_SET.se` を読む（テストで確認）。鳴り続ける音のうち、レースのエンジン・釣りの波・料理の焼く音・脱出の雨・ホラーの雨とうなり・ローグライクと 3D 工場の環境音は、プレイ中に音量を変えても追従し、0 で無音になる。ステルスの水の音だけは、蛇口を開け閉めした時の音量を使う（流れている間に変えた分は次の開け閉めから）。どれも終わる時に止まる。

## 確かめられなかった事

- **耳で聴いた確認はしていない**（数値と波形の解析だけ）。実機（iPhone・Android）のスピーカーでの聞こえ方、特に高いクリック（2〜5kHz）と低音（40〜60Hz）。
- BGM と効果音を一緒に鳴らした時の聞こえ方（BGM は HTMLAudio なので録音に入らない。大きさの関係は数値で合わせただけ）。
- ボットは主にメニューと台詞を押すので、次の音はプレイ中に鳴った所を録れていない（1 つずつ鳴らした計測では確認済み）：レースのブレーキの鳴き・アフターファイア、防衛の接近・危険・鼓動・秒読み、ランナーの足音、レースのエンジンが全開まで回った状態。
- 3D の 2 本（race・factory3d）は描画の負荷で録音が抜けることがあり、描画を止めて測った。
- 効果音の大きさは 400ms の窓で測るので、20〜30ms のごく短いクリックは聞こえ方より小さく出る。ノイズの切り出しがランダムな音は測る度に ±3dB くらい変わる。
- GitHub Pages 上での動作（`sw.js` は変えていないので、新しい曲は通信で読み、保存分の扱いは今までの `assets/*.mp3` と同じ規則）。
