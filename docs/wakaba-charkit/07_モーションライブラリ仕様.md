# 07 モーションライブラリ仕様

全作品で使い回すモーションの台帳。**mapkit の素材メタデータ（`docs/wakaba-mapkit/07` §3・`asset-meta.schema.json`）を拡張する**（別の形を作らない＝fork しない）。
すべて【提案】。

---

## 1. mapkit のスキーマへの追加（v1 → v1.1 の案）
mapkit の `asset-meta.schema.json` は変えずに読める形で、次の 3 つを足すよう mapkit のフェーズ 1 で相談する：
1. `category` の列挙に **`animation`**・**`motion_source`**（撮影した動画などの元）・**`shader_preset`** を足す。
2. `source.type` に **`self_capture`**（自分で撮影してAIで変換）・**`hand_keyed`**（手付け）を足す。
3. `license` に **`performerConsent`**（演者の同意の記録の参照）と **`deps`**（通した模型・道具の制限：例 `smpl-x`）を足す。

charkit 側は `allOf` で mapkit のスキーマを参照し、`anim` の欄だけを足す（§3）。

**フェーズ 1 で実装（2026-10-17）**：上の 3 つを mapkit の `mapkit/schema/asset-meta.schema.json`（v1.1）に入れた。`deps` の各要素は文字列か `{ id, licensed, terms }`。研究用（非商用）の AI の判断のため `source.aiCommercial`（yes/no/unknown）も足した。§3 のスキーマは `charkit/schema/anim-meta.schema.json`、§4 の規則は mapkit の `mapkit/assets/gate.js`（門は 1 つ）、§5 の照合は `charkit/anim/combatfit.js`・`tools/charkit/validate_anim.mjs`。§7 の 3 つの例は `tests/fixtures/wakaba/anim/` に置いた（作り物の例なので目録には入れない）。

## 2. 名前の規則
`<組>_<動き>[_<向き・段>][_<変種>]`（小文字・`_`）。id は mapkit の形（`<category>.<…>`）に合わせて **`anim.<名前>`**。

| 組 | 中身 | 例 |
|---|---|---|
| `idle` | 立ち・呼吸・待機の小さな動き | `idle_stand`・`idle_breath_tense`・`idle_look_around` |
| `loco` | 歩き・走り・ダッシュ・横・後ろ・止まり・曲がり・しゃがみ移動 | `loco_walk_fwd`・`loco_run_fwd`・`loco_walk_strafe_L`・`loco_walk_back`・`loco_run_stop_L`・`loco_walk_turn_180_R`・`loco_crouch_fwd` |
| `trav` | 地形：跳ぶ・着地・階段・坂・乗り越え | `trav_jump_start`・`trav_land_soft`・`trav_land_hard`・`trav_stairs_up`・`trav_vault_low` |
| `int` | 扉・座る・つかむ・拾う・押す | `int_door_slide_open_R`・`int_sit_down_edge`・`int_pickup_low` |
| `cmb` | 戦闘（武器ごと） | `cmb_katana_draw`・`cmb_katana_light_1`・`cmb_katana_heavy`・`cmb_dodge_roll_F`・`cmb_guard`・`cmb_handgun_aim` |
| `react` | 被弾・吹き飛び・ダウン・起き上がり | `react_hit_front_light`・`react_knockback`・`react_down_back`・`react_getup_back` |
| `gest` | 会話の手・うなずき | `gest_talk_explain_1`・`gest_nod_small`・`gest_shrug` |
| `face` | 表情の動き（表情の重みの曲線） | `face_surprise_short` |
| `cin` | ムービー専用（作品専用になりやすい） | `cin_shinshoku_ch1_open` |

左右の対（`_L`・`_R`）は**鏡写しで作れる物は 1 本だけ持ち**、`anim.mirrorable: true` で実行時に反転（容量を減らす）。

### 3.1 品質の点数
- `auto`（0〜100）＝ 100 から減点：足の滑り（平均 cm/s × 6）・継ぎ目のはね（度 × 1）・めり込み（cm × 5）・ループの継ぎ目のずれ（度 × 2）・ふるえ（加加速度の外れ値の割合 × 50）。上限・下限は 0〜100。式は `tools/charkit/metrics.mjs` に置き、**版を `quality.metrics.formulaVer` に残す**。
- `human`（1〜5）は人が動画を見て付ける。**AI は付けない**（空なら `null`）。
- `score` ＝ `human` があれば `0.4 × auto + 0.6 × (human × 20)`、無ければ `auto`。**`human` が空のモーションは作品の本番に入れない**（G5）。

## 4. 権利の門（mapkit のライセンス門に足す規則）
| 条件 | 結果 |
|---|---|
| `source.type` が `self_capture` で `license.performerConsent` が空 | **止める** |
| `motion_source` の動画が他人の映像（`source.type: unknown`／映像の出典の URL が他人のサイト） | **止める**（作品に使わない） |
| `license.deps` に `smpl` `smpl-x` などがあり、商用の許可（`deps[].licensed: true`）が無く、作品が商用か未定 | **止める** |
| 研究用（非商用）の AI を通した（`source.aiModel` の規約が非商用） | **作品に入れない**（比較用の印 `use: ["比較のみ"]`） |
| Mixamo・Fab など「素のファイルの再配布は不可」の物を Web の書き出しに入れる | **止める**（UE の PC 版だけ可・要確認） |
| `quality.human` が空 | 作品の本番の束（`pack`）に入れない |

## 5. 戦闘モーションの検査（こまの合わせ）
- `combatRef` が `shinshoku/data/combat.js` の `katana.light[0]` を指す時、`events` の `hitStart` のこまが `startup`、`hitEnd` が `startup + active`、全体の長さが `startup + active + recovery`（60fps のこま）と**合っているか**を検査する。
- 合わない時は**モーションの方を区間ごとに伸縮**して合わせる（遊びの数字は変えない）。伸縮の倍率が 0.6〜1.6 を外れたら「作り直し」の印を出す（見た目が崩れるため）。

## 6. 配り方（Web）
- 1 本ずつ `.vrma`、または束ごとに `.glb`（骨だけ・網なし）。**最初に読むのは `idle`・`loco` の基本の束だけ**（起動を遅くしない）、戦闘・地形・会話は必要になった時に読む。
- 束の大きさの目安：基本の束 1MB 以下（gzip 後）。回転の値を量子化（`@gltf-transform` の量子化・未検証）で減らす。
