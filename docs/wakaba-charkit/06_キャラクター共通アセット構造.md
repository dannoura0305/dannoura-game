# 06 キャラクター共通アセット構造

フォルダの置き方・標準骨格・名前の規則・キャラクターごとの設定（陰影の値・性格の値）の JSON スキーマと、だんのうらの例。
**すべて【提案】**（実装はフェーズ 1 以降・利用者の承認の後）。mapkit `07` §1〜§3 と同じ考え方（原本は Git に入れない・軽い書き出しと目録だけ Git）。

---

## 2. 単位・向き
| 項目 | 規則 |
|---|---|
| 単位 | m（glTF・VRM）。UE は cm（FBX の書き出しで変換） |
| 上 | Y（glTF・VRM・Three.js）／Z（Blender・UE） |
| 前 | **+Z**（VRM 1.0・境界侵食と同じ）。VRM 0 は読み込み時に回す（今の `vrm.js`） |
| 休みの姿勢 | **T ポーズ**（VRM 1.0 の標準） |
| 原点 | 両足の間の床 |
| 時間 | 動きは 30fps または 60fps で作る。戦闘は 60fps（`data/combat.js` が 60Hz） |

## 3. 標準骨格「wakaba-humanoid/1」
- **本体＝VRM 1.0 の humanoid の骨**。必須：`hips spine chest neck head` と左右の `UpperArm LowerArm Hand UpperLeg LowerLeg Foot`（＝今の 17 本）。
- **推奨（本基盤では必須にする）**：`upperChest`・左右の `Shoulder`・`Toes`・`Eye`・`jaw`・**指 15 本×2**（`Thumb Metacarpal/Proximal/Distal`・`Index/Middle/Ring/Little` の `Proximal/Intermediate/Distal`）。
- **追加の骨（`ext_`）**：VRM の humanoid の外。名前は `ext_<組>_<部位>[_<L|R>]_<番号2桁>`。

| 組 | 例 | 親 | 動かし方 |
|---|---|---|---|
| hair | `ext_hair_ponytail_01〜05`・`ext_hair_side_R_01〜03`・`ext_hair_bang_01〜03` | head | SpringBone |
| cloth | `ext_cloth_hood_01〜02`・`ext_cloth_jacketTail_L_01〜03`・`ext_cloth_skirt_F_01〜03`（服による） | chest・hips | SpringBone＋体の当たり |
| acc | `ext_acc_hat`・`ext_acc_flower`・`ext_acc_glasses`・`ext_acc_backpack`・`ext_acc_charm_01〜02` | head・chest | 固定 or SpringBone |
| tail／ear（化け猫） | `ext_tail_01〜08`・`ext_ear_L_01〜02`・`ext_ear_R_01〜02` | hips・head | SpringBone＋手続き（耳のぴくっ・尾の振り） |
| socket（持たせる位置） | `socket_hand_R`・`socket_hand_L`・`socket_back`・`socket_hip_L` | 手・胸・腰 | 武器・拾った物を付ける |
| weapon | `ext_weapon_sheath`（鞘） | socket_back | 固定 |

- 骨の数の上限：本体 55 本前後＋`ext_` は 主人公 60 本まで（`10` の段で揺らす本数を減らす）。
- 対応表（VRM ⇔ UE ⇔ Mixamo ⇔ Rigify ⇔ 今の 17 本）は `04` §3。

## 4. 名前の規則
| 物 | 規則 | 例 |
|---|---|---|
| キャラクターの id | 小文字・英数字・`_` | `dannoura`・`dannoura_white`・`companion` |
| 材質（陰影の種類を名前で決める） | `skin`・`face`・`eye_iris`・`eye_white`・`eye_hl`・`brow`・`mouth`・`hair`・`cloth_<部位>`・`metal_<部位>`・`acc_<部位>`・`glass_<部位>` | `cloth_jacket`・`metal_glasses_frame`・`glass_lens` |
| 表情 | VRM の標準（`happy angry sad relaxed surprised aa ih ou ee oh blink blinkLeft blinkRight lookUp lookDown lookLeft lookRight neutral`）＋独自 `x_<名前>` | `x_smug`・`x_wince`・`x_determined`・`x_tired`・`x_scared`・`x_catEyes` |
| 補正の形 | `cor_<骨>_<軸><符号><角度>` | `cor_leftLowerArm_x+140`・`cor_leftUpperLeg_x-90` |
| テクスチャ | `<id>_<材質>_<種類>.png`（種類：`base`・`shade`・`sdf`・`hl`・`mask`） | `dannoura_face_sdf.png` |
| モーション | `07` §2 | `loco_walk_fwd`・`cmb_katana_light_1` |

## 6. 性格の値の意味（動きのどこに効くか）
| 値 | 効く所 | 実装（`14` §4） |
|---|---|---|
| walkSpeed・runSpeed・dashSpeed | 速さの表・ブレンドスペースの軸 | 移動の目標の速さ |
| strideScale・cadenceScale | 同じ速さでの歩幅と足の運び（歩幅 × 運び＝速さ） | 再生の速さとクリップの伸縮 |
| comHeightOffsetM・comBob | 腰の高さ・上下の揺れ | hips の y に足す・揺れの倍率 |
| armSwing・hipSway | 腕の振り・腰の左右 | クリップの上に足す層（追加の回転） |
| accelS・decelS・turnInPlaceDeg | 歩き出し・止まり・その場の回転 | 状態機械の切り替えの時間 |
| footForce | 着地の重さ | 着地の時の腰の沈み・足音の大きさ |
| spinePitchDeg・shoulderRollDeg・headTiltDeg・stanceWidth | 姿勢 | 追加の層（背骨・肩・頭）・立ちの足幅 |
| gesture.* | 会話・待機の手の動きの量・手首のしなり | 会話の手の動きのクリップの重み・手首の追加回転 |
| reaction.* | 被弾・物音への反応の速さ・驚き方 | 反応のクリップの開始の遅れ・強さ |
| face.* | 表情の強さ・瞬き・視線の動き | 表情の重みの倍率・瞬きの間隔・首と目の配分 |
| states.tension／fatigue／fear | 緊張・疲れ・恐れ（0〜1 の値をゲームが与える） | 上の値に倍率を掛ける（例：恐れで腰が低く・速さが上がる・瞬きが増える） |
