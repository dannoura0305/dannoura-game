# 15 ユーザー確認チェックリスト（キャラクター基盤）

**マップ基盤のチェックリスト（`docs/wakaba-mapkit/09_ユーザー確認チェックリスト.md`）の続き**です。PC・UE・Blender・n8n などの共通の質問は mapkit の方に答えてもらえば、ここで重ねて答える必要はありません。
**★（先に必要）** だけで次に進めます。わからない所は「わからない」で大丈夫です。答えはそのまま（コピーで）返してください。

## 0. 一番かんたんな方法（任意）
2 つのスクリプトを利用者の Windows で実行すると、PC・ソフトの有無をまとめて JSON にします（**どちらも読むだけ**：インストール・書き換え・ネットへの接続をしない）。
1. mapkit の `docs/wakaba-mapkit/tools/survey_local.ps1`（PC・GPU・ディスク・UE・Blender・Gaea・開発ツール）
2. 本基盤の `docs/wakaba-charkit/tools/survey_local_char.ps1`（VRoid Studio・Blender の VRM アドオン・Cascadeur・Rokoko・カメラ・マイク・VRM などのファイルの数）
```
powershell -ExecutionPolicy Bypass -File .\survey_local.ps1 -Redact -OutFile .\survey.json
powershell -ExecutionPolicy Bypass -File .\survey_local_char.ps1 -Redact -OutFile .\survey_char.json -SearchPaths "D:\Models","$env:USERPROFILE\Documents"
```
- `-SearchPaths` に書いた場所だけで `.vrm` `.vroid` `.blend` `.fbx` `.bvh` `.vrma` `.moc3`（Live2D）を数えます（ファイルの中身は読みません。名前は最大 30 件）。
- `-Redact` でユーザー名を隠します。**共有する前に中身を確認**してください。
- **Windows で一度も動かしていません（未検証）**。エラーの文字はそのまま教えてください。
