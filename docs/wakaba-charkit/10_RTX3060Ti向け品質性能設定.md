# 10 RTX 3060 Ti 向け 品質・性能設定（と Web・スマホの段）

基準の機械：**Core i7-9700（8 コア 8 スレッド）／RTX 3060 Ti（VRAM 8GB）／メモリ 16GB／SSD 512GB**（申告値・未実測）。
数値は**目標**で、実機で測って直す（`12` フェーズ 2・3 の受け入れ条件に「実機で 1 回測る」を入れる）。mapkit `07` §6 の段（`ultra/high/mid/low`）に**キャラクターの欄を足す**形にする（別の段を作らない）。

## 1. Three.js（方式 A）のキャラクターの予算

| 項目 | ultra（3060 Ti・1080p） | high（今の PC の段） | mid | low（スマホ） |
|---|---|---|---|---|
| 主人公の三角形（LOD0） | 5 万 | 4 万 | 3 万 | **2 万**（LOD1） |
| 仲間・目立つ敵 | 3 万 | 2.5 万 | 2 万 | 1 万 |
| 主人公の描画呼び出し（本体・顔・髪・目・輪郭線） | ≤ 8 | ≤ 6 | ≤ 5 | **≤ 3**（今の基準と同じ） |
| 材質の数 | ≤ 6（地図帳にまとめる） | ≤ 5 | ≤ 4 | ≤ 2 |
| テクスチャ（主人公の合計） | 2048 × 3 枚（KTX2） | 2048 × 2 | 1024 × 2 | 512〜1024 × 1 |
| 主人公の GPU のテクスチャの量 | ≤ 48MB | ≤ 32MB | ≤ 16MB | ≤ 8MB |
| 骨（本体＋揺れ物） | 本体 55＋揺れ 60 | 55＋40 | 55＋24 | 本体 17〜25＋揺れ 12 |
| 揺れ物の計算（SpringBone） | 全部・60Hz | 全部 | 主人公だけ | 主人公の髪の主な鎖だけ・30Hz |
| 補正の形（モーフ） | 全部 | 全部 | 肩・ひじだけ | なし |
| 表情（モーフの数） | 全部 | 全部 | 全部 | 口・瞬きだけ |
| 顔影 | SDF | SDF | SDF | 平ら（影なし） |
| 輪郭線 | 殻＋（任意）内側の線の後処理 | 殻 | 殻（近くだけ） | 殻（`outlineDist` 7m・今のまま） |
| 影 | キャラクターも 2048 の影の地図 | 1024 | 512 | なし（足元の丸い影） |
| 足の IK・地形 | 両足＋腰・手の IK | 両足＋腰 | 両足 | 腰の高さだけ |
| 同時に出す人型 | 12 | 10 | 8 | 6 |
| 目標 fps | 60（最低 45） | 60 | 30〜60 | 30 |

- **主人公 1 体の CPU の時間の目安**：混ぜる係＋IK＋SpringBone＋表情で **1 フレーム 1.0ms 以下**（3060 Ti の PC の CPU）／スマホ 2.5ms 以下。`?perf=1` に「キャラクターの時間」の欄を足して測る（`14` §5）。
- VRoid の素のモデルは材質が 10 を超えることがある → 書き出しの「材質をまとめる」と、Blender での地図帳のまとめで減らす（`03` §2.3）。
- スマホで重い時は、**コード製の今のキャラクター（描画 3 回）に戻す**選択肢を残す（DECISIONS：スマホは方向性を変えてよい）。

## 3. UE5（方式 B／C の試しの時）の出発点（**未検証**）
| 項目 | 設定の案 | 理由 |
|---|---|---|
| キャラクターの網 | 5〜8 万三角形・LOD 3 段 | 8GB の VRAM と他の背景との取り合い |
| 骨の更新 | 画面外は更新しない・遠い者は更新の頻度を下げる（URO） | CPU（8 スレッド）の節約 |
| Motion Matching | データベースは最初 5〜10 分の動き。探索の間隔は既定 | 大きいとメモリと探索の時間が増える |
| Chaos Cloth | 主人公の上着の裾だけ・LOD で切る | 布は重い |
| 影 | Virtual Shadow Maps（mapkit `07` §6.2） | – |
| トゥーン | ポストプロセスか材質のどちらか（試しで決める） | – |
| エディタ | **メモリ 16GB では Blender・ブラウザを閉じる**。シェーダーのコンパイルは長い | mapkit `08` §8 |

## 4. 制作の PC の注意（16GB・512GB）
- Blender で 5 万三角形のキャラクター＋補正の形の作業は 16GB で足りる見込み。**画像 → 3D の AI（8GB を超える物）は動かない**（`02` §1）。
- 撮影の動画（60fps・1080p）は 1 分で数百 MB。**撮った動画は外付け SSD か NAS へ**（mapkit `07` §9）。
- FreeMoCap・MediaPipe は CPU で動くとされる（GPU は他の作業に使える）。
- 夜間の重い処理（書き出し・こま撮りの動画）は**1 つずつ**（`08` §2.1）。
