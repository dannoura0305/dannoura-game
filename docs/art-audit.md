# 画風の監査表（フェーズ3 §2）

対象は本編・家/庭・ミニゲーム17本。各シーンについて、だんのうら・娘・猫・敵・アイテム・背景の描き方と、正典やスタイルガイドとの違いを記録した。
基準は docs/asset-style-guide.md（外周線 `#1b1226`・左上光源・パレット）と、キャラクターの正典。

**正典（だんのうら）**：紫の髪、めがね（濃い紫 `#2a1c36` の枠）、ピンクの花の髪飾り、ピンクの小さなシルクハット、ラベンダーの上着とピンクのシャツ。
疲れ切ったとき（家の部屋では「疲労75以上 または 精神25以下」）だけ、白い髪・猫耳・マゼンタのパーカーの姿に変わる。この変身は設定どおりなので、そのまま残す。

**正典（娘）**：4歳。紫がかった黒のあご下のおかっぱ、まっすぐな前髪、ピンクの花で結んだ小さなふたつ結び、大きな紫の目。
家ではミントのパジャマに黄色い星、外では黄色い帽子・水色のスモック・黄色の長靴。クマは左耳（画面の右）がほつれている。

**正典（猫）**：三毛猫。白地に茶と黒のぶち、黄緑の目、ピンクの耳（`HOME_ART.drawChar('cat')`）。

**描き方の略号**：ドット＝原寸ドット絵／ベクター＝Canvas のパス描画／3D＝three.js のローポリ／画像＝`assets/img` の webp・svg／影＝シルエット。

**重大度**
- 高：主人公・娘・猫の見た目が正典と違う。
- 中：目印（めがね・髪飾り・髪色）が欠けている。
- 低：外周線の色、光源、小物のずれ。
- －：問題なし。

## 重大度別のまとめ

- **高（2件・修正済み）**
  - stealth：猫が三毛ではなかった。
  - race：ふだんの日もライダーが変身後の姿だった。
- **中（2件・修正済み）**
  - rogue：髪飾りがなかった。
  - runner：めがねの枠がなかった。
- **低（5件・すべて修正済み）**
  - cooking・escape・horror・rpg の外周線。
  - manager の外周線とシルクハット（追記で対応）。

## 残したもの

- **factory3d**：一人称で、手や袖を描いていない。手を足すのは「大幅な作り直し」にあたるので、見送った。
- **影・シルエット**（horror の人影など）：塗り一色の表現なので、外周線と光源の決まりは当てはめない。

## 追記：manager の外周線とシルクハット（対応済み）

- 22×24 の絵を、左右に1ドット・上に6ドット（帽子5段＋外周線1段）広げた 24×30 のキャンバスに描き、外周線 `#1b1226` を不透明ドットの上下左右の空きに付けた。胸像の下端（切り口）には付けない。
- 描く側は `drawSpr(c, spr, x, y, S)` で、広げたぶん（左1・上6）を差し引いた位置に置く。体・顔の位置と大きさは前と同じで、帽子だけが上にはみ出す。タイトル画面・配信中（ひとり・コラボ）・常連のアイコンの代わり絵（`portrait`）のどれも位置がずれないことを、スマホ 390×780・PC 1280×800 の撮影で確かめた。配信画面では帽子の上端もモニター枠の内側に収まる。
- だんのうらの帽子は正典（`assets/img/char_normal.webp`）どおり頭の左上。髪飾りは右側の5枚花びらのピンクの花。ミドリは帽子なし（外周線だけ）。常連（`fan`）は帽子を付けない。
