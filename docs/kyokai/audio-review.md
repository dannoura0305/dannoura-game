# 境界事象：効果音と BGM の見直し（2026-11）

対象：`kyokai/music.js`（KY_BGM）・`kyokai/engine.js`（効果音 SE・環境音 AMB・文字送り）・`kyokai/battle.js`（戦闘の効果音・曲・鳴き声）。
音声ファイルは前も後も使っていない。すべて Web Audio の合成（ゲームボーイ風のパルス波 2・三角波・ノイズ）で、4 色のドット絵と同じ「GB の制約の中で作る」方針のまま。

## 1. 監査：場面ごとに鳴っている音（変更前）

### 観点ごとのまとめ

- **4 色のレトロな見た目に合うか**：合っている。全部が GB の 4 音の合成で、音声ファイルを足す必要は無い（素材は使わない判断。§6）。
- **A→B→C で不穏さが深まるか**：町の曲は深まる（短調 → 昭和のワルツ → まばら → 混ざる）。ただし戦闘曲は世界によらず同じだった。
- **戦闘の手応え**：ドラム（ノイズ）が無く、当たりの音の強さがばらばら。
- **会話の文字送り**：全員同じ音。
- **音量のばらつき**：歩く曲の間で 2.7 LU、効果音では static が突出、UI の音が小さすぎ、戦闘曲は BGM 設定を無視。
- **単調な繰り返し**：町 19 秒・分室 22 秒・昭和 11 秒・戦闘 3 秒でループ。

## 2. 変えた物（前 → 後 → 理由）

### BGM（music.js）

| 曲 | 前 | 後 | 理由 |
|---|---|---|---|
| town（町 A） | 8 小節・19 秒 | 16 小節・38 秒。後半は F→G→Em…と少し明るむ 8 小節。のばす音に段々のビブラート | 単調さ。前半の旋律はそのまま |
| office（分室） | 8 小節・22 秒 | 16 小節・44 秒。後半は Am→Em→F… | 単調さ |
| showa（世界 B） | 8 小節・11 秒・−41.3 LUFS | 16 小節・22 秒・−39.0 LUFS。ビブラートを強め（古いレコードの揺れ） | 単調さ・音量 |
| deep（地下） | −40.4 LUFS | −39.3 LUFS。旋律の山びこ（3 歩遅れ）とまれな水滴の音 | 音量・冷たい空間の広がり |
| empty（世界 C） | まばら | 山びこ（5 歩遅れ）と大きめの揺れを足した。音量は据え置き（−40 LUFS） | 誰もいない町の反響。静けさは保つ |
| rift（X） | — | 変更なし | 十分に不安 |
| **title**（新） | 無し | D の短調、まばらな旋律＋山びこ。電線のうなりと遠い汽笛の上に小さく（−40 LUFS） | タイトルに曲が無かった。解決しない終わり方で静かな不穏さ |
| **roll**（新） | 無し（スタッフロール中ほぼ無音） | F の長調、16 小節・46 秒。観測を終えたあとの少しだけ明るい曲 | エンディング後の余韻。台詞・物語・結末は変えていない |
| **bt_wild**（戦闘・新） | battle.js の 16 歩ループ（2 音） | E の短調 8 小節・12 秒。三角波ベース・和音・キック／スネア／ハイハット | 手応え・単調さ |
| **bt_wild_c**（新） | 無し | 崩壊 C・混ざる世界 X の戦闘。半音でずれていく不安定な曲 | 戦闘でも A→C で不穏さが深まるように |
| **bt_boss**（新） | 16 歩（2.7 秒） | 16 小節・22 秒。前半 E フリギアで重く、後半で追い上げる | 単調さ・ボスらしさ |
| **bt_win / bt_win_boss**（新） | 2 音の短いジングル | ドラム付きの 1 回だけのジングル（自分で止まる） | 手応え |

- **戦闘曲を KY_BGM に移した**：`KY_BATTLE.music()` は `KY_BGM.force(曲)` を呼ぶ。**設定の「BGM」音量に従う**ようになった（0 で消える）。KY_BGM が無いとき（単体テスト）だけ古いループで鳴らす（古いコードは残した）。
- 鳴る場面：タイトル（`D.titleOn`）・スタッフロール（`D.rollOn`）・歩く地図・戦闘。会話の一枚絵では従来どおり止める。
- 設定画面の BGM の説明文を「タイトル・町や建物の中を歩いているあいだ・戦闘・スタッフロールで流れます」に更新。
- 新しい音色：旋律の山びこ（echo：12.5% パルスで遅らせて弱く）、キック（三角波の音程が急に下がる＋低いノイズ）、のばした音の段々ビブラート（1/24 秒ごと。GB の音源らしく）。
- 存在安定度が低いときの旋律の揺れは、戦闘曲にはかけない（戦闘中のリズムが崩れないように）。

## 4. 守ったこと

- 実ファイル操作は無し（§41）。台詞・物語・結末は変えていない（設定画面の BGM の説明文だけ更新）。伏せる決まりの人物名は、新しい表示・文書のどこにも出していない。
- 起動時の読み込みは増やしていない（ファイル・素材の追加なし。曲はデータの文字列）。
- `sw.js` には触れていない。他のゲームのセーブは読まない。

## 5. 確かめられなかった事

- 実機のスピーカー／イヤホンでの聞こえ方（この環境に音の出口が無い。書き出した mp3 の数値と波形で判断）。
- iOS Safari での AudioContext の再開（既存の仕組みのまま）。
- 世界 B・C・X での戦闘を実際の進行で通すこと（曲の選び方はテストと関数呼び出しで確認）。

## 6. 素材について

外部の音声素材は使っていない（`docs/kyokai/AUDIO_CREDITS.md`）。4 色のドット絵に合わせ、すべて合成で作る方がまとまりが良いと判断した。
