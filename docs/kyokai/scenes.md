# 境界事象：場面と注目物の座標（`kyokai/art.js` / `window.KY_ART`）

場面・顔・アイコンはすべてキャンバスのコード描画（生成画像ではない）。生成画像に差し替えるときは `assets/kyokai/manifest.json` の `file` を埋める（手順とプロンプトは `docs/kyokai/art-requests.md`）。

## 使い方（エンジン担当向け）
- `KY_ART.draw(ctx, sceneId, world, t, opts)`：`ctx.canvas` いっぱいに描く。原寸 320×180 ドットを最近傍で拡大し、看板の文字だけ拡大後の解像度で描く。毎フレーム呼んでよい（1 回 1ms 未満）。
  - `world`：`'A'`（通常）/ `'B'`（別の歴史）/ `'C'`（崩壊・無人）。その場面に無い世界は「最初の世界＋薄い色かぶせ」で描く（エラーにしない）。
  - `t`：秒。雨・灯りのゆらぎ・LED・列車・波・モニターなど。
  - `opts.fit`：`'cover'`（既定：はみ出しを切る）/ `'contain'`（全体を入れる。地図・ボードはこちら推奨）。
  - `opts.stability`（0〜100）：70 未満＝一部の看板の文字が一字ずれる（下の表で「alt」と書いた看板）＋細い横ずれ1本／50 未満＝横ずれ2本＋薄い二重像／30 未満＝横ずれ4本＋シアンのかぶり＋**月代駅（営業中）で年配の女性と子供が消える**／10 未満＝ノイズ線。
  - `opts.dark`：真っ暗（懐中電灯の円：`opts.light={x,y,r}`、既定は中央下寄り。`opts.flashlight:false` で円なし）。`opts.highlight` の場所は暗くても照らされる。
  - `opts.highlight`：`[{x,y,r}]`（0..1、r は横幅に対する比率・既定 0.04）。点線の輪がゆっくり回る（調べられる場所の示唆）。
  - `opts.flags`：場面ごとの小さな差分（下の「場面ごとの opts」）。
  - `opts.vignette:false`：周辺減光を切る。`opts.noRaster:true`：差し替え画像があってもコード描画。
- 座標：注目物の `x,y,w,h` は **16:9 の絵全体に対する 0..1**。画面が 4:3 などで cover 表示のときは切れるので、クリック判定は必ず
  `KY_ART.toScene(px, py, cw, ch, fit)`（画面 px → 0..1）／`KY_ART.toCanvas(nx, ny, cw, ch, fit)`（0..1 → 画面 px）／`KY_ART.visible(cw, ch, fit)`（見えている範囲）で変換する。
  4:3 に切ると横 0.125〜0.875 だけが見える。大事な物はこの中に置いてある（例外は表の「端」と書いたもの）。
- `KY_ART.objects(sceneId, world)`：下の表と同じ注目物の配列（{id,label,x,y,w,h}）。章スクリプトから直接使ってもよい。
- `KY_ART.ids()` 場面 id 一覧／`KY_ART.ids('portrait')`／`KY_ART.ids('icon')`／`KY_ART.worlds(id)`／`KY_ART.faces(who)`／`KY_ART.name(id)`。未知の id は「NO SIGNAL」のプレースホルダー（例外を投げない）。
- `KY_ART.portrait(ctx, who, face, w, h, opts)`：(opts.x, opts.y) を左上とする w×h の枠に、下端中央合わせで描く（背景は透明。`opts.bg` で塗る）。
  - who：`yuu` `mido` `nagi` `kujo` `shiro` `resident_a`〜`resident_f` `player`（顔なしの人影＋職員証）。未知の who は player。
  - face：`normal` `smile` `worry` `surprise` `serious`、九条だけ `cold` `sad`、シロは `idle` `alert` `glow`（normal 等も受ける）。未知の表情は先頭の表情。
  - シロは輪郭が時間でゆらぐ：毎フレーム描き直す（`opts.t` を渡せば同期、無ければ performance.now）。
  - 住民：a＝商店の主人（50代女性・紺のエプロン）、b＝年配の男性（はげ頭・白い横髪・ベスト）、c＝学生（学ラン）、d＝母親（低く結んだ髪・セーター）、e＝駅員（制帽・口ひげ）、f＝子供（黄色い通学帽）。
- `KY_ART.icon(name)` → 32×32 のキャンバス（キャッシュを共有するので描き込まないこと）。
  行動 `look` `photo` `record` `scan` `talk`／世界 `world_A` `world_B` `world_C`（`A` `B` `C` も可）／消耗品 `battery` `light` `med` `stab`／装備 `phone` `flashlight` `magnet` `boundary_meter` `hq_recorder` `wave_scanner` `portable_observer` `anchor` `shiro_link`／証拠の種類 `ev_photo`（写真。`photo` はカメラ）`testimony` `audio` `map` `video` `log` `item` `person` `article`／メニュー `map` `board` `notebook` `evidence` `diff` `people` `danger` `sync` `b30` `save` `settings` `back`。`act_` `ev_` `menu_` `eq_` `item_` の接頭辞は外して探す。
- 主人公の顔は描かない。だんのうら（深夜配信の男性）は **後ろ姿・逆光・ノイズ越し** のみ（`stream_room` / `factory_glimpse` / `center_lab` の `flags.feed` / `station_live` の広告のノイズ写真 / `collapse` の破片）。
