# 境界事象：音のクレジット

『境界事象 ― 月代町観測記録』の効果音・環境音・BGM は、すべてこのリポジトリの中のコード（`kyokai/music.js`・`kyokai/engine.js`・`kyokai/battle.js`）で Web Audio を使って合成したオリジナルです。

- 外部の音声素材（音声ファイル・サンプル）は使っていません。
- 外部素材を足すときは CC0 のものだけを使い、作者名・URL・ライセンスをここに記録し、ゲームのクレジット表示にも出します（CC-BY・GPL などは使わない）。
