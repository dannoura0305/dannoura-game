# 家・庭ドット絵 スタイルガイド（フェーズ1〜3）

対象：`main/home/sprites.js`（`window.HOME_ART`）。すべてキャンバスのコードで描いた独自素材。フェーズ3 から、`assets/original/manifest.json` の `file` に PNG を指定したときだけ生成画像に差し替えられる（既定は null＝コード描画。差し替える画像もこのガイドのパレット・外周線・光源に合わせる。手順は `docs/comfyui/README.md` §11）。

## 基本
| 項目 | 決まり |
|---|---|
| タイル | 画面上 32px（`T`）。原寸は **1タイル＝16ドット**。描画倍率は `T/16`（T=32 で1ドット=2px）。拡大は最近傍（`imageSmoothingEnabled=false`） |
| 視点 | 見下ろし3/4。床の範囲（足元）は真上から、家具は「上面＋手前の面」を見せる。高さは上方向へはみ出す（最大30ドット） |
| 向き | 0=正面（下向き・y+）、90=左、180=上（背面）、270=右。左右対称でない家具の 90 は 270 の左右反転で作り、影だけ右下に描き直す |
| 外周線 | `#1b1226`（homescene.js と共通）。1ドット。内部の細部は線を使わず色の段差で |
| 光源 | 左上。上面の上辺・左辺に1ドットのハイライト、右辺・下辺に陰 |
| 落ち影 | `rgba(27,18,38,.30)`。右下へ1〜2ドットずらした矩形または楕円。薄い影は `.18` |
| 灯り | 段階的な円（7段・低アルファ）を `lighter` 合成。家の灯り＝アンバー、貝殻ランタン＝ティール/真珠 |
| アニメ | `opts.t`（秒）で2コマ。揺れは1ドットまで。灯りのゆらぎはアルファのみ |

## キャラクター
- 足元をタイル下端に合わせ、上へはみ出す。中心はタイル中央。足元に楕円の影。
- だんのうら：16×24ドット（約1×1.5タイル）。頭14行・体7行・脚4行。紫の髪＋右側の髪束、めがね（`#2a1c36` の枠）、ピンクの髪飾り、ラベンダーのパーカーとピンクのシャツ、紫のズボン。homescene.js の文字マップを継承。
- 娘（4歳）：16×19ドット（約1×1.2タイル）。頭12行・体5行・脚3行。紫がかった黒のおかっぱ、まっすぐな前髪、ピンクの花で結んだ小さなふたつ結び、大きな紫の目（白い光）、ピンクのほっぺ、ミントのパジャマに黄色い星。家ではクマを持たない（クマは置けるアイテム）。
- 歩き4コマ（0,2=立ち、1,3=片足）。`sit` は2ドット持ち上げ、椅子にもクッションにも使える脚を前に出した姿勢。
- 左向きは右向きの反転。

## やること／やらないこと
- ○ 新しい素材は既存パレットから選ぶ。どうしても足すときはこの表に追記。
- ○ 1ドットの外周線を保ち、半端な拡大（1.5倍など）はアイコン縮小時のみ。
- ○ 意味を色だけで伝えない（灯りはシェードの明るさ＋グロー、鉢の色は名前も表示）。
- ○ 原寸キャンバスに描いてキャッシュし、毎フレームは拡大コピーだけ。
- × グラデーション塗り（グローを除く）、アンチエイリアス、細い斜線のにじみ。
- × 既存ゲームの家具・キャラ・UIを模倣しない（形・配色・構図とも独自に）。
- × 黒（#000）の外周線、純白の大面積（白は光とハイライトだけ）。
