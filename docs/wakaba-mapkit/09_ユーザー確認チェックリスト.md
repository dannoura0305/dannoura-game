# 09 ユーザー確認チェックリスト

このクラウドからは利用者の PC・NAS・インストール済みのソフトが見えません。下の項目を確かめて、**答えをそのまま（コピーで）返してください**。
わからない所は「わからない」で大丈夫です。全部を一度に答えなくても、**★（先に必要）** だけで次に進めます。

## 0. 一番かんたんな方法（任意）
`docs/wakaba-mapkit/tools/survey_local.ps1` を利用者の Windows で実行すると、下の §2 の大半を JSON にまとめて出します。
- **読むだけ**（インストール・書き換え・ネットへの接続をしない）。重いアプリは起動しない。
- 実行：PowerShell を開き、スクリプトのある場所で
  `powershell -ExecutionPolicy Bypass -File .\survey_local.ps1 -Redact -OutFile .\survey.json`
  （ComfyUI や NAS も見るなら `-ComfyPath "D:\ComfyUI" -ExtraPaths "\\NAS\共有名","E:\"` を足す）
- `-Redact` でパスの中のユーザー名を隠します。**共有する前に中身を確認**してください。
- このスクリプトは Windows で一度も動かしていません（未検証）。エラーの文字はそのまま教えてください。
