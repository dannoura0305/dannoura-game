## 5. AI チームと n8n の仕事の流れ

```mermaid
sequenceDiagram
  participant U as 利用者
  participant N as n8n（利用者の PC）
  participant Q as 仕事の列 jobs/*.json（Git）
  participant C as Claude Code
  participant X as Codex／Grok（任意）
  participant W as 作業 PC（Blender/UE/Gaea）
  participant GH as GitHub（PR）
  U->>N: 日本語の依頼（フォーム／チャット）
  N->>Q: 仕事を作る（id・触るファイルの宣言・必要な PC 能力）
  N->>C: 割り当て（ヘッドレス実行 or セッション）
  C->>Q: 鍵を取る（同じファイルの仕事が無いか確認）
  C->>GH: 仕事のブランチで地図仕様・スクリプト・コード → PR
  C->>W: 実行してほしいスクリプト（bpy・UE Python・Gaea CLI）
  W->>Q: 結果（書き出し・ログ・画像）を登録
  N->>X: 別の AI にレビューだけ依頼（同じファイルは編集しない）
  X->>GH: PR にコメント
  N->>U: 承認の依頼（PR のリンク・検証レポート）
  U->>GH: 承認 → マージ
  N->>Q: 鍵を外す・完了
```

## 6. PC の役割分担（案）

```mermaid
flowchart LR
  subgraph MAIN["メイン PC（i7-9700・RTX 3060 Ti 8GB・16GB）"]
    UEE["UE5 エディタ／Gaea／Blender の焼き込み<br/>（GPU を使う仕事）"]
    PERF["実機の性能計測・見た目の確認"]
  end
  subgraph SUB["サブ PC（性能は未確認）"]
    N8N["n8n（常時）"]
    LIGHT["軽い仕事：書き出し・最適化・テスト"]
  end
  subgraph NASB["NAS（未確認）"]
    ORIG["原本・バックアップ・UE の共有 DDC"]
  end
  subgraph CLOUD["クラウド（このコンテナ）"]
    CC["Claude Code：コード・スクリプト・文書・自動テスト（ソフト描画）"]
  end
  CLOUD <-->|"Git（PR）"| MAIN
  CLOUD <-->|"Git（PR）"| SUB
  MAIN <--> NASB
  SUB <--> NASB
  N8N -->|"仕事の割り当て"| MAIN
```
- 割り当ての規則（案）：仕事に `needs: { gpu: true, vramGB: 8, ramGB: 16, os: "windows", apps: ["blender>=4.5"] }` を書き、PC の能力表（`tools/survey_local.ps1` の JSON）と照らす。GPU の仕事はメイン PC へ、同時に 2 つの GPU の仕事を入れない（VRAM 8GB のため）。
- サブ PC・NAS の有無と性能は**未確認**（`09`）。無ければメイン PC 1 台で、n8n は軽いので同居させる。
