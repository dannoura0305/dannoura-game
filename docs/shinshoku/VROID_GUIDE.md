# VROID_GUIDE — だんのうらを VRoid Studio で作って、本物の動きで歩かせる（はじめての人向け）

2026-10-17 の利用者の声「キャラクターは歩くのも走るのもロボットのよう。今の方法で限界ならやめて違う方法でモデリングを」を受けて、
**キャラクターは外部の道具で作ったモデル（VRoid Studio → VRM 1.0）＋本物の動きのデータ（VRMA・モーションキャプチャ）を本番**にしました
（`DECISIONS.md` 2026-10-17）。コードで組んだ今のキャラクター・手続きの動きは**予備**（モデルや動きが無い時だけ使う）です。

ゲーム側の受け入れ口はもうできています（VRM の読み込み・表情・視線・揺れ物・VRMA の再生・足の固定・戦闘のこまの合わせ）。
**あなたの作業は「モデルを作る」「動きを用意する」「ファイルを置いて表を書く」の 3 つ**です。この案内はその順に書いています。

> 「要確認」と書いた所は、道具の版や規約で変わる所です。必ず公式のページ・画面で確かめてください（このクラウドでは道具を動かせないので、画面の名前は版により違うことがあります）。

## 1. だんのうら（紫の姿）を作る
### 1.1 正本（絶対に守る所）
`shinshoku/assets/characters/dannoura.character.json` の `canon` と同じです。
- **男性**。164cm・細身の若い男性。**女性の体つきにしない**（胸のふくらみ・腰のくびれ・腰の張りは付けない）。**スカートは使わない**。
- 紫の長い髪の**ポニーテール**／**小さなピンクのシルクハット**／**黒い四角いめがね**／**ピンクの花の髪飾り**（左の耳の上）／**紫の目**。
- 服：**ラベンダーのフードつきの上着**（前は開く）・中に**ピンクと白のしまのシャツ**・**暗い格子のズボン**・スニーカー。背中に黒い猫の顔のリュック（任意）。
- 他の作品のキャラクターの意匠を写さない（似せて作らない）。

色の目安（今の仮のモデルと同じ値・ずれてもよい）：髪 `#6a3fa0`／目 `#8a4fd0`／眉 `#4b2a78`／上着 `#e6def6`／シャツ `#f2a0c6` と白／ズボン `#2a2236` に `#6e5c96` の格子／帽子 `#f08cb8`／めがね `#1e1a24`。

### 1.2 手順（VRoid Studio）
1. **新規作成 → 男性のモデル**を選ぶ。
2. **体型**：
   - 身長：164cm にする。身長のスライダーの横に cm が出る版と出ない版があります（要確認）。出ない時は見た目で合わせ、ゲーム側で `height: 1.64` に合わせます（§3）。
   - 細身：肩幅・腕・脚は少し細く。**胸は 0**、腰・お尻は男性の値のまま。頭身は 6.5 前後。
3. **顔**：男性の顔のプリセットから近い物 → 目の色を紫、眉を濃い紫に。まつ毛は控えめ。目は少しつり気味・細め（今の仮のモデルの「男性の目」と同じ考え）。
4. **髪**：紫。後ろ髪は**ポニーテール**のプリセット（または手描きの房）で長く。横の房（もみあげの前の髪）を左右に 1 束ずつ。
   VRoid の髪には揺れ物（SpringBone）が自動で付きます。ポニーテールは「重め・ゆっくり」にすると走った時に自然です。
5. **シルクハット（小さなピンク）**：VRoid にシルクハットの部品は無いことが多いです（要確認）。次のどれかで：
   - (a) **髪の房で作る**：髪のエディタで頭の上に短い筒の房（つば・胴・上）を作り、ピンクに塗る。いちばん手軽・揺れ物を外す。
   - (b) **アクセサリー**の機能（版による・要確認）に帽子・円柱があればそれを使う。
   - (c) **Blender で形を足す**（VRM Add-on で VRM を開き、帽子の網を頭の骨 `head` に付けて書き出す）。きれいに作れるが手間。
6. **めがね（黒・四角）**：アクセサリーにめがねがあれば四角い物を黒で（要確認）。無ければ (c) と同じく Blender で足す。顔の絵に描く方法は横顔で破綻するので最後の手段。
7. **花の髪飾り（ピンク）**：アクセサリーの髪飾り、または髪の房を花びらの形に 5 枚並べてピンクに塗る（左の耳の上）。
8. **服**：
   - 上着：**フードつき**の上着（パーカー・ジャケット系）をラベンダーに。前を開ける形があれば開ける（無ければ閉じたままで可・後で Blender）。
   - シャツ：テクスチャの編集で**ピンクと白の横じま**を描く（「テクスチャを書き出す」→画像ソフトで描く→「読み込む」。UV の型紙を下に敷くと描きやすい）。
   - ズボン：長ズボン。テクスチャに**暗い紫の格子**を描く。**スカートは使わない**。
   - 靴：スニーカー（白と黒）。
9. 保存：`dannoura.vroid`（**原本**。Git には入れない。NAS などに保管。リポジトリには書き出した `.vrm` だけ）。

### 1.3 白い姿（化けを解いた姿）
`dannoura.vroid` を「名前を付けて保存」で `dannoura_white.vroid` に複製して作ります。**同じ人物・男性のまま**（別人格・女性として描かない）。
髪を白（`#f2eefa`）、黒いフードの服（`#1a1620`）、猫の耳・尾（VRoid のケモミミ・尻尾の部品があれば・要確認。無ければ Blender で `ext_ear_*`・`ext_tail_*` の骨と一緒に足す）。
書き出しは `dannoura_white.vrm`。ゲーム側の切り替え（白い姿の網の差し替え）は今はコードの白い姿のままなので、置いたら知らせてください（表に `dannoura_white` の欄を足します）。

## 2. VRM 1.0 で書き出す
1. 「撮影・エクスポート」→「エクスポート」→ **VRM 1.0** を選ぶ（VRM 0.x でも読めますが 1.0 を推奨）。
2. **軽くする**（同じ画面の「エクスポートの軽量化」・名前は版で違う・要確認）：

   | 項目 | PC 用 `dannoura.vrm` | スマホ用 `dannoura_low.vrm`（任意） |
   |---|---|---|
   | 三角形の数 | 3〜4 万以下 | 1.5〜2 万以下 |
   | 材質（マテリアル）の数 | 8 以下（アトラス化） | 4〜6 |
   | テクスチャの大きさ | 2048px 以下 | 1024px |
   | 髪の断面・揺れ物の骨の削減 | 少し | 多め |
   | 透明な網の削除 | する | する |

   スマホ用を作らなくても、ゲームはスマホ（画質「低」）でテクスチャを 1024px に縮め、輪郭線を消して読みます。
3. **利用条件（VRM のライセンス）**：作品は**商用あり**（DECISIONS 2026-10-17 Q-L1）なので、
   アバターの利用許可「自分だけ」・**商用利用「可」（法人も可 or 個人の営利まで）**・再配布「不可」・改変「不可」。
   **「非商用のみ（personalNonProfit）」にすると権利の門で止まります**（`mapkit/assets/gate.js` の `VRM_META_NONCOMMERCIAL`）。
4. 書き出したら VRM のビューア（VRoid Hub の見る機能など・アップロードは任意）で、T ポーズ・表情（まばたき・あ い う え お・喜怒哀楽）を一度見ておく。

## 3. ファイルを置いて、表に書く
1. 置く：`shinshoku/assets/characters/dannoura.vrm`（スマホ用があれば `dannoura_low.vrm`）。
2. `shinshoku/assets/characters/manifest.json` の `characters.dannoura` を書き換える：
   ```json
   "dannoura": { "file": "dannoura.vrm", "fileLow": "dannoura_low.vrm", "portrait": null, "provisional": false,
                 "height": 1.64, "fit": "bbox", "shader": "mtoon", "anim": "../anim/dannoura/clips.json",
                 "source": "VRoid Studio 2.14.0 で自作（dannoura.vroid）", "license": "project（商用可・再配布不可）", "author": "（あなたの名前）" }
   ```
   - `height`／`fit`：`fit: "bbox"` は帽子まで入れた上下の幅を 1.64m に合わせます。VRoid で身長を 164cm にできた時は **`fit: "none"`**（作ったままの大きさ・帽子の分だけ高くなるのが正しい）。
   - `shader`：`"mtoon"`（VRoid のままの陰影・既定）／`"toon2"`（本作のコードの陰影へ変換・試し）。
   - `anim`：動きの組（§4）。まだ無ければ `null`（その時は手続きの予備の動きで動きます）。
   - 武器の持たせ方がずれる時は `"sockets": { "rightHand": { "bone": "rightHand", "pos": [0, -0.02, 0.01], "rot": [0, 0, -1.5708] } }` で直す。
3. `shinshoku/assets/characters/dannoura.character.json` の `license` と `source` を書く（**あなたが確かめて書く欄**。AI は書きません）：
   ```json
   "source": { "type": "self_made", "tool": "vroid_studio 2.14.0", "vrmMeta": { "commercialUsage": "corporation" } },
   "license": { "id": "project", "commercial": "yes", "redistributeRaw": "no", "verifiedBy": "（あなた）", "verifiedAt": "2026-11-01" }
   ```
   - **VRoid Studio の規約**：VRoid Studio で作ったモデルは商用でも使える（プリセットの素材を含む）と案内されています — **要確認（公式の利用規約・ガイドライン）**。確かめた日を `verifiedAt` に。
   - 他の人が作った VRM（VRoid Hub などからの物）は**使わない**（権利が自分に無い）。
4. 確かめる：
   - 動きの実験場：`http://localhost:8797/tools/charkit/motion_lab.html?vrm=1&scn=walk`（`scn=run`・`idle`・`combo`・`startstop` も）。
   - ゲーム：`shinshoku.html` を開き、コンソールに `[shinshoku]` の警告が無いか。`?perf=1` で fps・描画の数。
   - 自動：`node tests/run.mjs`・`node tools/shinshoku_play.mjs --only pc`。

## 4. 動き（モーション）を用意する
### 4.1 ゲームが使う動きの組（`clips.json`）
動きは **VRMA（VRM Animation 1.0・`.vrma`）**で 1 本ずつ置き、表 `clips.json` に役割を書きます（例は `shinshoku/assets/anim/test/clips.json`＝配管の試験用）。
置き場所：`shinshoku/assets/anim/dannoura/`。

| 役割 `role` | 名前の例 | 要る？ | 書くこと |
|---|---|---|---|
| `idle` | `idle.vrma` | **まず** | `loop: true` |
| `loco` | `loco_walk.vrma`・`loco_jog`・`loco_run`・`loco_sprint` | **まず歩き・走りの 2 本** | `loop: true`・`speedMS`（その動きの速さ m/s：その場の歩きなら撮った時の速さ）・`rootMotion`（その場＝`none`／前へ進む＝`xz`：自動で抜いて速さも出す）・`events: [{ "t": "footL", "u": 0.0 }]`（左のかかとが着く位置 0〜1） |
| `start`・`stop`・`turnL`・`turnR` | `loco_start.vrma` … | 任意 | 一度だけの動き |
| `attack` | `cmb_katana_light_1.vrma` | 任意 | `fps`・`frames`・`events: [{"t":"hitStart","frame":6},{"t":"hitEnd","frame":10}]`・`match: { "weapon":"katana", "heavy":false, "step":0 }`。**当たりのこまはゲームの数字（`shinshoku/data/combat.js`）が正**で、動きの方を区間ごとに伸び縮みさせて合わせます（倍率 0.6〜1.6 を外れると「作り直し」の印） |
| `hit` | `react_hit_front.vrma` | 任意 | ひるみ |
| `dodge` | `cmb_dodge_roll_F.vrma` | 任意 | 無ければ今の手続きの転がり |
| `gesture` | `gest_talk_1.vrma` | 任意 | 会話の時に上半身だけ重ねる |

無い役割は、今の手続きの動きで補います（予備）。歩きの足の滑りは「足の固定」（IK）で消します（試験で平均 0.1〜0.4cm/s）。

### 4.2 動きの入手の道
1. **VRoid／pixiv の公式の VRMA の見本**（無料で配られている見本の動き・要確認）：まず試すのに最適。
   **作品に入れる前に配布ページの利用条件を確かめる（要確認）**。確かめたら目録の `license.verifiedBy` に記入。
2. **自分で撮る（ウェブカメラ＋MediaPipe を使うローカルのアプリ）**：例 XR Animator（無料・要確認）など、PC の中で動く物を選ぶ（映像を外へ送らない）。
   - 撮り方：全身が映る・明るい部屋・正面と横から。歩き・走りは「その場で」でも「前へ」でもよい（前へ進んだ時は `rootMotion: "xz"`）。
   - 書き出しが **BVH** の時は、BVH → VRMA の変換（pixiv が公開している変換の道具 bvh2vrma・要確認、または Blender＋VRM Add-on の VRMA の書き出し・版を要確認）。
   - 1 周期に切る：**左のかかとが着いた瞬間から、次に左のかかとが着く直前まで**（ずれたら `footL` の `u` で直す）。手のふるえ・足の滑りは Blender で掃除するとさらに良い。
   - 演者の同意：自分でも**同意の記録**（`rights/<日付>.json`：演者・日付・使う範囲）を残す（NAS に・Git に入れない）。目録の `license.performerConsent` に場所を書く（無いと門で止まる）。
   - 研究用（非商用）の動画 → 動きの AI（GVHMR など）は**使わない**（門で止まる）。
3. **Tripo の自動リグ**（画像 → 3D → 骨を自動で付ける）：下書き・比べる用。**商用には有料プラン（Pro 以上）が要るとされる・要確認**。
   無料プランの出力は門で止まります（`source.tool: "tripo"`・`plan: "free"`）。顔・髪の質は VRoid の方が安定します。
4. **Mixamo は Web 版に入れない**：素のファイルの再配布が規約で不可のため、`.vrma`／`.glb` にして配ると違反になり得ます（門で止まる・`KNOWN_NO_WEB`）。

### 4.3 動きの品質の目安（自動で測れる）
`node tools/charkit/capture.mjs --out <フォルダ> --only walk,run --extra '&vrm=1'` で GIF と数値（足の滑り・床へのめり込み・ひざのはね）が出ます。
**人が見て 1〜5 点**（`quality.human`）を付けた動きだけが本番の束に入ります（AI は点を付けません）。

## 6. よくある困りごと
| 症状 | 原因と直し方 |
|---|---|
| 後ろを向いている | VRM 0.x は自動で回します。それでも逆なら manifest に `"rotateY": 3.14159` |
| 大きさが違う | `fit: "bbox"`＋`height`、または `fit: "none"`（作ったまま）、または `scale` |
| 腕がねじれる・肩が上がる | 書き出しの時に T ポーズでない／骨の向きが独自。VRoid の標準の骨のまま書き出す |
| 刀・銃の持ち方がずれる | manifest の `sockets.rightHand` の `pos`・`rot` で直す |
| 揺れ物が暴れる・突き抜ける | VRoid の揺れ物の設定（硬さ・重力・当たり判定）を調整。無い時は `springs` の表で本作の揺れ物を当てられる |
| 白っぽく・のっぺり見える | VRoid の陰の色（シェードの色）を濃くする。試しに `shader: "toon2"` |
| スマホで重い | `fileLow`（軽い版）を作る。三角形・材質・テクスチャを §2 の右の列まで減らす |

関連：`docs/shinshoku/ASSET_IMPORT.md`（置き方の全部）・`docs/wakaba-charkit/12`（段階の計画）・`docs/wakaba-charkit/07`（動きの台帳と権利の門）。
