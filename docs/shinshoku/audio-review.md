# 『境界侵食』音の見直し（2026-11-14）

対象：CC0 の効果音・環境音・BGM（95 件＋この見直しで 1 件）。方針は**じわじわ型**（静けさ・暗さ・間・気配。驚かしは要所の 2 か所だけ）。
素材の出典・作者・CC0 の確認は `AUDIO_CREDITS.md`。データは `shinshoku/data/sound.js`、鳴らす所は `shinshoku/core/audio.js`・`soundbank.js`・`bgm.js`。

## 見直しの方法（耳では聞いていない）

作業環境には音を聞く手段がないので、次の方法で確かめた。

1. **素材ごとの数値**：長さ・平均の大きさ（LUFS）・短い時間の最大・起伏（LRA）・明るさ（スペクトルの重心）・発音の密度・調（長調か短調か）・1 本の中に何回音が鳴っているか（`librosa`・`ffmpeg ebur128`）。
2. **ゲームと同じ鳴らし方での書き出し**：本物の `Sfx`・`SoundBank`・`Music` を Chromium の `OfflineAudioContext` で動かし、音の名前ごと（全 117 個）・環境の種類ごと（22 個）に書き出して測った。音量の倍率（`g`）・速さ・全体の音量 0.7・環境音の倍率・合成の層まで、ゲームと同じ。
3. **繰り返しの目立ち方**：環境音を 60 秒書き出し、音量の動きを素材の長さ 1 周ぶんずらして重ねた時の相関（1 に近いほど、同じ形の繰り返しが聞き取れる）。
4. **素材の説明ページ**（OpenGameArt.org。Kenney のページはこの環境から 403 で開けなかった）。

数値は「400ms の最大（M）」「平均（I）」「最大値（pk、dBFS）」。全体の音量 0.7 を含む。

## 確かめ

- `node tests/run.mjs`：全部合格（音のテスト `tests/shinshoku-audio.test.mjs` に、上の 1〜3・5〜11 を確かめる 4 項目を足した）。
- Playwright（Chromium）：`shinshoku.html?autostart=1&step=…` で 16 の段（pro_meet・ch1_street〔家〕・ch1_alley・ch1_plaza・ch2_gym・ch3_lobby・ch3_tunnel・ch4_office・ch4_lab・ch4_r_giant・ch5_r_enter・ch6a_threads・ch6_s_enter・ch7a_edge・ch7b_enter・end_a）を開いた。
  - 音のエラー（読めない・壊れている・ページのエラー）は 0 件。
  - 音のファイルを最初に読んだ時刻は、どの段でも起動の後読み（`bootMs.lateAt`、約 3.0〜4.0 秒）より後（約 6.2〜7.4 秒）。起動時の読み込みは増えていない。
  - 家の中で始まる段（ch1_street）は環境が `home`。地下通路・巨大戦・崖は 2 本重ねが入っている。ボス曲の繰り返す区間はブラウザで [24.08, 67.85] 秒。
  - 静的サーバーの起動は作業環境の自動の判定で止められたので、代わりに Playwright の `route` でリポジトリのファイルを直接返した（読み込みの順番・時刻の確かめ方は同じ）。
- 聞き比べ用の mp3（前と後）は作業用の場所に作った（リポジトリには入れていない）。
