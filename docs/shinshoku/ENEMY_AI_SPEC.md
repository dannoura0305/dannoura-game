# ENEMY_AI_SPEC — 異形の意味と行動（状態機械）

区分：名前8種は**【確定・企画書】**。意味づけ・行動・数値は**【提案】**。
企画書の要件：意味のある敵／複数の解決（救う・無力化・逃げる・倒す）／**習慣の輪**・**取り違え**・**守ると攻めるの矛盾**を持つ AI。異形のすべてが罪人ではない。

## 1. 共通の仕組み

### 1.1 異形になった原因（企画書の3つ）
各敵のデータに `cause: {body, memory, env}` の重み（0〜1）を持たせ、資料と行動の味付けに使う。
- **body（置き換わった体）**：体の形・攻撃の種類
- **memory（残った記憶・癖）**：習慣の輪・取り違え
- **env（環境）**：場所に縛られる・光や音への反応

### 1.2 知覚
| 感覚 | 値（初期案） | 備考 |
|---|---|---|
| 視覚 | 前方 100°・12m（暗所 6m）。懐中電灯の光は 1.5 倍遠くから見える | 背後は見えない |
| 聴覚 | 拳銃 25m、走る足音 6m、歩く 2m、しゃがみ 0m | 音は「音の出来事」として発生地点と強さを配る |
| 記憶 | 最後に見た位置を 8 秒覚える | 見失うと「探す」へ |
| 取り違え | 敵ごとの「誰に見えているか」（下表） | 取り違えの相手には攻撃しないことがある |

### 1.3 共通の状態機械
```
            ┌──────────── 解決（救う／無力化） ───────────┐
            ↓                                            │
  [輪] ──気づく──> [見定め] ──取り違え──> [取り違えの反応]  │
   ↑                 │ 敵とみなす                         │
   │                 ↓                                    │
   └──見失う── [探す] <──── [攻め] ──よろけ──> [怯み] ────┘
                         │
                         └─守る対象が危ない─> [守る]
  どこからでも：体力0 → [倒れる]（倒す）／ 距離・時間 → [輪]（逃げる）
```
- **輪（ループ）**：その敵の習慣を繰り返す。邪魔しなければ襲ってこない敵もいる。
- **見定め**：0.5〜1.5 秒。ここで相手を「敵」「取り違えの相手」「無関係」に分ける。プレイヤーが見られる「間」（ホラーの静けさ）。
- **守る**：守る対象（子ども・ベッド・店・待ち合わせ場所）が脅かされると、輪を捨てて最優先で守る＝**守るために攻める矛盾**。
- 判断は 10Hz（0.1 秒ごと）、移動と攻撃の判定は 60Hz。同時に動く敵の上限：PC 12、スマホ 8（超えた分は輪の簡易版で動かす）。

### 1.4 解決の4種
| 解決 | 意味 | 結果 |
|---|---|---|
| **救う** rescue | 習慣の輪を「終わらせて」人に休みを与える（完全に元に戻るかは決めない） | 資料が増える・相棒の台詞・実績。弾は落とさないが回復品をもらえることがある |
| **無力化** neutralize | 輪を止める・閉じ込める・眠らせる | 通れるようになる |
| **逃げる** escape | 相手にしない | 何も起きない（再び出る） |
| **倒す** kill | 体力を0にする | 弾・部品を落とす。資料で「倒した」記録 |
- どの解決も**ルートを変えない**。結末の種類も変えない。エピローグの一言と実績、資料の書き方だけが変わる（`story.resolutions`）。
- 救う・無力化の方法は**画面の中の手掛かり**（資料・行動の輪の観察）で分かるようにする。必須の戦闘で「救う」を強制しない。

## 2. 敵ごとの仕様

### 2.1 帰路（きろ）
- **意味**：家に帰る道の途中で置き換えられた住人。帰り道を繰り返す。
- **原因**：memory 0.8／env 0.5／body 0.3
- **輪**：決まった道（商店街→裏路地→住宅）を歩き、家の前で戸を叩き、また最初へ。
- **取り違え**：自分の家の戸を開けた者を「家族」とみなす（攻撃しない・ついてくる）。
- **守る**：自分の帰り道。道をふさぐ物・人を押しのける（ここで攻撃になる）。
- **攻め**：押しのけ（パリィ可）・つかみ（赤い予兆・回避のみ）。
- **解決**：救う＝戸の鍵を開けて家に入れる（家の中で座り込み、眠る）／無力化＝道を柵でふさいで別の輪に入れる（遠回りの輪）／逃げる＝道の脇に避ける／倒す。
- 体力 40。歩く 1.4m/s、怒ると 3.5m/s。

### 2.2 重面（おもおもて）
- **意味**：別の可能性の顔がいくつも重なった人。どの顔が「本当」か本人も分からない。
- **原因**：body 0.7／memory 0.6
- **輪**：鏡・窓・ガラスの前で立ち止まり、顔を合わせ直そうとする。
- **取り違え**：顔ごとに見え方が違う。正面の顔が「知り合い」と思えば攻撃しない。数秒ごとに正面の顔が入れ替わる。
- **守る**：鏡・写真（自分の顔の手掛かり）。割られると激しく攻める。
- **攻め**：顔ごとに違う攻撃（噛みつき・叫び＝怯み・抱きつき）。顔が入れ替わる瞬間が隙＝**見切りの好機**。
- **解決**：救う＝本人の写真を見せる（資料「名簿の顔写真」）→ 顔がそろって座り込む／無力化＝相棒の声で顔の重なりが一瞬ずれる（相棒同行時、「弾く」入力で相棒に呼ばせる）→ その間に縛る／逃げる／倒す。
- 体力 70。

### 2.3 静養（せいよう）
- **意味**：病院のベッドから離れられない患者。眠りを守る。
- **原因**：env 0.8／memory 0.5
- **輪**：ベッドで眠る。廊下に音がするたびに半身を起こす。
- **取り違え**：白衣・名札を着けた者を「看護の人」とみなす（病院の制服を拾うと近くを通れる）。
- **守る**：ほかの患者の眠り。眠りを妨げる者（銃声・走る音）を集団で追う＝**守るために攻める**。
- **攻め**：ベッドから伸びる腕（届く範囲だけ）・点滴の管で縛る。部屋の外へは出ない。
- **解決**：救う＝ナースコールの配線を直して「巡回の時刻」を戻す（保全の工具）→ 皆が深く眠る／無力化＝照明を落とす／逃げる＝しゃがんで通る／倒す（寝ている者を倒すと相棒の台詞が変わる）。
- 体力 30（集団）。

### 2.4 閉店（へいてん）
- **意味**：閉店の手順を守り続ける店員。店を守る。
- **原因**：memory 0.9／env 0.6
- **輪**：決まった順で 明かりを消す→レジを締める→シャッターを下ろす→「本日は閉店しました」と頭を下げる→最初へ。
- **取り違え**：店内の者を「お客さま」とみなす。閉店時刻を過ぎて残る客を追い出す（ここで攻撃）。
- **守る**：店（商品・シャッター・中にいる者）。第3章の山場で、外の模倣者から**子どもを守っていた**のはこの種類【提案】。
- **攻め**：シャッターで押しつぶす（範囲・赤い予兆）・売り場の棚を倒す。
- **解決**：救う＝閉店の手順を最後まで手伝う（明かり・レジ・札）→ 深く頭を下げて動かなくなる／無力化＝シャッターの電源を切る／逃げる＝閉店前に店を出る／倒す。
- 体力 90（中ボス級の個体あり）。

### 2.5 収容者（しゅうようしゃ）
- **意味**：旧研究棟で境界応答の被験者だった人。収容の手順に縛られる。
- **原因**：body 0.9／env 0.7
- **輪**：自分の部屋の前を往復し、点呼の時刻に部屋に戻る。
- **取り違え**：白衣・職員証を持つ者を「職員」とみなし従う…が、点呼の時刻にはその職員も部屋に戻そうとする。
- **守る**：収容の規則。逃げる者（開いた扉）を連れ戻す。
- **攻め**：重い突進（パリィ不可・見切りのみ）・つかんで運ぶ（部屋に入れられる＝やり直しではなく脱出の小さな仕掛け）。
- **解決**：救う＝本人の記録（被験者番号と名前）を見つけて点呼で名前を呼ぶ／無力化＝部屋に誘導して扉を閉める／逃げる／倒す。
- 体力 160。

### 2.6 継接（つぎはぎ）
- **意味**：いくつもの可能性の体の部分がつながった存在。部分ごとに別の癖がある。中ボス。
- **原因**：body 1.0／memory 0.4
- **輪**：部分ごとに輪が違う（右腕は戸を叩く・左腕は何かを抱く・脚は帰り道を歩く）。
- **取り違え**：部分ごとに相手の見え方が違う（左腕は子どもを抱こうとしてプレイヤーを抱き寄せる）。
- **守る**：左腕が抱いている物（配偶者に関わる資料の入った鞄など）。
- **攻め**：部分ごと。**部分を壊すと行動が変わる**（右腕を壊すと戸を叩かなくなり、代わりに暴れる）。
- **解決**：救う＝抱いている物を本来の持ち主の所へ返す（資料から分かる）→ 部分がほどける／無力化＝脚を壊して動けなくする／倒す。逃げるは不可（中ボス戦）。
- 体力 400（部分ごと 80〜120）。

### 2.7 模倣者（もほうしゃ）
- **意味**：人の真似をする異形。真似している間は自分がその人だと思っている。
- **原因**：memory 0.7／body 0.5
- **輪**：近くの人の声・姿勢・口癖を真似る。真似の相手がいなくなると、最後に真似た人のまま輪を続ける。
- **取り違え**：自分を真似の相手だと思う。真似の相手（例：子どもの親）の役割で動く。
- **守る**：真似ている人の守る物（親を真似ていれば子どもを守る）＝**守ると攻めるの矛盾**の中心。
- **攻め**：だんのうら・相棒の声を真似て呼ぶ（罠）・不意の噛みつき。
- **解決**：救う＝真似の元の人の録音を聞かせる（「あなたは誰？」の問いに答えられなくなり、静かに崩れる）／無力化＝真似を否定せず遠ざける／逃げる／倒す。
- 体力 60。**相棒の声を真似る個体**が第4章の分岐の場面で使われる。

### 2.8 待人（まちびと）
- **意味**：誰かを待ち続ける異形。待ち合わせの場所から動けない。
- **原因**：memory 0.9／env 0.8
- **輪**：待ち合わせの場所（バス停・改札・病院の受付）で時計を見る。
- **取り違え**：近づく者を「待っていた人」と思い、ついてくる。違うと分かると悲しげに戻る（攻撃しない）。何度も近づくと怒る。
- **守る**：待ち合わせの場所。その場所を壊す者を攻める。
- **攻め**：時計の針を止める（周りの時間が遅くなる＝プレイヤーが遅くなる場）。
- **解決**：救う＝待っていた人の物（手紙・品物）を届ける／無力化＝時計を止める／逃げる／倒す。
- 体力 50。**配偶者に似た異形（`spouse_like`）**は待人の特別な個体【提案】：研究者を待っている。本人かどうかは決めない。

## 3. ボスの行動の骨組み【提案】
| ボス | 段階 | 特徴 |
|---|---|---|
| 継接（第5章） | 3段階（部分ごとに壊す） | 部分の輪を見て、壊す順で難しさが変わる |
| 人の姿の試練（第4章 secret） | 1段階・群れ | 模倣者＋重面の混成。紫の技だけで |
| 研究者・巨大最終形態（終章A） | 3段階 | 町の区画ごとに戦場が移る。守りながら戦う |
| 研究者・人間大（終章B） | 3段階 | 事故の瞬間の「再生」（時刻が巻き戻る攻撃）、過去の自分の残像、記録の間の照明。白い姿なしで勝てる設計 |

## 4. データの形（例）
```js
// shinshoku/data/enemies.js
export const ENEMIES = {
  kiro: {
    name: '帰路', hp: 40, speed: { walk: 1.4, angry: 3.5 },
    cause: { body: .3, memory: .8, env: .5 },
    senses: { fov: 100, sight: 12, sightDark: 6, hearMul: 1 },
    loop: { kind: 'path', path: 'route_kiro_A', actions: ['walk', 'knock', 'wait'] },
    misread: { when: 'opened_own_door', as: 'family', effect: 'follow' },
    protect: { target: 'own_path', reaction: 'shove' },
    attacks: ['shove', 'grab'],
    resolve: { rescue: 'unlock_home_door', neutralize: 'barricade_path', escape: true, kill: true },
  },
};
```

## 5. テスト
- 状態機械は DOM なし（`ai/*.js`）で、時刻を進めて状態の移り変わりを表で検査（node）。
- 「救う」の手掛かりが、その敵の出る区画の同じ章で手に入ることを検査（データの突き合わせ）。
- Playwright：決まった入力で「帰路を救う」「閉店を救う」を自動で通す。
