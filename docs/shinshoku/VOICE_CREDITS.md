## 演技（2026-11-11）

`tools/voice/acting.json` に、声のある 232 行すべての演技を場面の文脈から決めて書いた（型 `a` と理由 `why`、行ごとの上書き）。付け方は `tools/voice/acting.mjs`。

- 型（presets）：やさしく・悲しく・詫びる・きっぱり・冷ややかに・叫ぶ・ささやく・つぶやく・おびえて・ほっとして・呼びかける・覚悟・くずれて 等 31 種。速さ・高さ・抑揚・音量・間の倍率・語尾（下げる／上げる／言い切る／消え入る）・溜め・声の種類（玄野武宏の喜び／ツンギレ／悲しみ、九州そらのささやき、ずんだもんのなみだめ・ささやき、白上虎太郎のびくびく 等）
- 句読点の間：前は「、」「。」「……」がほぼ同じ長さだった。今は 読点 0.22・句点 0.40・「！」0.30・「？」0.34・「……」0.52・「——」0.45 秒（型の倍率で伸び縮み）。頭の「……」は話し出す前に溜め、終わりの「……」は語尾を伸ばして下げる。「！」は句の抑揚を強め、「——」の後の句は強く言う
- 句ごとの調整（`ph`）：言い切りたい句の抑揚を強める・高さを上げる 等
- 場面に収める：演技で遅くした結果、声に合わせて延ばしても（元の +30% まで）次の行に食い込む場面は、`gen.mjs` がその行（それでも足りなければ場面の全部の行）の間を詰め、少し速く読み直す（232 行のうち 53 行）。声の種類と抑揚の形はそのまま
- 声の割り当て（だれにどの声か）は変えていない

## 作り直し方

1. VOICEVOX ENGINE（Linux CPU 版）を GitHub の Releases（VOICEVOX/voicevox_engine）から取り、リポジトリの外に展開して起動：`<展開先>/run --host 127.0.0.1 --port 50021`
2. `node tools/voice/gen.mjs`（変わった場面だけ作り直す。全部は `--force`・1 場面は `--only cs03_guard`・読みの確認表は `--report <tsv>`）。要るもの：node 18 以上・ffmpeg（libmp3lame）
3. `node tests/run.mjs`（`tests/shinshoku-voice.test.mjs` が、全部の行に音声があるか・ハッシュが合うかを確かめる）

台詞の文を変えたら、その行は話し手と文のハッシュが合わなくなり、作り直すまでゲームでは鳴らない（古い声が違う文で鳴ることはない）。テストも落ちて知らせる。
