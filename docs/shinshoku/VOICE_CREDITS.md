演出（ムービー）の台詞に、無料の音声合成ソフト **VOICEVOX**（ENGINE 0.26.1・Linux CPU 版）で作った声を付けた。
作業環境の中でエンジンを動かして作った（API キーは使っていない）。エンジン本体はリポジトリに入れていない。

- 対象：`shinshoku/story/cutscenes.js`・`cutscenes3〜7.js` の `lines` のうち、声のある 232 行（地の文 `sys`・全体が（ ）のト書き・「……」だけの行は声なし）
- 音声：`shinshoku/assets/voice/*.mp3`（1 行 1 本・モノラル 24kHz・可変ビットレート）と対応表 `manifest.json`
- 作り直し：`tools/voice/`（`gen.mjs`・声の割り当て `voices.json`・読みの辞書 `yomi.json`）。手順は下の「作り直し方」

## 作り直し方

1. VOICEVOX ENGINE（Linux CPU 版）を GitHub の Releases（VOICEVOX/voicevox_engine）から取り、リポジトリの外に展開して起動：`<展開先>/run --host 127.0.0.1 --port 50021`
2. `node tools/voice/gen.mjs`（変わった行だけ作り直す。全部は `--force`・1 場面は `--only cs03_guard`・読みの確認表は `--report <tsv>`）。要るもの：node 18 以上・ffmpeg（libmp3lame）
3. `node tests/run.mjs`（`tests/shinshoku-voice.test.mjs` が、全部の行に音声があるか・ハッシュが合うかを確かめる）

台詞の文を変えたら、その行は話し手と文のハッシュが合わなくなり、作り直すまでゲームでは鳴らない（古い声が違う文で鳴ることはない）。テストも落ちて知らせる。
