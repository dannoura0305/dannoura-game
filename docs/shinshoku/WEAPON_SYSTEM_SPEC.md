## 2. 法律・世界設定上の疑問（Q7）
現代日本では、銃砲刀剣類所持等取締法（銃刀法）により、一般の人は原則として拳銃を持てない。日本刀と古式銃（火縄銃など）は、**美術品・骨董品として「銃砲刀剣類登録証」があれば**所持できる仕組みがある（登録は都道府県の教育委員会。※制度の細部は公開前に一次資料で確認すること。本書は企画上の整理であり法的助言ではない）。

| 物 | 自宅にある理由の案 | 世界設定とのぶつかり |
|---|---|---|
| 刀 | 案a：登録証つきの家伝の刀（化け猫として長く生きた頃の持ち物＝実年齢不明と合う）／案b：知人の形見 | 小さい。登録証を資料として見せられる |
| 火縄銃 | 案a：登録証つきの古式銃（同上）。**紫では撃てない＝弾も火薬も無い美術品**という扱いで法律ともつじつまが合う | 小さい |
| 拳銃・100発 | 案a：金庫は**だんのうらの物ではない**（前の住人／事務所が非常用に預けた／境界の「別の可能性の版」の物が置き換わって現れた）／案b：事件の後に事務所から支給（緊急措置の作中設定）／案c：拳銃をやめ、別の飛び道具（釘打ち機・信号拳銃など）にする | **大きい**。だんのうらが違法に拳銃を持っている設定は避けたい（父親・会社員としての本編の人物像に合わない） |
- **推奨【提案】**：刀と火縄銃は「登録証つきの古い持ち物」。拳銃と100発は「金庫の中に、身に覚えのないまま増えていた物」（境界応答による置き換えの最初の証拠）。→ 法律の問題を物語の謎に変えられ、他作品の設定も変えない。決めるのは開発者（Q7）。

## 3. 境界事象の事務所と武器庫（Q7-b）
- 既存の『境界事象』の分室は**観測・研究の部署**で、武器の描写は無い（PROJECT_AUDIT A5）。分室に武器庫を足すと既存作品の設定を変えることになる。
- 【提案】事務所にあるのは「武器庫」ではなく**「収容物品の保管庫」**：境界から流れ着いた物（由来不明の弾・壊れた装備・妖力に反応する金具）を記録して保管する棚。ここで弾の補給・武器の手入れ（強化）ができる。職員は「本来は持ち出し禁止」と言いつつ黙認する。
- 『境界事象』の人物（御堂・如月ユウ・佐伯など）を出すかは Q4-b。出す場合も、その性格・設定は変えない。

## 5. 自宅の金庫【提案。番号は決めない】
- 4桁のダイヤル式（数字の金庫）。番号は**仮**。
- 手掛かりは3つの場所に1つずつ。**どれか1つで番号が全部分かる**作り（詰み防止。ROUTE_BRANCH_SPEC §5）：
  1. 自宅の中（例：娘の描いた絵の裏の数字・カレンダーの印）
  2. 商店街（例：店の古いレシートの時刻）
  3. 他作品由来（例：『境界事象』の記録の数字）。**本作の中でも同じ手掛かりが手に入る**（第1章の監視カメラの時刻など）。他作品を遊んだ人は「見覚えがある」で早く気づけるだけ。
- **番号の候補（すべて仮。既存の数字を確かめた上での候補）**
  | 候補 | 由来 | 長所 | 注意 |
  |---|---|---|---|
  | `0305` | だんのうらの誕生日 3/5（企画書）。リポジトリ所有者名 `dannoura0305` とも一致 | 本人の金庫らしい | 簡単すぎる。誕生日を「本人が知らない数字」にする演出なら面白い |
  | `0217` | 『境界事象』の 2:17（1分間の通信障害） | 境界事象とのつながり | 境界事象の謎の意味づけを本作が決めてしまう危険 |
  | `0244` | 『境界事象』の 2:44:44 | 同上 | 同上 |
  | `0444` | 444（境界事象・トビネズミ富山の道しるべ） | 3作にまたがる | **USER_444 の正体に触れる印象**を与える。採るなら慎重に |
  | `0744` | トビネズミ富山のバス停「７：４４」 | トビネズミとのつながり | トビネズミの方針「決めない」に触れる |
  | `3030` 等 | 本編の30日 | 本編とのつながり | 意味が弱い |
- **推奨【提案】**：番号は `0305` 系のような**本作の中で完結する数字**にし、他作品の数字（2:17・444 など）は**手掛かりの見せ方**（時計の針・ログの時刻）にだけ使う。最終決定は Q9。
- データ：`data/safe.js` に `{code:'????', provisional:true, clues:[...]}`。テストで「3つの手掛かりのどれからも同じ番号になる」ことを検査。

## 7. 強化と技（スキル）【提案】
- 強化は「整備」：工具と部品で武器を手入れ（刀の研ぎ＝威力、拳銃の弾倉、鉄パイプの握り＝持ち替え短縮）。事務所の保管庫か自宅の作業台。
- 技の習得：章の区切りで「感覚」（ポイント）を得て選ぶ。
  | 技 | 効果 |
  |---|---|
  | 見切りの心得 | ジャスト回避の窓 +2f |
  | 居合の構え | 抜刀一閃の構えまで 36f→24f |
  | 早撃ち | 切替撃ちの1発目 4f→2f |
  | 連鎖の目 | 連鎖一閃の窓 +15f・最大+1 |
  | 保全の手つき | 仕掛けの操作時間 −30% |
  | 猫の受け身（白） | 空中で被弾しても落下硬直なし |
  | 妖の灯（白） | 妖力の自然回復 +50% |
- **本編のスキル（16種）とは数値でつながない**（本編を遊ばなくても同じ強さ）。本編のスキル名を見た目の一言にだけ使う案はあり（CROSS_GAME_LINK_SPEC）。
