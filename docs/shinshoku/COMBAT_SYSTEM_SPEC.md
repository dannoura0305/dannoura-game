# COMBAT_SYSTEM_SPEC — 戦闘の仕様（時間・入力）

状態：**提案（初期値）**。数値はすべて `shinshoku/data/combat.js`（データ駆動）に置き、`?tune=1` の調整画面で変えられるようにする。手触りはフェーズ2〜3で実際に遊んで詰める。
時間の基準：**シミュレーションは 60Hz 固定**（1f＝16.67ms）。描画は可変。入力は毎フレーム時刻つきで記録し、判定は「入力の時刻」で行う（描画が落ちても判定の窓は変わらない）。
表記：`6f(100ms)` のように両方を書く。

## 1. 3つの状態（確定・企画書）
| 状態 | 使える場面 | 役割 |
|---|---|---|
| A 紫（ふだんの姿） | 全章・両ルート | 銃・刀・鉄パイプ・回避・ジャスト回避・パリィ・一閃。**白い姿なしで極められる**こと |
| B 白（本来の姿） | reveal の第4章以降（自由操作は第5章Aから） | 妖爪・猫火・高速移動と空中・幻・連続技・妖力の刀・妖力式火縄銃（妖弾） |
| C 巨大猫又 | reveal の第6章A・終章A | 暴走→我に返る→町を守る。最終戦 |

## 2. 共通の基本値
| 項目 | 値 |
|---|---|
| 歩く／走る | 2.2 m/s ／ 5.0 m/s（紫）、6.5 m/s（白） |
| 体力 | 紫 100、白 120（形態で別の体力にはしない：同じ体力の器に上限だけ+20） |
| ヒットストップ | 軽 3f(50ms)・重 5f(83ms)・一閃 8f(133ms)＋スロー |
| 被弾の無敵 | 30f(500ms) |
| 入力の先行受付 | 攻撃・回避とも 10f(167ms) |
| ロックオン | 切替式。最も近い・画面中央に近い敵。タッチは自動 |
| カメラ | 三人称（肩越し）。屋内のホラー区画は「演出カメラ」の箱で角度を誘導（固定ではなく寄せる） |

## 3. 紫の姿（A）

### 3.1 回避
| 項目 | 値 |
|---|---|
| 全体 | 24f(400ms) |
| 無敵 | 3f〜14f（12f=200ms） |
| **ジャスト回避** | 回避開始から **0〜8f(0〜133ms)** の間に敵の攻撃判定が重なった → 成功 |
| 成功時 | 世界 0.3 倍速 36f(600ms 実時間)・「見切り」状態（下の一閃へ） |
| 連続回避 | 2回目まで。3回目は 12f の硬直 |

### 3.2 パリィ（刀・鉄パイプ構え中のみ。銃では不可）
| 項目 | 値 |
|---|---|
| 受付 | 敵の攻撃判定の発生の **6f(100ms) 前〜2f 後** に「弾く」入力 |
| 成功 | 敵がよろける 54f(900ms)・弾き一閃の窓が開く |
| 失敗（早すぎ） | 構えの硬直 18f(300ms)。ガード扱いで被ダメージ 50% |
| 弾けない攻撃 | 赤い光の予兆（掴み・巨体の踏みつけ）→ 回避するしかない |

### 3.3 一閃（いっせん）の種類
| 名前 | 発生条件 | 入力の窓 | 効果 |
|---|---|---|---|
| **見切り一閃** | ジャスト回避の成功 | 成功から 21f(350ms) 以内に攻撃 | 敵の背後へ抜けて斬る。大ダメージ・無敵 |
| **弾き一閃** | パリィの成功 | 24f(400ms) 以内に攻撃 | 正面から斬り返す。よろけ延長 |
| **抜刀一閃** | 納刀の構え（長押し 36f=600ms 以上）中に敵の攻撃が届く | 構え中に攻撃判定が来た瞬間、自動で居合 | 構えの間は歩けない。外れると 30f 硬直 |
| **連鎖一閃** | 一閃が当たった直後、近くに「見切り」状態（青い縁）の敵がいる | 60f(1000ms) 以内に攻撃 | 次の敵へ跳んで一閃。最大5連鎖 |
| **撃ち一閃** | 銃で敵の弱点（光る部位）を撃つ → 「怯み光」 | 30f(500ms) 以内に刀の攻撃 | 銃から刀へ瞬時に持ち替えて踏み込み斬り |
- 一閃は**ゲージを使わない**（紫だけで極められるため）。上手さ＝窓に合わせること。
- 一閃の演出：0.3倍速の間、音を抑え、刃の一筋だけ光らせる（CUTSCENE_SPEC の「静かな演出」方針）。

### 3.4 銃⇄刀の持ち替え（企画書：速い持ち替え）
| 持ち替え | 時間 |
|---|---|
| 刀 → 拳銃 | 9f(150ms) |
| 拳銃 → 刀 | 9f(150ms) |
| 刀の連撃の戻り中 → 拳銃（**切替撃ち**） | 戻りの 8f 目以降なら 4f(67ms) で1発目 |
| 拳銃の発砲直後 → 刀（**撃ち一閃**以外） | 12f(200ms) |
| 重い武器（鉄パイプ・火縄銃）が絡む持ち替え | 18〜27f(300〜450ms) |

### 3.5 武器ごとの値（詳細は WEAPON_SYSTEM_SPEC）
| 武器 | 攻撃 | 発生 | 判定 | 戻り | 威力 | 備考 |
|---|---|---|---|---|---|---|
| 刀 | 弱1/2/3 | 6/8/10f | 4f | 14/16/22f | 10/10/16 | 3段目は踏み込み |
| 刀 | 強（溜め） | 18f | 6f | 26f | 30 | 溜め中に回避で取り消し |
| 鉄パイプ | 弱1/2 | 12/14f | 6f | 24/28f | 14/18 | よろけ強・壊れない |
| 拳銃 | 構えて撃つ | 構え 6f／連射間隔 15f(250ms) | – | – | 12（弱点×2.5） | 弾倉12・装填 84f(1.4s) |
| 拳銃 | 構えずに撃つ | 4f | – | – | 12 | 命中のぶれ大 |
| 火縄銃（紫） | **銃床の打撃のみ** | 20f | 6f | 30f | 28 | 撃てない（企画書） |

## 4. 白い姿（B）
| 技 | 入力 | 値（案） |
|---|---|---|
| 妖爪 | 攻撃連打 | 5段：発生 4/4/5/6/8f、威力 8/8/9/10/18、空中でも可 |
| 猫火 | 銃の構え＋撃つ | 妖力 10。追尾する火の玉3つ。燃える敵は怯む |
| 高速移動 | 回避 | 全体 18f・無敵 2〜12f・空中で1回 |
| 二段跳び・空中ダッシュ | 跳ぶ（白だけ） | 空中の連続技へ |
| 幻 | 弾く（白では幻になる） | 妖力 15。分身を置き、敵の狙いを 3 秒そらす。分身が攻撃されると自動で見切り一閃 |
| 妖力の刀 | 刀の強攻撃 | 刃が伸びる（届く距離 ×1.6）。妖力 5／回 |
| 妖力式火縄銃（妖弾） | 火縄銃を構えて撃つ | 妖力 20。溜め 30f。貫通・大威力 60 |
| 妖力ゲージ | 0〜100 | 攻撃が当たると +2、一閃 +15、時間で +1/秒。0 になると紫に戻る（暴走しない） |
| 変身 | 「変身」長押し 30f | reveal で第5章A以降。紫へ戻るのは任意・いつでも |
- **白い姿は暴走ではない**（企画書）。操作感は「速く・軽く・空中」、紫は「重く・正確・一閃」と描き分ける。

## 5. 巨大猫又（C）
- 視点：遠めの三人称。町の縮尺は 1/10 相当で作った「巨大用の区画」（LEVEL_DESIGN_SPEC §6）。
- **暴走の場面**（第6章A 前半）：プレイヤーは**市民を攻撃する操作を持たない**（企画書）。操作は「抑える」（長押し・連打どちらでも可の設定）と移動だけ。抑えるほど被害の演出が減る。失敗という状態は無く、相棒の声の場面へ必ず進む。
- **守る場面**（我に返った後）：
  | 動き | 入力 | 使い道（壊す→守る） |
  |---|---|---|
  | 尾で払う | 攻撃 | 倒れてくる看板・電柱をはらう |
  | 体で受ける | 弾く | 落ちる瓦礫・研究者の攻撃から建物を守る（成功で弾き一閃に相当する反撃） |
  | 前足でつかむ | 調べる | 崩れる足場から人の乗った車・避難バスを持ち上げて安全地帯へ |
  | 吠える | 変身ボタン | 異形の群れを怯ませる（人には効かない） |
  | 跳ぶ | 回避 | 被害を出さない着地点が光る（着地点以外は選べない） |
- 最終戦（終章A）は同じ操作に「見切り（ジャスト回避）」「弾き」を加えた巨体同士の戦い。

## 6. 入力の割り当て

| 操作 | PC（キーボード＋マウス） | ゲームパッド（標準配置） | タッチ（横向き） |
|---|---|---|---|
| 移動 | WASD | 左スティック | 左の仮想スティック |
| カメラ | マウス | 右スティック | 画面右半分をなぞる |
| 走る | Shift（押す間） | 左スティック押し込み（切替） | スティックを外まで倒す |
| 攻撃（刀・鉄パイプ・妖爪） | 左クリック | X（□） | 「斬」ボタン |
| 強攻撃・抜刀の構え | 左クリック長押し／Q 長押し | Y（△）長押し | 「斬」長押し |
| 銃を構える | 右クリック（押す間） | LT | 「銃」ボタン（押すと自動照準で構え・離すと撃つ） |
| 撃つ | 構え中に左クリック | RT | 同上 |
| 弾く（パリィ・幻） | F | LB | 「弾」ボタン |
| 回避 | Space | A（×） | 「避」ボタン |
| 持ち替え（銃⇄刀） | ホイール／1・2 | RB | 「替」ボタン |
| 装填 | R | X 長押し（構え中） | 弾が切れたら自動 |
| ロックオン | 中クリック／T | 右スティック押し込み | 自動（タップした敵に切替） |
| 調べる・話す | E | B（○） | 物に近づくと出る「調」ボタン |
| 変身（白・巨大の吠える） | X 長押し | LB+RB 同時 長押し | 「妖」ボタン（reveal で解禁後のみ表示） |
| 道具 | 3〜6 | 十字キー | 道具の帯をタップ |
| 一時停止・メニュー | Esc | Start | 右上「≡」 |
| 一閃 | 窓の間に「攻撃」 | 同左 | 窓の間「斬」ボタンが光る（同じボタン） |
- タッチは窓を **+2f(33ms)** 広げる（指の遅れ）。ゲームパッドは Gamepad API（標準 mapping）、キーの割り当て変更は設定画面で（フェーズ10）。

## 7. 難しさと手助け
| 設定 | ジャスト回避の窓 | パリィの窓 | 被ダメージ | 弾の落ちる量 |
|---|---|---|---|---|
| やさしい | 12f | 前10f〜後3f | ×0.6 | ×1.5 |
| ふつう | 8f | 前6f〜後2f | ×1.0 | ×1.0 |
| むずかしい | 6f | 前4f〜後1f | ×1.4 | ×0.7 |
- 「一閃の手助け」（スロー延長・窓の印）を個別に入り切り。結末は変えない。
- 本編・既存ミニゲームの「やさしい／ふつう／むずかしい」（`dannoura_mg_diff`）は**読まない**（本作の設定は本作で持つ）。

## 8. 検証の方法
- 判定は DOM なしの `combat/timing.js` に置き、node のテストで「入力時刻と攻撃判定の時刻の組」→ 結果（成功／失敗）を表で検査。
- Playwright で決まった入力列（`__sh.input.script([...])`）を流し、ジャスト回避→見切り一閃が出ることを確認。
- 実機の手触りは利用者に確認してもらう（数値の記録は `docs/shinshoku/` に追記）。
