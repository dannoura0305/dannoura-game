# 3D_GAME_DESIGN — 『境界侵食』（仮題）ゲームデザイン概要

区分：**【確定・企画書】**／**【提案】**／**【未決定】**。細部は各仕様書へ。

## 1. 柱（ピラー）
1. **静かな恐怖**【確定・企画書の方針】：驚かしの連発でなく、町と人の「ずれ」で怖がらせる（『境界事象』の「違和感中心」と同じ方向）。
2. **人の姿で極める**【確定・企画書】：紫の姿だけで、一閃・見切り・銃と刀の切替を極められる。
3. **倒すだけが解決ではない**【確定・企画書】：異形は罪人とは限らない。救う・無力化・逃げる・倒す。
4. **秘密と信頼**【確定・企画書】：正体を明かすか、隠し通すか。2つのルートが互いを照らす。
5. **壊す力を守る力へ**【確定・企画書】：巨大猫又の動きは、壊すためのものから守るためのものへ変わる。
6. **独りでも遊べる、つながると嬉しい**【確定・企画書】：他作品を遊ばなくても完結。遊んでいれば気づける。

## 2. 遊びの循環
```
探索（区画・調べる） → 資源（弾・回復・部品） → 遭遇（見定める：救う／避ける／戦う）
   ↑                                                        ↓
 新しい道（鍵・仕掛け・形態） ← 調査（資料・矛盾の発見） ← 戦闘（一閃・見切り）
```
- サバイバル（資源の少なさ・保管箱・セーブの場所）と、アクション（敵を気持ちよく斬る）の配分は**章で変える**：序〜第3章はサバイバル寄り、第4章以降はアクション寄り（reveal は白い姿で一気に加速、secret は最後まで張り詰めたまま）。

## 4. 画面・カメラ・HUD【提案】
- 三人称（肩越し）。屋内のホラー区画は「演出カメラの箱」で角度を寄せ、廊下の奥・扉の影を見せる（固定カメラにはしない＝アクションと両立）。
- HUD は少なく：体力（だんのうらの輪郭の色でも分かる）、弾数（銃を構えたときだけ）、妖力（白い姿のときだけ）、調べるの印。画面の歪み（体力が低い・異形が近い）は CSS の重ね（factory3d の手法）。
- 資料は「手帳」：読んだ資料・地図・人物・異形の記録（`境界討伐録` の素）。
- 日本語のみ（ふりがなは任意）。文字の大きさ設定。

## 5. 3D 表現の要件（企画書の要件を具体化）【提案】
| 要件 | 内容 |
|---|---|
| 光 | 主光源は少なく（街灯・懐中電灯・自販機・非常灯）。影は1灯だけ（スマホは影なし＋焼き込み） |
| 霧と闇 | 霧で遠景を切る（性能と恐怖の両方）。闇の中の「見えそうで見えない」輪郭 |
| 音 | 環境音で恐怖を作る（遠い踏切・自販機のうなり・シャッター・配信アプリの通知音）。曲は控えめ。Web Audio で合成できる物は合成（既存作品と同じ） |
| 驚かし | 1章に1回まで。必ず前触れ（音・光の変化）を置く |
| 歪み | 商店街の明かりが一列ずつ消える・看板の文字が一瞬違う・時計の針が止まる（境界事象の「違和感」と同じ文法で、本作独自の物を） |
| 流血・人体の損壊 | 未決定（Q13：年齢区分の目安）。初期案は「黒い霧になって崩れる」表現で、流血は控えめ |
| 映像の遊び | 一閃の0.3倍速・刃の一筋の光・音の抜け |

## 6. 難しさ
- やさしい／ふつう／むずかしい（COMBAT_SYSTEM_SPEC §7）＋「一閃の手助け」。
- クリア後：「人の姿で極める」高難度（全編紫のみ。reveal でも白い姿を封じる遊び）【提案】。
