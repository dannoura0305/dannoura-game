第3章の終わりの表を閉じる → 「続ける」→ 無線 → 観測分室（第4章「境界の夜」）。章の飛び先 `shinshoku.html?ch=4`（`&route=reveal` で白い姿の戦いから・`&route=secret` で人の姿の試練から。ルートの記録は `via:'debug'`）。

  - **reveal（化けを、解く＝妖力解放）**：めがねを外す → 化けを解く演出 → 白い姿で群れ（応答体 3・模倣する影 2）と戦う（相棒の目の前）→ 沈黙 3 秒 → **相棒「見た目だけで決めつけちゃ駄目ってことかしらね」**（第3章のだんのうらの言葉をそのまま返す。`cs04_line` の 1 か所・字幕・一字一句。第3章の 1 回と合わせて全編で 2 回、3 回目は無い）→ だんのうら「……それ、アタシの台詞よ」→ 相棒「……誰にも、言いません」（仮）→ 地響き → 相棒は地上のポンプ室へ → 搬入口 → 搬入ヤード → **境界の先触れ**（仮名・大型の異形）→ **巨大猫又**（巨大化の演出）で戦う → 決着 → 相棒が「だんのうらさん！」と呼ぶ → 白い姿へ戻る → 終わりの表（妖力解放）。
  - **secret（このまま、人として＝正体秘匿）**：化けを抑える演出 → **人の姿の試練**（紫のまま群れに勝つ。勝つまでルートは未確定。白の入力は無効 `why:'route'`。負けたら「もう一度／選択に戻る」、3 回負けで「手助けあり」（敵 −1）が増える）→ 勝利でルートの確定 → 非常停止（灯りが落ち、応答体がうろつく）→ **配電盤**（必須・設備保全の知識：容量 3 のうちに隔壁＋鎮静、応答炉は入れない）→ **蒸気の弁**（任意：鎮静の蒸気で通路の応答体を座り込ませる）→ 制御室 → **守り**（相棒が応答炉を止める 40 秒。換気口から来る応答体を寄せない。相棒がつかまれたら叩いて離す）→ 応答炉が止まる → 終わりの表（正体秘匿・相棒は正体を知らない）。
- **ルートの確定**（`story/route.js`・`game/ch4.js` の `lockRoute`）：セーブに `route.route`・`route.routeLock {chapter:'ch04', step:'branch', at, rulesVer}`・`branchLog` の `{kind:'route_lock', decision, via:'choice'|'load_branch'|'debug', trial:{attempts, assist, result}, tries, assisted, seed, snapshot, saveVer, gameVer}` を明示的に残す。`branch` 枠を読み込むと選択がまた出て、前の確定の記録は `superseded:true` で残る（`carryBranchLog`）。reveal は `reveal.companionKnows=true`・白の自由使用、secret は白を使えない。
- **謎**：必須＝入退室の記録（停電 23:41〜非常電源 02:10 の間に「記録がある」00:52 B-07 の行を選ぶ。停電の時刻は事故報告書・保全記録のどちらからでも分かる）、secret の配電盤。任意＝所長室の報告書の控え（黒塗り）・電源の手掛かり・試験の手順書・蒸気の弁。どれを見逃してもルートは閉じない。
- **新しい敵**（すべて `provisional:true`）
  - **応答体**（研究施設の異形）：試験の手順をくり返す（呼び出しの音で端末へ歩き「……応答、します」→ 槽へ戻る）。**共鳴**：1 体が傷つくと近くの個体も目を覚ます。決着＝**試験終了の合図で救う**（手順書を読んで端末）／鎮静の蒸気で無力化／倒す。白い予兆の打撃（弾ける）・赤い予兆の叫び（範囲）・つかみ。

## 0. フェーズ4「第3章（病院・地下通路）と白髪形態」で増えたもの
避難所の決着のあと、そのまま第3章へ続く（終わりの表を閉じる → 「（相棒）と話す」→ 病院へ）。章の飛び先 `shinshoku.html?ch=3`（`&stance=reveal|secret` で転機の後から）。

- **流れ**（`story/chapters.js` に 10 段）：病院の玄関 → 受付（`ch3_lobby`）→ **カルテの照合**（必須の謎）→ 小児病棟 306 号 → **守り手**の場面（恐ろしい姿の異形が子どもを守っていた）→ 子どもを渡す → **だんのうら「見た目だけで決めつけちゃ駄目ってことかしらね」**（第3章の原文の台詞。演出 `cs03_line` の 1 か所だけ・一字一句一致をテストで確認）→ 地下通路 → **写し身**（第3章のボス）→ 体力 60% で**転機**（選択）→ 決着 → 第3章の終わりの表。
- **区画**（`world/areas3.js`）：病院（暗いロビー・受付・長椅子と車椅子・ナースステーション・カルテ棚と掲示板・鍵箱・処置室・病室 301〜306 のベッドとカーテンと点滴・小児病棟の飾り・ちらつく蛍光灯・光の筋）／地下通路（配管・待避所・柱の広間・避難所のシャッター・非常電話のセーブ）。避難所 ↔ 病院 ↔ 地下通路（区画グラフに追加）。
- **謎**：必須＝**記録のない患者**（ナースステーションの病室の名札 301〜306 とカルテ棚を照合し、カルテの無い 306「小野寺 ケイ」を選ぶ → 鍵箱 → 306 の扉）。任意＝東 ミヨの「転んでない」（カルテと本人の話の食い違い）・掲示板。どれを見逃しても先へ進める。
- **新しい敵**（すべて `provisional:true`）
  - **記録のない患者**（病院の異形）：自分の記録を探して往復する。懐中電灯を当てたり走って近づくと敵とみなす。**看護師の名札を見せて名前を呼ぶ＝救う**／病棟のスイッチで灯りを落とす＝無力化／倒す。
  - **模倣する影**：市民（病院）や**相棒**（地下通路）に化けて近づく。懐中電灯を当てると目が光る（予兆）。正体を出すと**プレイヤーの直前の行動の型**（斬る・突く・撃つ・つかむ）を真似て返す（頭上に「模倣：斬」などの表示・赤い予兆つき）。
  - **写し身**（第3章のボス・仮名）：模倣の親玉。衝撃波・模倣の連撃・「呼び声」（16 秒ごと、子どもの声をまねる間は与える傷 1.5 倍）。決着＝倒す／救う（呼び声の間に子どもの留守電を聞かせる）。
  - **守り手**（仮名）：子どものベッドの前から動かず、押し返すだけ。子どもを守っていたと分かる場面へ。
- **分岐の土台**（`story/route.js`）：転機の選択は「**化けを、解く**」（`stance:'reveal'`）／「**このまま、人として**」（`stance:'secret'`）。セーブに `route.stance` と `branchLog`（`{seq, kind:'stance', decision, chapter:'ch03', step:'ch3_tenki', via, locksRoute:false}`）を明示的に残す。**ルートの確定（routeLock）はまだしない**（第4章以降の仕事）。転機の直前に上書き可の `tenki` 枠へ自動セーブ → いつでも選び直せる。どちらでも第3章の終わりまで遊べる。
  - 秘匿の構えで 3 回負けると「このまま、人として（手助けあり）」が出る（写し身の体力 −25%・動きが遅く）。勝手に白い姿にはしない。構えは secret のまま。
- **白髪形態**（だんのうらの本当の姿。男性の化け猫）
  - 演出 `cs03_transform`：紫の姿 → 霧と光 → 白い髪・猫耳・白い尻尾（揺れる）・黒いフードの上着に白い帯（X）・爪・ピンクの花・眼鏡・細い瞳の光。「白髪形態」の表示。
  - 技：**妖爪**（5 段・速い）・**猫火**（構え＋攻撃・3 つの追尾火）・**瞬歩**（回避・長い無敵）・**幻術**（弾くボタン・分身に敵を引き付ける）・**日本刀**（強攻撃・妖刀）。
  - **妖力**（0〜100）：白い間は減り続け、当てると増える。0 で静かに紫へ戻る。V 長押し（パッド Select／タッチ「化」長押し）で妖力 30 以上なら白へ／紫へ。
  - **連撃の数**（Combo）と連撃ボーナス（白の間だけ、10 連ごとに与える傷 +10%・最大 ×1.8）。
  - **ルートに合わせた制限**：`secret` では白の入力が無効。**相棒が見ている所では化けを解かない**（自動で紫へ戻る）。第3章では相棒は白い姿を見ない（決着の後、シャッターが上がる前に紫へ戻る）。
- **見た目の底上げ**：腕と脚の網を細かく（16 面）、指と親指のある手、アニメ調の顔（目・まぶた・眉・口の表情 8 種：普通・笑う・真剣・怒り・驚き・悲しい・話す・落ち着き）と瞬き、髪の量（層とアホ毛）、服のしわ（しわの陰と斜めの筋）、肩の形。環境は長椅子・車椅子・ベッド・点滴・配管をインスタンス化、床と壁のしみ（デカール）、壁と小物に頂点 AO（焼き込み）、安い光の筋（`render/shafts.js`）。
- **音**：病院・地下通路の環境音、爪・猫火・瞬歩・幻術・化ける／戻る・妖力切れ・模倣の正体・呼び声・留守電・心音など。
