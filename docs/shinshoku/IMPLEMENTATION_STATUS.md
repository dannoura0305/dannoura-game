- **点検の道具（`tools/shinshoku/audit_env.mjs`＋`tools/shinshoku/audit/`）**：node の中で**本物の組み立て**（`shinshoku/world/*`）を動かす（`loader.mjs`＝importmap と同じ解決・`node_env.mjs`＝キャンバスの代わり）。`record.mjs` が Builder の箱・網・インスタンス網（36 頂点ごとの部品）・電線・直接置いた網を**世界の座標の箱**として記録し、看板の文字（地図帳に描いた文字）と作った関数の名前（スタック）を付ける。`rules.mjs` の規則：
  - **float**：地面に触れる物から「触れている物」（2.5cm）をたどり、たどれない形のかたまり＝浮いている（電線に吊った物は電線の両端の支えで判定）。隙間 5cm 以下は warn。

  - **vehicle**：車輪が地面に着かない・道（駐車場）の外・道の向きと違う・車どうしが重なる。
  - **zfight**：同じ平面で同じ向きの面が重なる（色・絵が違う）。0.3㎡ 以上は error。
  - **block**：出入り口の前（0.6m 外）を見た目の形が塞ぐ（P11 の試験は当たり判定、こちらは見た目）。

## P13c. キャラクターの動きの自然さ・「ポリゴンの気持ち悪さ」（利用者の感想「歩きや走りなどのモーションは不自然で、ポリゴンの気持ち悪さが出ているがアニメ調に少しなった」への対応）
環境（world・town・townmat・render/env*）は別の作業。物語・台詞・当たり判定・戦闘の数字（startup／active／recovery・踏み込みの距離）・セーブの版は変えていない。

### 調べたこと（動画と数値で：`tools/charkit/capture.mjs`）
- **撮る道具**：`tools/charkit/motion_lab.html`（だんのうら／白い姿／相棒を Player・CompanionActor のまま 60Hz の決まった刻みで動かす。場面＝待機・歩き 1.2／2.2・小走り・走り 5.0・全力 6.5・歩き → 走り → 止まる・180° の折り返し（走り・歩き）・円を描いて走る・刀の 3 段＋強・回避）と `tools/charkit/capture.mjs`（こまごとの PNG → ffmpeg で GIF／アニメ WebP・1 周期 12 こまの一覧・骨の記録から数値）。数値の式は `charkit/anim/metrics.js`（足の滑り・めり込み・腰と頭の上下・腰の左右・骨盤の傾きと回り・肩の逆回り・関節の 1 こまの回り・ひざのはね・腕と脚の相関・ひじの遅れ）。
- **不自然に見えた原因**（前の版 `anim8.js` の足の IK の歩き）：
  1. **腰が着地のたびに「がくっ」と落ちる**：腰の高さを「着いている脚」の 2 値（着く／離れる）で選んでいたため、かかとが着いた瞬間に届く高さが飛び、2.2m/s の歩きで腰の上下 **15cm**（人は 5〜7cm）。同時にひざが 1 こまで **51°** 曲がる（ぽん、と折れる）。
  2. **骨盤の回りが逆**：踏み出した脚の側の腰が後ろへ回っていた（`yaw = sin(ph)` の符号）。肩の逆回りも合わせて逆。
  3. 骨盤の左右の寄り・傾き（遊脚の側が下がる）が **0**、頭は胴と一緒に揺れる（安定が無い）、腕は脚の角度を写しただけ（相関 0.99・ひじの遅れ 0 こま＝機械的）。
  4. 動き出し・止まりは脚の角度の補間（速さは一瞬で 0 ↔ 2.2／5.0m/s）。止まると足が滑って寄る。曲がる時の体の傾き・先を見る首が無い。
  5. 髪の揺れ物（VRM の式）の drag が世界の速さを毎刻み 40% 消すので、**歩くだけでポニーテールが真横に流れ切る**。
  6. 攻撃の姿勢は腰を下げるのに脚の角度はそのまま＝**足が床に最大 14cm めり込む**（3 段目・強）。
- **ポリゴンの気持ち悪さの原因**：(a) 髪の房ごとの平たい管の法線＋天使の輪の式（Kajiya-Kay を 90 乗・毛束ごとのずらし大）→ 髪に**ぎざぎざの白い縞**が出る。(b) 部品ごとに法線を作るので継ぎ目で陰影が切れ、輪郭線の殻が割れる。(c) 頂点色の斜めの「しわの縞」が疎らな網で**三角形のぎざぎざの影**になる。(d) 袖の管と袖口の管が同じ太さで重なり、**交わりの線が歯の形**に見える。(e) 鼻の小さな塊に輪郭線が付き、正面で丸い「できもの」に見える。(f) 手が平たい板に短い指（手袋のよう）。(g) 白い姿の毛皮の襟が**とがった破片**。(h) 段の陰影の境目が低い網の三角形に沿ってぎざぎざ。

### 直したこと
- **歩き・走りの仕組みを作り直した**（`charkit/anim/loco.js`・`charkit/anim/locodriver.js`。`shinshoku/actor/anim8.js` は前の名前の入口）：
  - **クリップをデータに**：`charkit/anim/clips/loco_{walk,jog,run,sprint}.json`（1 周期を u＝0..1・u＝0 で左のかかと。骨の名前は VRM 1.0 の humanoid。`hips.sway／yaw／roll／pitch／surge`・`spine.pitch`・`chest.roll`・`head.nod`・`arm.swing／elbow` のキー（周期の Catmull-Rom）・立脚のひざの曲げの曲線・遊脚の持ち上げ／蹴りの曲線・歩数と立脚の割合（速さの式）・大きさ（度・cm））と `personality.json`（だんのうら・白い姿・相棒・娘の性格の値）。`node tools/charkit/build_clips.mjs` で `clips/index.js` を作る（試験で一致を確かめる）。外部のモーキャプ／VRMA は同じ位相の約束で差し替えられる形。
  - 速さで 4 つのクリップを重ねる（歩き ≤2.35・小走り 2.9〜3.6・走り 4.6〜5.6・全力 6.2〜）。**歩数＝base＋perMS×v（脚の長さの √ で割る）・歩幅＝2v÷歩数**、位相は進んだ距離で進める（足が滑らない）。
  - **腰の高さはキーで描かない**：立脚の脚の「ひざの曲げの曲線」（着地 3°→ 荷重 15°→ 片脚の真ん中 7°）から脚の長さを決め、両脚（遊脚の終わり 20% からは着く所）の柔らかい最小で 1 周期 48 点を作って滑らかにする → 着地の後が低く片脚の真ん中が高い（歩き）・立脚の真ん中で沈む（走り）が自然に出て、ひざが伸び切りで折れない。届かない時は前足の揺りかご（かかとを上げる）を自動で増やし、遊脚はその形から始める。
  - **3 次元の脚の IK**（ひざの向き＝前・つま先の外向き・柔らかい伸び切り 99.3%）。骨盤の左右の寄り・前後のゆれは `pose.hipsT`（`rig.js` の Poser が腰の骨の位置へ当てる）。
  - 骨盤：踏み出す脚の側が前へ回る（**符号を直した**）・遊脚の側が下がる・前傾。胸は逆に回る（肩の逆回り）・背骨で傾きを打ち消す・**首と頭は向きを保つ**（85〜94%）。腕：反対の脚と逆・前へ大きく後ろへ小さく・**ひじは 3〜4 こま遅れて曲がる**・走りは 90° で体の前で内へ。刀を構えた右腕にも振りを 30% 残す。白い姿の走りも肩の逆回りを残す。
  - **係（locodriver）**：見た目の速さ（0.09〜0.12 秒で追う）で歩幅と位相を決める（動き出しは小さく速い歩みから伸びる）。**動き出し**は「左が立脚の真ん中」の位相から・待機の足から 0.2 秒でつなぐ。**止まる**と「止まりの一歩」（浮いている足を先に運び、着いていた足は後で持ち上げて直す・0.42 秒）。前後の傾きはばね（動き出しで前へ・止まると前へ行き過ぎて戻る）。**曲がる時は体を内へ傾け**（向きの変わる速さ×速さ、足の下を軸に）、**首・頭が先に曲がる先を見る**。待機も足の IK（両足を床に・重心の左右の移り・休む脚のひざ・呼吸）。相棒・コード製の町の人も同じ係。
  - 攻撃・構え・ひるみの姿勢は**足を床の上へ戻す**（`groundClamp`：腰を下げた分、後ろ脚のひざを曲げる）。時間と腕の振りは前と同じ。
  - 揺れ物：根（体）の動きの 80% は空気の抵抗を受けずに運ばれる（`follow`）。歩きでは髪が下がって揺れ、走ると後ろへ流れる。止まってからの落ち着きは前と同じ試験を通る。
- **ポリゴンの気持ち悪さ**：
  - 法線：髪（頭と横の房）は頭の形の中心からの向きへ 72% 寄せる・顔は 40%・毛皮の襟は首の周りの楕円へ 65%（アニメの「球に写した法線」）。**同じ位置・同じ材質の頂点の法線をつなぐ**（部品の継ぎ目・輪郭線の殻の割れ）。管のふたは側面と頂点を分ける（縁のぎざぎざの影を消す）。
  - シェーダー：段の境目のやわらかさ＝種類の値（下限 0.04）＋画面の変わり方（`fwidth`）。天使の輪は 64 乗・ずらし小・やわらかい境目・頭の上の帯だけ（白い縞のぎざぎざ → なめらかな輪）。
  - 形：頂点色の斜めのしわの縞をやめた（v2）。袖・ズボンの管は袖口の中で止める（重なりの交わりの線が出ない）。鼻は輪郭線なしの小さな高まり（形は顔の絵の線）。**手を作り直した**（手首へ細く平たい手のひら・3 つの節で曲げた指 4 本・丸い指先・親指。手の長さは身長の約 0.105）。白い姿の毛皮の襟は丸くふくらんだ房 2 段＋下地の輪。娘の目は二重の線を描かず下まぶたを薄く（大人びた線で不気味に見えない）。
- 確かめのページ：`tools/shinshoku_viewer.html` も歩きの係を使う（`&loco=0` で前の手続き）。
