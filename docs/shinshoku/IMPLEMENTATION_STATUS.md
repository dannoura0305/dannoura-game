## 1. フェーズ3「序章〜避難所の試作」で遊べるもの
- **流れ**（`shinshoku/story/chapters.js`・15 段）：序章（商店街で相棒と会う → 停電の演出 → 鉄パイプ → 帰路を追い払う → 家・テレビの演出）→ 第1章（刀を取る・金庫は任意 → 発生後の商店街 → 裏路地で再会 → 表通り＝商業施設の前・放送の演出）→ 第2章（避難所＝市民体育館：名簿の照合 → 鍵 → 体育館 → **収容者**（中ボス）→ 決着の演出・試作の終わりの表）。
- **区画**（1 度に 1 区画だけ読み込む）：商店街（家を含む）／裏路地／表通り（商業施設の前）／避難所（ロビー・器具庫・体育館）。雨に濡れた路面・赤い提灯・縦の電飾看板・立入禁止の柵とコーン・事故車・紫と赤の空。
- **調べ物（謎解き）**：必須＝名簿と受付票の照合（6 班それぞれの「いない人」を選ぶ）・受付の机の引き出し（番号）。任意＝金庫（カレンダーの番号 → 拳銃・弾 100・小型銃用ホルスター）・警備室の防犯映像（あり得ない時刻）。
- **収容者（中ボス・仮名）**：毛布の胴・放送スピーカーの頭・背中に積んだ椅子・名札・簡易ベッドの骨の爪（人とモノの融合・血は出さない）。3 段階（体力 100%／60%／25%）。予兆つきの薙ぎ・叩きつけ（範囲）・突進・毛布投げ（範囲）・つかみ（相棒を狙う）。20 秒ごとの**点呼**。決着 3 通り：**救う**（点呼の間にマイクで「久住 トキ」を呼ぶ＝名札の手掛かり）・**無力化**（器具庫へ誘ってシャッターを閉める）・**倒す**。結末ごとに演出と台詞が変わる。
- **相棒（仮 ID `companion`・名前未定）**：ついて来る（足跡をたどる）・敵が近いと隠れる・赤い予兆／背後の敵を声で知らせる・つかまれたら助けられる（信頼 +5／見捨てると −5）。
- **演出（データ駆動）**：`story/cutscenes.js` の時間表（カメラ・字幕・人物の動き・出来事）。上下の黒帯・字幕・長押しで飛ばす（キー／パッド B・Start／タッチ「調」）。7 本（停電・テレビ・再会・放送・収容者・決着 3 種）。
- **戦闘の追加**：連鎖一閃（一閃が当たった直後 60f の窓で次の敵へ・最大 5 連鎖）、鉄パイプ（ガード崩し・弾きあり・刀より遅く重い）、左クリック長押しで強攻撃、ロックオンの切り替え（Z/C・十字左右・画面フリック・タップ）、体幹（崩し）→よろめき→連鎖可能（青い輪郭）、弾の拾い物（小／100）、回復、装備 2 枠（小型銃用ホルスター・抜刀補助・見切り補助、すべて**仮**）。
- **キャラクター（コードで組んだ 1 枚のスキン網・骨入り）**：だんのうら（164cm・紫のポニーテール・ピンクの小さなシルクハット・黒い四角い眼鏡・ピンクの花・薄紫と白のフード付き上着・ピンクと白の縞のシャツ・暗いチェックのズボン・黒い猫顔のリュックと飾り・背中に紫の柄の刀・拳銃）、相棒（普通の私服）、帰路（顔のない影・長いコート）、閉店（看板・シャッター・レジ）、収容者。手続きアニメ：呼吸・足が地面に付く歩き／走り・回避の転がり・刀の弧＋刃の帯・構え・被弾・倒れると黒い霧に溶ける・瞬き・ポニーテールの揺れ。
- **描画**：トゥーン（段の陰）＋リム光＋被弾の閃き＋溶け、骨に追従する輪郭線、光のにじみ（ビルボードの安い代用）、濡れた路面の映り込み（縦の光の筋）、霧、ちらつく灯り、空。
- **音（WebAudio で合成・素材なし）**：区画ごとの環境音・路面ごとの足音（濡れたタイル・アスファルト・床・体育館）・遠くのサイレン・滴り・店内の BGM の残骸・異形ごとの癖の音（戸を叩く・シャッター・点呼の放送）・左右の定位・緊張度。懐中電灯の切り替え。
- **HUD（参考画像に合わせた配置）**：左上＝顔絵・体力・メイン／サブミッション、右上＝丸いミニマップ（方角・目標までの距離）、左下＝持ち物 4 枠（数）、右下＝武器（名前・弾 今／予備）と副武器、右側＝ボタンの案内。スマホでも読める大きさ。
- **差し替え（コードの変更なし）**：`shinshoku/assets/characters/manifest.json` に `.vrm`／`.glb`／`.gltf` と顔絵（png/webp/jpg）を書くだけ。骨は VRM の humanoid／Mixamo／Blender 風の名前を自動で対応、高さ合わせ、T ポーズの補正、敵は複製。手順は **[ASSET_IMPORT.md](ASSET_IMPORT.md)**。確認用 `tools/shinshoku_viewer.html`。

## 5. 制限・仮のもの・企画からのずれ
- 名前は**仮**：相棒、収容者、6 班の人名（笹木 ミツオ ほか）、通りの名前、装備 3 種、金庫の番号の作り方、章題。
- **ずれ（仮の判断）**：①収容者を第2章（避難所）の中ボスとして早めに出した。②刀は家の刀掛け（登録証つき）、拳銃は任意の金庫から（序章は素手→鉄パイプ）。③相棒の「つかまれる」は収容者だけ。いずれも OPEN_QUESTIONS で確認したい。
- 保存のキー名 `wakaba_progress_v1` は「わかばシステム（外部の素材制作ツール）」とは**無関係**（名前が紛らわしい既存の進み具合の箱）。他作品との連携は `window.SHINSHOKU_HOOKS` で後から差し込める形にした。
- キャラクター・敵・町はすべてコード製の仮。手続きアニメなので、モーションキャプチャ並みの動きではない。外部モデルに入っているアニメーションはまだ使わない。表情（BlendShape）未対応。
- 段差・坂なし。光のにじみと映り込みは見た目の代用（本物のブルーム・反射ではない）。
- 火縄銃・白い姿・巨大猫又・第3章以降は未実装。キーの割り当て変更は未実装。
