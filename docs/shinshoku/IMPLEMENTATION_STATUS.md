## 5. VRM（VRoid Studio 等）への差し替え
1. `.vrm` を `shinshoku/assets/characters/` に置く（例 `dannoura.vrm`）。
2. `shinshoku/assets/characters/manifest.json` の該当キャラクターに `"file": "dannoura.vrm"` を書き、`provisional`・`source`・`license`・`author` を正しく記入（`height`・`scale`・`rotateY` で調整可）。
3. 再読み込みで、コードで組んだ仮の姿の代わりに読み込まれる（`@pixiv/three-vrm` と GLTFLoader はその時だけ読み込む）。失敗したら仮の姿のまま続ける（コンソールに警告）。
- 動きは同じ手続きアニメ（`actor/anim.js`）を VRM の humanoid の骨（hips・spine・leftUpperArm…）に当てる。T ポーズの腕は `actor/vrm.js` の `rest` で下ろす。刀・銃の持たせ方と表情（BlendShape）は未対応（フェーズ10）。
- 今は dannoura・companion のみ差し替え対応。異形（kiro・heiten）はコードの仮の姿。
