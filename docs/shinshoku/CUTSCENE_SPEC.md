# CUTSCENE_SPEC — 演出場面の仕様

区分：台詞の **【原文・確定】** は一字一句変えない。それ以外は **【提案】**（仮台詞は「仮：」）。
すべてゲーム内の 3D でその場で描く（動画ファイルは使わない：容量と差し替えのしやすさ）。

## 1. 共通の約束
- **データ駆動**：場面は `shinshoku/story/cutscenes/*.js` のタイムライン（下記の形）。カメラ・人物の位置・台詞・音・入力をトラックで並べる。
- **飛ばせる**：初回も飛ばせる（長押し 1 秒で飛ばす。誤って飛ばさないため）。飛ばしても状態（フラグ・ルート）は同じに書かれる。
- **字幕**：台詞は必ず字幕。声は未決定（Q12）。声がなくても成り立つ間（ま）で作る。
- **入力**：場面ごとに「入力なし／抑える入力／選択」を明記。入力のある場面は、ゲームパッド・タッチでも同じ意味。
- **静かな演出**：音を抜く・カメラを止める・光を一つにする、を基本にする。驚かしは使わない（使うのは 3D_GAME_DESIGN §5 の枠内）。
- **性能**：場面ごとに読み込む物を区画に含める（場面のための読み込み待ちを作らない）。

```js
// タイムラインの形（案）
export default {
  id: 'cs03_line', skippable: true, letterbox: true,
  tracks: [
    { t: 0,    cam: { shot: 'ots_dan', target: 'companion', fov: 40, dur: 2.5 } },
    { t: 0.4,  actor: { id: 'dan', anim: 'look_down', at: 'spot_child_exit' } },
    { t: 1.2,  line: { who: 'dan', text: '見た目だけで決めつけちゃ駄目ってことかしらね', fixed: true } },
    { t: 4.0,  sound: { amb: 'mall_hum', vol: .3 } },
    { t: 5.0,  input: { kind: 'none' } },
  ],
  writes: { flags: { cs03_line: true } },
};
```
`fixed:true` の台詞はテストで原文と一字一句照合する（TEST_PLAN）。

### 1.1 場面の継ぎ目（遷移）と、人物に合わせるカメラ（2026-11-10）
利用者の声：「シーンが変わるときの継ぎ目がすぐに場面が変わるので不自然」「何が起こっているかわからない」。これに合わせて、次を足した。
- **遷移**（`shinshoku/ui/transition.js`・`shinshoku/game/trans.js`）：前の画を写して（凍らせて）重ね、種類ごとに消す。
  - `dissolve`：前の画がゆっくり溶ける／`seep`：**境界のにじみ**（紫に光る縁のまだらで、前の画が真ん中から食われるように抜ける）／
    `black`：黒へ落ちて、少し置いて明ける（時間の経過）／`white`：白く飛んで明ける（変身・強い光）／`area`：区画の移動。
  - 演出データで指定する：`intro`・`outro`＝`{ kind, dur?, hold?, out?, in? }`（既定は溶け）。カメラの鍵 `{ cut: true, tr: 'seep', trDur: 1.0 }` で場面の中の切り替え（`tr` の無い `cut` は今までどおりそのまま切る）。
  - 黒・白の**覆っている間は演出の時計を止める**（被写体が黒の裏で先に進まない）。遊びも止める。音も一緒に遠のく（`Sfx.dip`）。
  - **区画の移動**：前の画 → ゆっくり黒（0.6 秒）→ その裏で読み込み → 場所の名前と助言を出して間（0.55 秒）→ ゆっくり明ける（1.1 秒）。入った時の演出は明ける時から始まる。
  - **章の札**：黒の上に出す（黒へ落ちる → 札 → 明ける）。区画の移動の黒の最中なら、その黒を延ばして出す。演出の始まりにある章の札（t ≤ 0.5）は演出の前に出す。同じ札は続けて出さない。
  - 章の終わり（成績の表の前）・結末の病室→家・エンドロールの前は `outro: { kind: 'black' }`。
  - 飛ばした時は場面の中の遷移を出さず、終わりは短い溶けだけ。**試験の起動（?autostart=1・?test=1）では遷移しない**（`?trans=1` で使う）。
- **人物に合わせるカメラ**（`story/cutscene.js` の `shotCam`）：カメラの鍵に `shot: { shot, on, from, side?, dist?, h?, fov? }` と書くと、その時の人物の位置から置く。
  - `close`（寄り：話し相手の方から）・`ots`（肩越し）・`two`（二人を横から）・`wide`（引き）・`low`（見上げ）・`back`（後ろ姿の肩越しに、見ている先）。
  - 当たりの箱で壁越しにならない位置・被写体が画面（帯の内側）に入る位置を探す（被写体のまわりを回り、少しずつ寄せる）。前に選んだ候補を先に試す（揺れない）。
  - 戦いの後の場面（立ち位置が毎回ちがう）・話す人を映す寄りに使う。結末A の原文の一言の間（白い髪）は今までどおり決まった鍵。
- 人物：`face`（その人の方へ向く）・`near`（その人の横へ歩いて寄る）を足した（`game/story.js` cineActor）。
- 確かめ方：`tests/shinshoku-cine.test.mjs`（遷移の計画・再生器・shotCam・データ・長さは直す前の +30% まで）。

## 2. 主な場面

### CS-00 「明かりが消える」（序章）
| 項目 | 内容 |
|---|---|
| カメラ | 商店街のアーケードを縦に見通す固定 → 明かりが奥から一列ずつ消えるのに合わせ、ゆっくり手前へ寄る（ドリー） |
| 人物 | だんのうら（紫）と相棒が立ち話。相棒が先に気づいて奥を見る |
| 台詞 | 仮：相棒「……今、奥の方」／だんのうら「停電、かしら」 |
| 音 | 店の BGM・自販機のうなりが一つずつ止む。最後に自販機だけが残り、それも止む。無音 1.5 秒 |
| 動き | 最後に消えた明かりの下に、帰路の輪郭（まだ人に見える） |
| 入力 | なし。終わりで操作に戻る（カメラは同じ向きのまま＝つなぎ目を感じさせない） |

### CS-03 「見た目だけで」（第3章）
| 項目 | 内容 |
|---|---|
| 前提 | 子どもと「閉店」の真相が分かった直後（倒した・救ったで細部が変わる） |
| カメラ | だんのうらの肩越しに、子どもを抱いて出ていく相棒 → だんのうらの横顔（めがねに売り場の非常灯） |
| 台詞 | **だんのうら「見た目だけで決めつけちゃ駄目ってことかしらね」**【原文・確定】 |
| 返し | 仮：相棒が少し笑う（言葉は短く。**同じ台詞は返さない**） |
| 音 | 閉店の放送の最後の一節が遠くで途切れる |
| 入力 | なし |

### CS-04R 「化けを解く」（第4章・reveal）
| 項目 | 内容 |
|---|---|
| 前提 | 分岐の選択「化けを、解く」 |
| カメラ | 相棒の目線（低い位置）→ 異形の群れの向こうのだんのうら。めがねを外す手のアップ → 髪の色が紫から白へ変わる（**一瞬で変える。変身の長い見せ場にしない**＝本人にとっては「隠していたものが出るだけ」） |
| 動き | 白い姿で群れを一掃（ここはプレイヤーが操作する短い戦闘に切り替える案もあり） |
| 間 | 戦いのあと、相棒とだんのうらが向き合う。沈黙 3 秒。カメラは2人を横から |
| 台詞 | **相棒「見た目だけで決めつけちゃ駄目ってことかしらね」**【原文・確定：第3章の言葉をそのまま】 |
| その後 | 仮：だんのうら「……それ、アタシの台詞よ」（入れるかは任意）／相棒「……誰にも、言いません」 |
| 音 | 群れの音が消えたあと、配信アプリの通知音が一度だけ（視聴者数が0に戻る） |
| 書く状態 | `route='reveal'`, `reveal.companionKnows=true`, `branchLog` |

### CS-04S 「人として」（第4章・secret）
| 項目 | 内容 |
|---|---|
| 前提 | 分岐の選択「このまま、人として戦う」 |
| カメラ | だんのうらが鏡（割れたガラス）に映る自分を一瞬見る → 髪に白がにじみかけて、戻る（**見るのはプレイヤーだけ**。相棒は見ない） |
| 台詞 | 仮：だんのうら「……まだよ。まだ、この姿で」 |
| 続き | そのまま「人の姿の試練」の戦闘へ（ROUTE_BRANCH_SPEC §3） |
| 書く状態 | 勝利後 `route='secret'`, `branchLog` |

### CS-06A-1 「暴走」（第6章A）
| 項目 | 内容 |
|---|---|
| カメラ | 地上の相棒の目線から見上げる巨大猫又 → 巨大猫又の目の高さ（町が小さく見える） |
| 動き | 尾が看板を払い、足元のアーケードが崩れる。相棒が瓦礫で負傷（直接の攻撃ではない） |
| 入力 | **「抑える」**（長押し or 連打を設定で選ぶ）。押している間は動きが鈍り、被害の演出が減る。**市民を攻撃する操作は無い**。失敗の状態は無い |
| 台詞 | 相棒は**決め台詞を言わない**。名前を呼び続ける（呼び方は Q8-b）。呼ぶたびに画面の歪みが少し引く |
| 音 | 巨大猫又の呼吸と町の崩れる音。相棒の声だけが近い（ミックスで声を前に） |

### CS-06A-2 「我に返る」（第6章A）
| 項目 | 内容 |
|---|---|
| カメラ | 巨大猫又の目のアップ → 瞳に映る相棒 → 引きで、町の上で動きを止めた巨大猫又 |
| 動き | 倒れかけた電柱を尾で支える（最初の「守る」動き）→ 操作が「守る」へ切り替わる |
| 台詞 | なし（または相棒の短い一言。仮：「……戻って、きた」） |

### CS-END-A 「見舞い」（結末A）
| 項目 | 内容 |
|---|---|
| 場所 | 病院の個室。昼。窓の光 |
| 人物 | ベッドの相棒。見舞いのだんのうら：**白と紫が混ざった髪**（化けが不安定なだけ。けがではない） |
| 台詞 | 相棒はまだ許すとは言わない（仮台詞を数行）→ **相棒「でも、あの後……みんなを助けてくれたんですよね」**【原文・確定】 |
| カメラ | **この台詞の間、カメラはだんのうらの白い髪を映す**【確定・企画書】（顔ではなく髪。相棒の声だけが聞こえる） |
| その後 | 相棒が秘密を守ることが分かる一言（仮）。窓の外の商店街（修理中） |
| 音 | 病院の環境音のみ。曲は最後の数秒から |

### CS-END-B 「信頼」（結末B）

### CS-BOTH 「対比」（両ルートを見たあと・候補）
- タイトルの背景またはギャラリーの一枚：同じ病院の廊下を左右に分けて、左は白い髪、右は紫の髪のだんのうらが歩く。台詞なし。【提案・候補】

## 3. オープニングの差し替え（CROSS_GAME_LINK_SPEC の解放表と連動）
- 本作のオープニングは**何度でも見直せる**（タイトルの「記録」→「オープニング」）。
- 解放の状態で、オープニングの一部（窓の外の小物・配信画面のコメント・遠景の灯り）が変わる。物語の意味は変えない。
