## 遊び方（プレイガイド）
- **タイトル**：続きから／はじめから／章選択／記録（ギャラリー）／設定（画質・難しさ・字幕・キー・暴走の「抑える」・画面の揺れ）／本編のタイトルへ。
  - 結末を 1 つでも見ると「章選択」で全 11 章（分岐の後の章はそのルート）、「記録」で見た結末を見直せる。両方の結末を見ると「対比（同じ廊下）」。
  - 結末を見た後の「はじめから」では「引き継いで はじめから（仮）」も選べる（装備・回復の道具・弾だけ）。
- **流れ**：序章 → 第1章 → 第2章 → 第3章 → **第4章で分岐**（化けを、解く＝妖力解放／このまま、人として戦う＝正体秘匿。分岐の前は専用のセーブ枠）→
  - 妖力解放：第5章A 侵食 → 第6章A 巨躯（暴走 → 我に返る → 守る → 崩れた商店街 → 塗替）→ **終章A 崩れた町**（公衆電話でセーブ → 淵の縁で巨大猫又 → 境界を喰らうもの）→ **結末A 見舞い**
  - 正体秘匿：第5章B 秘匿 → 第6章B 制御（中央管理棟）→ **終章B 記録の間**（内線電話でセーブ → 研究者と人の姿のまま）→ **結末B 信頼**
- **操作（PC）**：移動 WASD・視点 マウス（クリックで固定）・攻撃 左クリック（長押しで強攻撃）・弾く F・回避 Space・調べる E・持ち替え ホイール／1〜4・ロックオン T・懐中電灯 L・回復 H・化（白い姿）V 長押し・一時停止 Esc。ゲームパッド・タッチ（スマホ横向き）にも対応。詳しくは一時停止 →「操作」。
- **終章のこつ**：
  - 終章A：「喰らう」（白い線）は避難の灯を狙う。灯と淵の間に立つと巨大猫又の体で受けられる（咆哮でも止まる）。胸の「淵の目」は咆哮・崩しで開き、傷が 2 倍。
  - 終章B：赤い灯の箱（記録装置）が動いている間、研究者の傷は巻き戻される。**書き込み中（赤）に止めると記録が壊れるので、待機（緑）の時に**止める。（相棒）への白い線は間に立って受ける。巻き戻しは「数秒前にいた所」を狙うので動き続ける。
  - どちらも 3 回負けると手助け（体力 −25%・記録に残るだけ・結末は変わらない）。難しさは設定でいつでも変えられる。
- **飛び先（試験・確認用）**：`shinshoku.html?autostart=1&ch=7&route=reveal`（終章A）・`&at=boss`（最終戦）／`?autostart=1&ch=7&route=secret`（終章B）・`&at=boss`／`?autostart=1&ending=A|B`（結末だけ）。章 3〜6 の飛び先は IMPLEMENTATION_STATUS を参照。
