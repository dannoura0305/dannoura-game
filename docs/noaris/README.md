本格的な女性向け恋愛アドベンチャー（乙女ゲーム）× ダークファンタジー × ループミステリー。企画書：企画者の「『境界ノアリス』ゲーム開発企画・基本仕様書」（2026-11-20 受領）。

## 確定している事（企画書・企画者）

- 『だんのうら』『境界事象』『境界侵食』と**同じ世界**（2026-11-20 企画者）。つながりの中身は未確定
- このリポジトリに新しい作品として足す（`noaris.html` ＋ `noaris/`。2026-11-20 企画者）
- 主人公は女性。幼い頃に化け猫に拾われ育てられた。20 歳の誕生日を大きな期限とする消滅の運命（理由は物語の謎。序盤で説明しない）
- 五つのエリア：白薔薇の宮殿／忘れられた森／終わらない戦場／終わりのない図書館／月の沈む遊園地。各エリアのテーマと精神崩壊の演出方針（企画書 §4・§7）
- 五人の攻略対象の姿を使い分けていたのは一匹の化け猫。五人との恋愛を「偽物だった」と感じさせないことを最優先
- 化け猫は主人公の育ての親。五人のルートの後に隠し攻略キャラとして登場（猫耳・尻尾の青年）
- 進行の五段階（王道 → 不穏 → 繋がり → 隠しルート → 決着）
- 正式エンド「明日を生きる」（化け猫が命を懸けてループを終わらせる）
- トゥルーエンド「次は、私が守る番」：化け猫は普通の黒猫の姿で生き残り、主人公が保護する。最後の台詞「次は私が守っていく番だね、お父さん」と、黒猫がきょとんと見上げる余韻（覚えているかは明かさない）。**安易に変えない**

### 状態は 2 層

- **1 周の中**（`run`）：今の場面と行・好感度やフラグ（`vars`）・見えている背景と人物・主人公の名前。セーブに入る
- **周回をまたぐ**（`meta`）：ループ回数・既読・見たエンディング・CG。ゲームオーバーでループ回数が増え、1 周の状態は消え（名前は残る）、ループの幕間（`loop`）から次の周が始まる

## 遊びの仕組み（2026-11-22：企画者がくれた、ほかの恋愛アドベンチャーの解析メモ〔仕組みと数だけ〕を参考に足した）

物語・台詞・人物・絵・音は持ち込んでいない。数の決め方と画面の仕組みだけを参考にした。

| 仕組み | 中身 | 場所 |
|---|---|---|
| 想いの段 | 人物ごとに 6 つの境目（`NA.FEELINGS`）。会話の画面の「想い」で、白い薔薇の花びら 6 枚のうち何枚開いたかを見せる（数そのものは見せない）。**最後の境目＝その人物の GOOD の条件**（白薔薇は愛情 9）。最初の境目 0＝出会えば 1 枚。意思は見せない | `config.js`・`ui.js showFeel` |
| 想いが通じた演出 | 選択肢で想いが**上がった時だけ**、右上に白い花びらが舞い、高い 3 音が鳴る（下がった時は見せない） | `engine.js choose`（fx `feel`）・`ui.js feelFx` |

白薔薇で集められる愛情の最大は 10（GOOD に着く道筋）、GOOD の条件は 9。取りこぼしの余裕は 1（参考のメモの作品は 0〜5）。

### 企画者に決めてもらう事（参考のメモから出た案。まだ入れていない）

1. **選択肢の点の付け方**：参考では「当たりを選ぶと ＋1、外れは 0、下がる事は無い」。今の白薔薇は ＋1〜＋3 と、掟を破った時の −1・−2 がある（意思も上下する）。参考に寄せるなら、点を ＋1 にそろえて罰を無くす（境目と試験も直す）
2. **取りこぼしの余裕**：白薔薇は 1。参考では人物ごとに 0〜5。余裕を 2〜3 にすると、GOOD に届きやすくなる
3. **二段構え**：参考では「道筋に入る境目（低い）」と「良い結末の境目（高い）」が別。隠しルート（化け猫）の解放条件を決める時に、「五人の想いがそれぞれ一定の段以上」のような形にできる
4. **用語の辞書**：参考では物語の中の言葉（約 150 か所）から辞書の項目を開ける。宮殿の掟・境界の回廊などを、読みながら引けるようにする案
5. **まばたき・口の動き**：立ち絵が届いたら、まばたき（4 コマ×50 ms、3〜5 秒おき）と口の動きを付ける案

## 台本の書き方

```js
NA.scene('rose_01', [
  '#bg rose_gate',              // 背景
  '#chara rose normal',         // 人物と表情（#chara off で消す・#face cold で表情だけ）
  'rose|――ようこそ、白薔薇の宮殿へ。',   // 話者|本文（話者は config.js の NA.CHARS。me は主人公）
  '扉を抜けると……',             // 話者なし＝地の文
  '?loop>=1 rose|……君はいつも、初めて来たような顔をする。',   // ?条件 を前に付けると、条件が成り立つ時だけ
  '#choice',
  '- 差し出された手を取る => rose_02 +rose 2',   // - 文 => 行き先 [+名前 数] [=フラグ] [?条件]
  '- 「わたし、すぐに帰らないと」 => rose_02 =wantleave',
], { title: '白薔薇の宮殿' });
```

命令：`#bg` `#chara` `#face` `#cg`（見た CG はギャラリーに残る）`#bgm` `#se` `#fx fadein|blackout|flash|shake|crack|loop` `#wait ms` `#set 名前 [値]` `#add 名前 数` `#jump 場面` `#if 条件 => 場面` `#name`（名前の入力）`#select`（扉の選択）`#end good|bad|normal id` `#gameover id` `#title` `#unlock 名前`

条件：`名前>=数` `名前==数` `名前` `!名前` を `&` でつなぐ。`loop`＝ループ回数、`end_<id>`＝そのエンディングを見た。

文中の `{name}` は主人公の名前。
