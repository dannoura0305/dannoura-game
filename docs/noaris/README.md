### 状態は 2 層

- **1 周の中**（`run`）：今の場面と行・好感度やフラグ（`vars`）・見えている背景と人物・主人公の名前。セーブに入る
- **周回をまたぐ**（`meta`）：ループ回数・既読・見たエンディング・CG。ゲームオーバーでループ回数が増え、1 周の状態は消え（名前は残る）、ループの幕間（`loop`）から次の周が始まる

## 台本の書き方

```js
NA.scene('rose_01', [
  '#bg rose_gate',              // 背景
  '#chara rose normal',         // 人物と表情（#chara off で消す・#face cold で表情だけ）
  'rose|――ようこそ、白薔薇の宮殿へ。',   // 話者|本文（話者は config.js の NA.CHARS。me は主人公）
  '扉を抜けると……',             // 話者なし＝地の文
  '?loop>=1 rose|……君はいつも、初めて来たような顔をする。',   // ?条件 を前に付けると、条件が成り立つ時だけ
  '#choice',
  '- 差し出された手を取る => rose_02 +rose 2',   // - 文 => 行き先 [+名前 数] [=フラグ] [?条件]
  '- 「わたし、すぐに帰らないと」 => rose_02 =wantleave',
], { title: '白薔薇の宮殿' });
```

命令：`#bg` `#chara` `#face` `#cg`（見た CG はギャラリーに残る）`#bgm` `#se` `#fx fadein|blackout|flash|shake|crack|loop` `#wait ms` `#set 名前 [値]` `#add 名前 数` `#jump 場面` `#if 条件 => 場面` `#name`（名前の入力）`#select`（扉の選択）`#end good|bad|normal id` `#gameover id` `#title` `#unlock 名前`

条件：`名前>=数` `名前==数` `名前` `!名前` を `&` でつなぐ。`loop`＝ループ回数、`end_<id>`＝そのエンディングを見た。

文中の `{name}` は主人公の名前。
