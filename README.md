## 🏡 家・庭づくり（フェーズ1）

メニューの「🏡 家・庭をひらく」で、娘と暮らす部屋（12×8マス）と小さな庭（16×12マス）を整えられます。遊ばなくても本編は進められます。

- **暮らしモード**：人や家具をタップして調べる・使う（座る、灯りを点ける、本を読む、水やり）。「話す」で娘と会話。
- **模様替えモード**（時間は進みません）：下の収納から選ぶ → マスをタップでプレビュー → ［置く］。［回転］［収納］［移動］［取り消し］［やり直し］［破棄］［確定］。置けないときは理由が文で出ます。
  - PC：クリック・ドラッグ、R＝回転、Esc＝取り消し、Ctrl/Cmd+Z＝戻す、Ctrl+Y／Ctrl+Shift+Z＝やり直し、Enter＝置く、Delete＝収納。
- **クラフト**：木材・布・金具・海のかけらで家具を作る（30分・疲労+2）。素材は工場の仕事・子育て・釣り・RPGの章クリアで少しずつ（1日1回まで）。
- **物語「窓辺の小さな約束」**：5日目以降、娘と花を育てる連続イベント。思い出は「思い出帳」に残り、良い結末では自分の部屋や庭がエンディングに映ります。
- **RPGとの連動**：棚を直すと第2章に専用の会話。第2章クリアで「貝殻ランタン」のレシピが解放。

### セーブスロット・模様替えの追加
- **セーブは3スロット**：タイトルの「つづきから」でスロットを選ぶ（日数・所持金・借金・到達した結末または「暮らし ○日目」・保存した時刻）。削除は確認つき。「はじめから」は使うスロットを選び、データのあるスロットは上書きの確認が出る（セーブが一つも無いときはそのままスロット1）。自動セーブは選んだスロットへ。旧版の単一セーブ（`dannoura_save_v1`）は初回にスロット1へ移る（書けたのを確かめてから旧キーを消す）。エンディング一覧・設定はスロットと関係なく共通。

## ゲームの流れ
- DAY1〜DAY30を、配信・工場の仕事・資格の勉強・育児・休息をやりくりして生き延びます。
- 毎晩22時から行動を選びます。配信を終えるか朝6時になると、夜が明けて次の日へ進みます。
- 借金と育児ストレスは毎晩少しずつ精神を削ります（21日目以降はさらに重くなります）。こまめに休みましょう。
- 7日ごとに生活費（6万円）を払い、手元の3万円を超えた分は自動で繰り上げ返済されます。
- 次のどれかに当てはまると、その時点でゲームオーバーです。近づくと画面上部の目標欄が赤く光り、通知で知らせます。
  - 精神が0になる
  - 疲労が100で、精神が20未満
  - 借金が200万円を超える
  - 炎上が10に達する
- 30日を終えると、育て方に応じたエンディングになります。到達したエンディングはタイトル画面の「エンディング一覧」で確認できます（ブラウザに保存）。

## ミニゲーム（17種・各1日1回）
ミニゲームは「🔧 工場」（7種）と「🎮 夜のミニゲーム」（10種）の2つの選択画面に分かれています。難しさ（やさしい／ふつう／むずかしい）は設定画面か選択画面で切り替えられます（初期値はやさしい、報酬は同じ）。結果はパラメータに反映されます。どのゲームにも導入の会話・結果で変わる結末・S〜Cの評価・自己ベストの記録があり、2回目以降は難しい版や別ルートが解放されます。

#### 🔥 炎上コメント撃退（シューティング）のつくり
- **流れ**（約2〜3分）：WAVE 1〜3 → 中ボス「まとめ管理人」（持ち時間24秒・倒すとボム＋1かレーザーが出る）→ WAVE 4（エリート「インフルエンサー」がレーザー予告）→ ボス「炎上の渦」（体力で3段階：渦巻き・狙い撃ち／包囲網・晒しレーザー／大炎上・言葉の雨。段階が変わると画面の弾が点に変わる。60秒耐えると「夜明け」でクリア＝撃破ではない）。
- **敵**：荒らし・煽り（蛇行）・炎上タグ（装甲）・拡散（分裂）・論客（狙い弾）・スパムBOT（紫のばらまき）・エリート。弾は色で種類が分かる（赤＝狙い、橙＝ボス、紫・金＝小粒）。当たるのは自機の白い芯だけ。
- **得点**：コンボ5ごとに倍率 +0.5（最大×4）・上の方で倒すと速攻×1.5・弾をかすめると「かすり」ボーナス（コンボも延びる）。
- **応援コメント**（撃たずに受け止める）：拡＝拡散・護＝バリア・緩＝スロー・貫＝貫通ボイス・♥＝回復・モ＝ボム＋1。やさしいでは声が応援をすり抜ける（誤射なし）。
- **操作**：ドラッグ（指の位置からの相対移動なので指で自機が隠れない）／矢印・WASD、射撃は自動、Shift で精密移動（当たり判定とかすりの範囲が見える）、B・X・右下のボタンでモデレーター召喚（やさしい2回・ふつう／むずかしい1回＋拾う）、P／Esc／右上のボタンで一時停止（タブを離れたときも自動で止まる）。
- **難しさ**：やさしい／ふつう／むずかしい（むずかしい＝以前の調整）。感情制御スキル（こころ +1/Lv・無敵 +0.15秒/Lv）。報酬の計算は以前と同じ。
- **中身**：ロジックは `minigames/shooter.js` 先頭の `ShooterLogic`（台本はシードで決まる・弾の形・当たり判定・スコア・評価・報酬）。テストは `tests/minigame-shooter.test.mjs`。弾は使い回し、敵弾の絵は種類ごとに一度だけ描いて再利用。動きを減らす設定（OS）では揺れとフラッシュを弱める。ボス戦だけ音程のない軽いリズムを足す（BGMの音量に従う）。

## 読み込みの速さ・ホーム画面に追加（PWA）
- **ミニゲームは遊ぶときに読み込み**：起動時に読むのは目録（`minigames/registry.js`）と共通部分（`minigames/core.js`）だけ。選択画面のカードに触れた・マウスを乗せた時点で先読みし、選ぶと「読み込み中…」を出してから始まります。通信に失敗したときは通知だけ出て、何も変わりません（もう一度選べます）。起動時の JS は約2.8MB → 約1.0MB。
- **ホーム画面に追加**：`manifest.webmanifest`（縦向き・紺と金）とアイコン `assets/pwa/`（`node tools/make_pwa_icons.mjs` でゲームのドット絵から描き出し）。スマホのブラウザのメニューから「ホーム画面に追加」で、アプリのように全画面で遊べます。
- **オフライン**：`sw.js` が、本体（HTML・CSS・起動時の JS）をはじめに保存し、ミニゲーム・画像・BGM は一度使ったものを保存します。一度開けば、電波が無くても再読み込みして遊べます（まだ遊んだことのないミニゲームはつながっているときに）。本体はつながっていればいつも最新を読みます。
- **更新**：`sw.js` の `VERSION` を上げて公開すると、遊んでいる人の画面に「新しいバージョンがあります・更新」が出ます。ミニゲーム本体や画像を変えたときは `VERSION` を上げてください（古い保存分が消えます）。
- https（GitHub Pages）か localhost のときだけ動きます。バランスシミュレーターの中では動きません。

## 娘の絵を差し替えるには
娘の顔の画像は `game.js` の `CHILD_IMG`（ふつう・笑顔・寝顔・泣き顔・お熱）で一括管理しています。新しい画像を `assets/img/` に置いて、ここのパスを書き換えるだけで全画面に反映されます。

脇役（班長・先生・千代さん・源さん・ミナモ・さくら・常連・ミドリ・先輩・夜鷹）の顔は `main/mobs.js` の `MOB_IMG` で管理しています（`assets/img/mob_*.svg`）。同じようにパスを書き換えれば差し替えられます。

**キャラクター設定**：だんのうらは富山県出身で、話し言葉はオネェ言葉（ときどき富山弁）。子どもは4歳の娘ひとり。

## 本編の演出・物語
- `main/presentation.js`：タイトル画面、オープニング、日付カード、エンディングの映像演出とスタッフロール
- `main/story.js`：30夜・4幕のストーリー（全33場面）。選択によって物語とエンディングの後日談が変わる
- `main/homescene.js`：動くドット絵の部屋。疲れが限界に近づくと、だんのうらが白髪・猫耳の姿に変わる
- `main/ui.js`：メニュー・ゲージ・ウィンドウなどの画面デザインとキーボード操作（↑↓・Enter・Esc）

## 境界事象 ― 月代町観測記録 ―
タイトル画面の「境界事象」から最初から遊べる、探索サスペンスADV（`kyokai.html`）。
- プロローグ＋全14章、任意調査6件、エンディング A／B／C／TRUE。手帳・観測ボードで推理し、世界 A／B／C を切り替えて謎を解く。
- 本編のセーブは読むだけ（書き換えない）。本編で見たエンディングによって作中の観測記録 B-30 が変わる。
- TRUE END 到達＋本編エンディング記録ありで、本編タイトルに **DAY 31** が出る（`main/day31.js`）。
- 仕様：`docs/kyokai/README.md`、原案：`docs/kyokai/story-outline.md`、絵の差し替え枠：`assets/kyokai/manifest.json`。

## バランスシミュレーター
`tools/simulator.html` を開くと、ゲーム本体を裏で読み込み、30日間を4種類のプレイ方針で自動プレイして、エンディングの出やすさ・平均借金・1日の行動数などを集計します。数値を調整したあとに、狙った難しさになっているか確かめるのに使います。

- 開き方：GitHub Pages なら https://dannoura0305.github.io/dannoura-game/tools/simulator.html 。手元なら `python3 -m http.server` などでサーバーを立てて開く（file:// で直接開くと動きません）
- セーブデータやエンディング一覧には書き込みません
- 夜のミニゲーム・工場タブのミニゲームは実際には遊ばず、典型的な結果を当てはめています（「工場」は工場タブのゲームを1本。その日遊び尽くしたら勉強に回す）。スキルは買いません
- 工場タブへの移行時（各300回・シード1）：借金の平均 目標ガイド 34万→32万／配信重視 58万→58万／仕事・勉強 16万→14万／無計画 48万→38万。凄腕保全エンド 目標ガイド 36%→17%・仕事・勉強 18%→44%、夜明けエンド 仕事・勉強 14%→28%、崩壊エンド 無計画 41%→10%（設備点検を何度でも繰り返せなくなったため）

## 公開のしかた（GitHub Pages）
1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch を **main**、フォルダを **/(root)** にして **Save**
4. 1〜2分後に https://dannoura0305.github.io/dannoura-game/ で遊べるようになる

以降は `main` に変更を取り込むたびに自動で更新されます。
