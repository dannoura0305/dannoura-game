だんのうら育成ゲーム

## 遊び方
ブラウザで遊べます：https://dannoura0305.github.io/dannoura-game/
（GitHub Pages を有効にすると、このURLで公開されます。下の「公開のしかた」を参照）

## 🏡 家・庭づくり（フェーズ1）

メニューの「🏡 家・庭をひらく」で、娘と暮らす部屋（12×8マス）と小さな庭（16×12マス）を整えられます。遊ばなくても本編は進められます。

- **暮らしモード**：人や家具をタップして調べる・使う（座る、灯りを点ける、本を読む、水やり）。「話す」で娘と会話。
- **模様替えモード**（時間は進みません）：下の収納から選ぶ → マスをタップでプレビュー → ［置く］。［回転］［収納］［移動］［取り消し］［やり直し］［破棄］［確定］。置けないときは理由が文で出ます。
  - PC：クリック・ドラッグ、R＝回転、Esc＝取り消し、Ctrl/Cmd+Z＝戻す、Ctrl+Y／Ctrl+Shift+Z＝やり直し、Enter＝置く、Delete＝収納。
- **クラフト**：木材・布・金具・海のかけらで家具を作る（30分・疲労+2）。素材は工場の仕事・子育て・釣り・RPGの章クリアで少しずつ（1日1回まで）。
- **物語「窓辺の小さな約束」**：5日目以降、娘と花を育てる連続イベント。思い出は「思い出帳」に残り、良い結末では自分の部屋や庭がエンディングに映ります。
- **RPGとの連動**：棚を直すと第2章に専用の会話。第2章クリアで「貝殻ランタン」のレシピが解放。


### フェーズ2（物語と暮らしの拡張）
- **家具12種・植物**：おもちゃ箱、娘の机、千代さんのラジオ、班長の工具箱、発表会の写真、風鈴、海のモビール、表札、物干し、豆電球、プランター、じょうろ。あさがお・ひまわり・ハーブの種を鉢やプランターに植えられます。
- **住人と訪問者**：三毛猫の「ねこ」が暮らしています。千代さん・班長が訪ねてきます。娘は置いた家具で過ごし方が変わり、23時以降は布団で眠ります。
- **生活イベント**：千代さん（あさがおの種・古いラジオ・ベンチで月見）、班長（工具箱・物干し）、発表会の写真／話し合い。
- **行動の記録（bonds）**：約束・行動・話し合い・頼る・休むを記録し、良い結末の「その後」と思い出帳の「この30日」に一言。結末の種類は変えません。
- **RPG連動**：第1章→風鈴、第4章→海のモビール、第5章→表札のレシピ。家の様子が夢の会話に出ます。
- **クリア後の暮らしモード**：良い・ふつうの結末の最後に「🏡 暮らしを続ける」。「☀ 一日を過ごす」で日が進み、本編の数値は変わらずゲームオーバーもありません。「つづきから」で再開できます。

### フェーズ3（素材刷新と自由度拡張）
- **操作アイコン**：下部メニュー・行動メニュー・ステータス・設定・ミニゲーム選択などの操作用の絵文字を、独自のドット絵アイコン82種（`main/icons.js`）に置き換え。差し替えは `assets/original/icons/`（`docs/icon-inventory.md`）。
- **画風の統一**：全ミニゲームのだんのうら・娘・三毛猫の見た目をそろえた（`docs/art-audit.md`）。
- **家・庭の拡張**：部屋 14×9・庭 20×14 に一回だけ広げられる（クラフト画面の「家の改修」）。家の外観（屋根・外壁・戸）、部屋の壁紙・床（畳など）を選べる。
- **季節と天候**：本編は夏→初秋、暮らしモードは15日ごとに四季。雨・雪・落ち葉・花びら・蛍。雨の日は自動で水やり。
- **写真**：暮らしモードの「写真を撮る」で部屋・庭をPNG保存、思い出帳にも貼れる。
- **生成画像の受け口**：`assets/original/manifest.json` の `file` にPNGを指定すると、Web版の家・庭もその画像で描く。

### Godot 4 試作・ComfyUI 素材
- `godot/`：家・庭の模様替え画面の Godot 4 試作（`godot/README.md`）。ドット絵は `node tools/export_sprites.mjs` で Web 版から書き出し。**この環境では Godot を動かせず未検証**です。
- `docs/comfyui/`：ComfyUI で作る画像の依頼リスト（180件・優先度つき）、プロンプト、ワークフローの雛形、手順と検品チェックリスト。

設計：`docs/home-story-design.md`／素材台帳：`docs/asset-inventory.md`・`assets/original/manifest.json`／画風：`docs/asset-style-guide.md`／検証：`docs/verification.md`／テスト：`node tests/run.mjs`

## ゲームの流れ
- DAY1〜DAY30を、配信・工場の仕事・資格の勉強・育児・休息をやりくりして生き延びます。
- 毎晩22時から行動を選びます。配信を終えるか朝6時になると、夜が明けて次の日へ進みます。
- 借金と育児ストレスは毎晩少しずつ精神を削ります（21日目以降はさらに重くなります）。こまめに休みましょう。
- 7日ごとに生活費（6万円）を払い、手元の3万円を超えた分は自動で繰り上げ返済されます。
- 次のどれかに当てはまると、その時点でゲームオーバーです。近づくと画面上部の目標欄が赤く光り、通知で知らせます。
  - 精神が0になる
  - 疲労が100で、精神が20未満
  - 借金が200万円を超える
  - 炎上が10に達する
- 30日を終えると、育て方に応じたエンディングになります。到達したエンディングはタイトル画面の「エンディング一覧」で確認できます（ブラウザに保存）。

## 夜のミニゲーム（17種・各1日1回）
メイン画面の「🎮 夜のミニゲーム」から選べます。難しさ（やさしい／ふつう／むずかしい）は設定画面か選択画面で切り替えられます（初期値はやさしい、報酬は同じ）。カテゴリ別のタブで探せて、結果はパラメータに反映されます。どのゲームにも導入の会話・結果で変わる結末・S〜Cの評価・自己ベストの記録があり、2回目以降は難しい版や別ルートが解放されます。

## 娘の絵を差し替えるには
娘の顔の画像は `game.js` の `CHILD_IMG`（ふつう・笑顔・寝顔・泣き顔・お熱）で一括管理しています。新しい画像を `assets/img/` に置いて、ここのパスを書き換えるだけで全画面に反映されます。

脇役（班長・先生・千代さん・源さん・ミナモ・さくら・常連・ミドリ・先輩・夜鷹）の顔は `main/mobs.js` の `MOB_IMG` で管理しています（`assets/img/mob_*.svg`）。同じようにパスを書き換えれば差し替えられます。

**キャラクター設定**：だんのうらは富山県出身で、話し言葉はオネェ言葉（ときどき富山弁）。子どもは4歳の娘ひとり。

## 本編の演出・物語
- `main/presentation.js`：タイトル画面、オープニング、日付カード、エンディングの映像演出とスタッフロール
- `main/story.js`：30夜・4幕のストーリー（全33場面）。選択によって物語とエンディングの後日談が変わる
- `main/homescene.js`：動くドット絵の部屋。疲れが限界に近づくと、だんのうらが白髪・猫耳の姿に変わる
- `main/ui.js`：メニュー・ゲージ・ウィンドウなどの画面デザインとキーボード操作（↑↓・Enter・Esc）

## ファイル構成
```
index.html        画面構成（HTML）
style.css         見た目（CSS）
game.js           ゲームロジック（JS）
minigames/        夜のミニゲーム（共通部分 core.js ＋ 17ゲーム）
main/             本編の演出・物語・画面デザイン（game.js を拡張）
vendor/           three.js（3Dゲーム用・MITライセンス）
tools/            開発用ツール（バランスシミュレーター）
assets/bgm/       BGM（mp3）
assets/voice/     ボイス（m4a）
assets/img/       背景・キャラ・エンディング画像（webp）
```

音声・画像を差し替えるときは `assets/` のファイルを置き換えるか、
`game.js` 内の `BGM_DATA` / `VOICE_DATA` / `BG_IMG` / `CHAR_IMG` / `SD_IMG` / `ENDING_IMG` のパスを書き換えてください。

## バランスシミュレーター
`tools/simulator.html` を開くと、ゲーム本体を裏で読み込み、30日間を4種類のプレイ方針で自動プレイして、エンディングの出やすさ・平均借金・1日の行動数などを集計します。数値を調整したあとに、狙った難しさになっているか確かめるのに使います。

- 開き方：GitHub Pages なら https://dannoura0305.github.io/dannoura-game/tools/simulator.html 。手元なら `python3 -m http.server` などでサーバーを立てて開く（file:// で直接開くと動きません）
- セーブデータやエンディング一覧には書き込みません
- 夜のミニゲームは実際には遊ばず、典型的な結果を当てはめています

## 公開のしかた（GitHub Pages）
1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch を **main**、フォルダを **/(root)** にして **Save**
4. 1〜2分後に https://dannoura0305.github.io/dannoura-game/ で遊べるようになる

以降は `main` に変更を取り込むたびに自動で更新されます。
